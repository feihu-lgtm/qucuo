# 玩家头像目录

放置玩家角色的预制头像，**2:3 竖版**（唐卡高饱和厚涂风格，藏地高原背景+金色描边，
来自同一批8连图裁切）。

## 文件名约定与当前内容
- `male.png` —— 性别选「男」时的默认头像（藏剑大叔）
- `female.png` —— 性别选「女」时的默认头像（花商）
- `other.png` —— 性别选「其他」时的默认头像（朔风独行刀客）
- `preset1.png` ~ `preset5.png` —— 头像选择器里的额外预制选项（飞贼/猎手/猫人/假小子/穿越者，
  可选，缺了会自动隐藏）

玩家也可在游戏里「侠客」页点头像上传自己的图片（存 localStorage，不占仓库）。
