# 回合上下文 `d` 字段清单

> 路线甲第 1 步产物，测于 main `855982a`。共 87 个 `d.*` 字段（`src/engine/act` + `src/engine/turn`）。
> 用途：把处理器改成纯函数之前，先看清每个处理器到底用了什么、谁在悄悄互相传值。

## 四组分类

### A. AI 的提议（提取层/`d.p` 系）

`p`（提取层解析结果）、`dealResult`（赌石谈价）、`freshNpcData`（战斗固化数据）、`giftSettlement`、`softSettle`、`narrativeText`、`rawFull`、`newConvo`、`mvuCommands`（提取的写回命令）。

### B. 回合开始时的状态快照 / 只读输入

状态：`char`、`charName`、`charBodyProfile`、`room`、`mapData`、`varTree`、`time`、`convo`、`mainConvo`、`talkTarget`、`activeTarget`、`questProgress`、`innerRoomName`、`activePreset`、`effectivePreset`、`effectiveSpecialNow`。
回合参数：`cmd`、`intent`、`isTalk`、`isSettle`、`lockedDestName`、`giftInfo`、`settleNpc`、`settleKind`、`settleBeast`、`preserveHp`、`pendingQuestBranch`、`pickupJudgment`。
注入配置与文案：`apiCfg`、`ai`、`gm`、`narrator`、`ctx`、`scenario`、`nsfwOn`、`embeddingEnabled`、`budgetInstruction`、`npcLoreBlockWithQuest`、`visibleNpcsCount`、`knowledgeTree`、`knowledgeTreeBase`、`infoDomainBlock`、`recallBlock`、`recallInfo`、`reunionBlock`、`hist`、`inSeaOfMind`、`snowLeopardContext`。
诊断：`_trace`、`isStale`。

### C. 写状态 / 写日志的函数

`addLog`、`setLog`、`setVarTree`、`setRoom`、`setMapData`、`setTime`、`setConvo`、`setChar`、`setSkills`、`setInv`、`setDao`、`setExp`、`setPot`、`setFlags`、`setGambleNegotiation`、`setPendingQuestBranch`。

改纯函数后要消掉的正是这一组：处理器不再直接调，改为返回 `{ logs, changes }` 由 `commitRound` 统一落盘。

### D. React ref（要赶出 engine 的）

`roomMapRef`、`outerDepartRef`、`pendDirRef`、`varTreeRef`、`dayMaterialRef`、`collectGrantedRef`、`roundsSinceLastSaveRef`、`playedThisSessionRef`、`pickupJudgmentRef`、`pickupExtractionFailedRef`、`gambleTalkCtx`（ref 形态传入）。

## 已发现的悄悄传值点

- `collectGrantedRef`：`resolveIntent` 写、`commitProposalWrites` 读——「采到物→跳过 mvu 写背包」的隐式通道。
- `outerDepartRef`/`pendDirRef`：`resolveIntent`（移动判定）写、`roomWrite` 读。
- `dayMaterialRef`：记忆侧跨处理器传物。
- `pickupJudgmentRef`/`pickupExtractionFailedRef`：拾取判定 `resolveIntent` → 提交侧。
- `roomMapRef`：`resolveIntent`/`roomWrite`/`commitRound` 三处读写。
- `varTreeRef`：`memoryNote`/`npcFixation`/`commitRound` 共享读——ref 存在的理由是「逻辑读最新值」，改纯函数后要变成显式输入。

## 处理器改造顺序（路线甲第 2 步）

熟→生：`choices`（2 字段）→ `narrative`（3）→ `talkKnow`/`emergence`/`rumors`/`convoAppend`/`dealSettle`/`commitFlags`（3-7）→ `roomWrite`（14，ref 最密）→ `memoryFact`/`memoryNote`/`npcFixation`（记忆+NPC 放最后）。
