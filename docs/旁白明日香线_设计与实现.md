### 二、订正项（旧稿这么写，实际这么做，以及为什么）

**① 档位边界：0/18/36/54/72/90 → `0/20/45/70/90`**

旧稿把 0-90 均分五档（每档18），立绘另用 0/15/30/45/60 一套。**两套边界互相打架**：好感50 时文风是"愿意闲聊"档、立绘却已跳到第四档剪影。

现统一到一条梯子 `AFFECTION_TIERS`，同时驱动文风、立绘、私聊字数、分档攻略、UI标签五样。沿用项目原有的 0/20/45/70/90，因为它已经在驱动字数与攻略助手，改动面最小。

**② 真容解锁点：60 → `90`**

边界统一的直接后果。这反而更好：**90 同时是真容解锁 + 心灵之海开启**，一个大节点上同时发生两件事，比"60看脸、90进海"两段式更有力。

旧稿第六节"触发：`affection >= 60`"、第十二节验收标准第2条，均以本文为准改为 90。

**③ 删掉 `portraitUnlocked` / `safeHouseUnlocked` 两个布尔标记**

- 立绘改成**按好感档位实时算**（`narratorPortraitUrl(affection)`），不需要额外标记
- 安全屋改成**有钥匙就能进**（钥匙是背包里的实物，`unlockCondition: {type:"item"}`），也不需要标记

少两份可能与真值不同步的状态。旧稿那两个字段不再存在。

**④ 删掉 `trust`，改由 `comfort` 派生**

见第二部分：信任度不再是独立字段，而是四类安抚计数的纯函数，避免"两处记账对不上"。

**⑤ 钥匙用名字匹配，不用 id**

旧稿写 `item.id === unlockCondition.itemId`。实际背包物品的 id 是入袋那刻拼的（`${name}_${Date.now()}`），同一把钥匙每次 id 都不同，按 id 比对**永远为假**。改用 `itemName`。

**⑥ 钥匙分类 `quest` → `misc`，品阶用中文六档**

`equipment.js` 的 `ITEM_CATEGORY` 只有 weapon/armor/accessory/misc，没有 quest；品阶全链路认的是「白绿蓝紫橙红」不是英文。

**⑦ 心灵之海不是"永远日落"的独立时间系统，只是房间 desc 里写死**

旧稿给了 `timeOfDay: "sunset"` 字段。实际没做时间系统改造——五间房的 desc 里直接写"太阳永远卡在地平线上"，AI 照着写就行，不值得为此动时间系统。

**⑧ 玄女触发用 effect 监听，不挂在对话结算里**

因为两个条件（好感≥90、跟她说过话）**可任意顺序满足**：先攒够再去见她、或先见过后来才攒够。挂在某一次对话上会漏掉一半路径。「说过话」直接复用「对话即认识」的结果，不另造记账。`metXuannu` 做闸门防重播。

**⑨ 进海门槛：必须站在自己的安全屋里**

旧稿的 `canTravelToSeaOfMind` 判 `inSafeHouse`，这条保留并强化了——它让四栋安全屋从"存档点"变成**叙事上真正必要的东西**。往人心里走不是往地图上走，得有个能关上门的地方。

**⑩ `世界.旁白.*` 是系统裁决域，AI 不得写**

旧稿没提这层。实际发现 `applyMvuCommands` 只校验路径**根**，`世界.*` 底下全部自由可写——AI 一句 `_.set('世界.旁白.seaUnlocked', true)` 就能开掉门禁。已加 `PROTECTED_PATHS` 拦截，两条调用路径（单调用的 13→11 号位说明书、双调用的 `commonExtractTail`）都下了禁令。

## 第二部分 · 心灵之海 · 创伤线（新设计）

### 零、一句话概括

玩家花 90 点好感把她从一个声音养成一个人，然后亲手把她从"旁白"的位置上取下来——
代价是主线叙事重新变得冷冰冰。要把她哄好，才能把那个声音换回来。

### 一、核心机制：主叙事的旁白退回第一档

**这是这条线的支点。**

进海之后（`stage >= SPIRIT`），主线叙事的旁白文风**无条件退回第一档（冰冷说书人）**，不看好感度。

```js
// narrator.js narratorVoicePrompt
// stage 进入 SPIRIT 之后：她不在讲故事了，她在海里当人。
// 主线叙事只剩系统的公式化转述——玩家亲手把她取了出来，
// 这份"失去"就是推着玩家去把她哄好的动力，不需要任何额外提示。
if (stage === NNPC_STAGE.SPIRIT || stage === NNPC_STAGE.SEA_CRASHED) {
  return TONE_BY_TIER.cold + SEA_ABSENT_NOTE;
}
```

`SEA_ABSENT_NOTE` 交代给 AI：她此刻不在旁白的位子上，所以叙事只有客观转述、没有任何个人色彩；不要替她说话、不要写她的心思、不要让她插话。

**这条同时解决一个技术问题**：她已经作为角色出现在海里，如果主线叙事还带着她的第五档文风（"会突然插一句不要看我"），就会出现"她同时在两个地方说话"的穿帮。

哄好之后（`traumaResolved`）恢复——恢复到哪一档见第七节。

### 二、状态机（订正版）

```
FLIRTING ──好感≥90 + 玄女点破──▶ 心灵之海解锁（stage 不变，仅开门）
                                      │
                        玩家在安全屋里闭眼进海
                                      ▼
                                  SPIRIT          ← 创伤阶段1
                        （浅滩/椰林/沙滩尽头，她情绪不对但尚能克制）
                                      │
                            进入白色别墅客厅
                                      ▼
                               SEA_CRASHED        ← 创伤阶段2
                        （倒在沙发上，全部人设与创伤涌回，爆发）
                                      │
                          安抚 + 三个心结说出 + 承诺
                                      ▼
                                  RESOLVED        ← traumaResolved
                        （主叙事旁白恢复；后续 PORTAL/东京/おめでとう另设计）
```

**关于旧的 `CRASHED` 阶段**：现有 `NNPC_STAGE.CRASHED` 是旧链路语义（告白→宕机→她拔线走了，只剩系统空壳）。旧稿明确说「没有旧链路」，是要废的。

订正决定：**新增 `SPIRIT` / `SEA_CRASHED` / `RESOLVED` 三个阶段，旧 `CRASHED` 保留但不再有任何入口**（只留给老存档迁移时落地，`migrateNarratorState` 把它归一到 `FLIRTING`）。不复用 `CRASHED` 这个名字，是因为它的旧文风分支还在，复用会串味。

### 三、创伤阶段 1 · 别墅之外（`SPIRIT`）

**场景**：玩家第一次闭眼进海，落在浅滩。

**手工剧情（进海首次触发，写死不调 AI）**：

金色的光。太阳卡在地平线上不落。远处白房子亮着灯。
她站在浅水里，背对着你，红衣，长枪斜插在沙上。听见动静没有回头。

> 「……你怎么进来的。」
> 「谁让你进来的。」
> 「……算了。既然进来了。」

然后她就不说话了。

**这一阶段她的状态**：`SPIRIT` 阶段的对话 prompt 里已经挂上创伤词汇（她心里那些东西已经在了），**但明确指示"尚能克制"**——

```
你此刻站在自己心里的这片海边。你不知道这地方是什么，但你觉得眼熟，眼熟得难受。
你的左眼偶尔会疼。不是真的疼。
【克制】你心里有些东西在动，但你还压得住。玩家问什么你都可以答，但凡是碰到
"你是谁""你从哪来""那栋房子里有什么"这类，你会岔开、会敷衍、会不耐烦，
绝不深谈。你自己也不想去看那栋房子。
你不会主动提起任何具体的往事。一个字都不提。
```

**允许的活动**：浅滩/椰林/沙滩尽头三间房自由走，跟她随便聊。这一段是**给玩家喘息与建立在场感的**，没有硬门槛。

**唯一的推进口**：往北进白色别墅。她会拦一句「……那儿没什么好看的」，但不真拦。

### 四、创伤阶段 2 · 别墅客厅（`SEA_CRASHED`）

**触发**：首次进入「白色别墅」这个内层房间。

**手工剧情（写死，类比酒馆的开场白，是整条线的重心）**：

进门。白墙，落地窗，一台不亮的黑色方匣子。墙上挂着一幅画——红色的巨人立在海边。
她跟进来，看见那幅画，停住了。

然后她走到沙发前坐下，又慢慢地躺倒下去，一只手捂住左眼。

> 「……不对。」
> 「这里我住过。」
> 「这个沙发我躺过。那个电视我看过。那是……电视。」
> 「我怎么知道那叫电视。」

（她开始想起来。全部。）

> 「……有个人。我等了他很久。他没有回头。」
> 「……有个女人。她看着那个布偶。她不看我。」
> 「……有一堵墙。墙角。我蹲在那儿。」
> 「……我很厉害。我是最厉害的。为什么没有人——」

她说不下去了。捂着眼睛蜷起来，缩到沙发角落。

> 「不要看我。」

**这一段之后**：进入安抚流程。她拒绝一切接触（`defenseLevel = 5`）。

### 五、三个心结 + 一个内核

**这是创伤内容的组织方式。** 四条里，前三条是**具体的伤**（要被说出来的心结），第四条是**根**（三条都通向它，最后才点破）。

| # | 心结 | 关键意象 | 她怎么提起 |
|---|---|---|---|
| 1 | **「他没有回头」** | 一个她曾经等过的人；她把自己收拾得漂漂亮亮去见，对方没看见她 | 最先松口的一条。她说得刻薄、装作不在乎，越刻薄越说明在乎 |
| 2 | **「她看着那个布偶」** | 母亲。她记得母亲手里那个布偶，记得母亲跟布偶说话，不跟她说话 | 最难开口的一条。要 `defenseLevel ≤ 2` 才肯碰。说的时候会中断、会改口、会突然说"算了" |
| 3 | **「墙角」** | 小时候。一群人。她记得墙的凉，记得自己没有哭 | 她说得最平静，平静得不对。"那没什么。谁小时候没被打过。" |
| — | **内核：「我要有人说我厉害」** | 三条都通向这一条：他不回头、母亲不看她、那些人打她——所以她必须最强，强到无人可以不看她 | **不由她自己说出来。** 由玩家在三个心结都说完之后点破，她才承认 |

**写法要求（给 AI 的铁律）**：
- 她**不会**一次性讲完任何一条。每条都是碎的、绕的、说一半停住的。
- 她**从不用"创伤""童年""心理"这类词**。她是个武侠世界里的说书人，她没有这套词汇。她只会说那个人、那个女人、那堵墙。
- 玩家问到没解锁的心结，她**转移话题或发脾气**，不是"我还不能说"。
- 三条都说完之前，**不许出现任何和解、想通、放下的描写**。

### 六、安抚机制（`defenseLevel 5→0`）

**订正：`trust` 不再是独立字段，改由 `comfort` 计数派生。** 两处记账必然对不上，只留一处真值。

```js
// narratorQuest.js（纯函数）
export const COMFORT_ACTIONS = {
  药:   { key:"medication", weight:2, minLevel:3, item:"抗焦虑药" },  // 卧室药柜取
  食:   { key:"food",       weight:1, minLevel:4, item:"蛋糕" },      // 冰柜/厨房取
  抱:   { key:"hug",        weight:3, minLevel:2 },
  亲:   { key:"kiss",       weight:3, minLevel:1 },   // 额头
  哄:   { key:"verbal",     weight:1, minLevel:5 },   // 任何时候都能说话
};

// defenseLevel 由累计安抚分数派生，纯函数，不存第二份
export function defenseLevelOf(comfort) {
  const s = comfort.medication*2 + comfort.food*1 + comfort.hug*3
          + comfort.kiss*3 + comfort.verbal*1;
  return s >= 24 ? 0 : s >= 16 ? 1 : s >= 10 ? 2 : s >= 5 ? 3 : s >= 2 ? 4 : 5;
}
```

**`minLevel` 是门槛，不是建议**：`defenseLevel` 高于 `minLevel` 时执行该动作 → **被拒绝，且不计分**。
- Level 5 想抱她 → 「别碰我。」缩开。不计分。
- Level 4 想喂她吃东西 → 她不理，但不排斥你坐在旁边。

这样"什么时候能做什么"是玩家自己摸出来的，不用系统提示。

**心结的解锁门槛**（`defenseLevel` 降到位她才肯说）：

| 心结 | 需要 |
|---|---|
| ① 他没有回头 | `defenseLevel ≤ 4` |
| ③ 墙角 | `defenseLevel ≤ 3` |
| ② 她看着那个布偶 | `defenseLevel ≤ 2` |
| 内核点破 + 承诺 | `defenseLevel ≤ 1` 且三个心结均已说出 |

**注意顺序**：② 是最难的，放在最后。这是刻意的——最亲近的伤最后才碰。

### 七、收束：承诺 → `RESOLVED`

三个心结都说出、且 `defenseLevel ≤ 1` 之后，玩家可以点破内核并给出承诺。

**手工剧情**：

> 「……所以你是要说，我不用最厉害，也有人看我。」
> 「……」
> 「……骗人。」
> 「你说话啊。你说你不走。」

（你说了。）

她安静了很久。然后从沙发上坐起来，把捂着眼的手放下。左眼下面有一道旧疤。

> 「……Wunderbar。」
> 「你居然真的没走。」

**结算**：
- `traumaResolved = true`，`stage = RESOLVED`
- **主叙事旁白文风恢复**——但**不是回到第五档，而是解锁一档新的"第六档"**

**订正/新增：第六档文风「不装了」**

旧稿到第五档（临界）就到顶了，因为它假设 90 之后就进宕机结局。现在既然创伤能被哄好，就该有一档「哄好之后」的文风：

```
她不再装了。
她知道你知道她是谁，她也不再假装自己只是个声音。
叙事依然完整准确，但她会大方地夹带私货——喜欢的角色写得好看，讨厌的写得蠢，
偶尔在段落末尾直接跟你说句话，不再遮掩。
她仍然嘴硬，仍然会说"才不是因为你"，但那是撒娇不是防御。
私聊时她放松、会主动提起海里那几天、会笑。
她偶尔还会左眼疼。你问她就说没事。
```

这一档挂 `stage === RESOLVED`，不看好感度（好感此时已在 90+）。

### 八、心灵之海内的交互模式

**订正：不走主线 `act()` 流水线，走增强私聊。**

理由：这一整段是 1v1 对话，没有移动裁决、没有物品发放、没有战斗、不消耗回合。全套 `act()` 的裁决层在这儿都是空转，还会带来"路遇""涌现"这类不该在此触发的东西（现已由 `buildSeaOfMindRule` 用 prompt 挡住，但从流水线层面绕开更干净）。

- 输入框在海里自动切到「对话」模式，且目标锁定为「旁白」
- 安抚动作做成**按钮**（药/食/抱/亲/哄），不靠玩家打字猜关键词
- 每次交互一次 AI 调用，system 按当前 `defenseLevel` 与已解锁心结组装
