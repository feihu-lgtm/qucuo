## 0. 数据字段规范（对齐现有 catalog，别自造）

现有 `catalog.js` 装备结构（已核实）：
```
武器 { name, category:WEAPON,   quality, atkMul,  effect?, sixDim?, desc }
护甲 { name, category:ARMOR,    quality, defMul,  effect?, sixDim?, desc }
饰品 { name, category:ACCESSORY, quality,         effect?, sixDim?, desc }   // 无倍率，靠 effect/sixDim/bonus
```
- 倍率跟公式走：`equipAtk = round(100×atkMul)`（红档满值 100）；护甲同理 def。
- **effect 可用字段全集**（从现有 catalog 提取，玉器只从这里选，不发明新字段）：
  - 攻击向：`forceFirst`(必先手) / `ignoreDefense`(无视防御) / `doubleVsStatus`(克状态翻倍) / `lowHpBonus`(残血增伤) / `afterStatusBonus`(趁中招追击) / `detonateMark`(引爆内伤{perStackRatio})
  - 控制向：`enemyCostPenalty`({value,turns} 封穴抬高对方耗气) / `freezeEnergyRecovery`(冻回气) / `applyMark`({name,stacks}+`applyMarkChance`+`applyMarkOnHit` 内伤印)
  - 应对向：`onCounterSuccessDamageRatio`(应对成功追伤) / `onCounterSuccessEnergyGain`(应对成功回气)
  - 续航向：`hpRestore`(起手/每回合回血比例) / `energyRestore`(起手回气)
  - 六维：`sixDim:{ 根骨/悟性/体魄/魅力/智谋/身法/气运: ±N }`
- 品质分档潜规则：白绿基本只倍率；蓝档轻特效或单条六维；紫橙红才挂强特效/多六维。
- desc 走说书人味 + 玉料典故（种水/场口/雕工），保持项目文风。

**注**：下方 effect 是**建议配置**。用户说"特效你自己用 AI 随机"——落地时可保留这份建议，或对紫橙红档在 effect 全集里按品质档随机抽配。两种都行，建议先用这份定稿（已按玉器气质配好），日后再引入随机。

## 2. 原石原料的多种可能（真实赌石体系 → 架空本地化）

### 2.1 一块原石的数据模型（出生即固化，玩家不可见"真相"）
```
石头 = {
  id,
  场口,              // 决定风格与基础赌性（见 2.2）
  皮壳,              // 决定线索可信度（见 2.3）
  真实种水,          // 玻璃/冰/糯/豆/砖（决定成品品质上限，见 2.4）
  真实色,            // 帝王绿/秧苗绿/阳绿/晴水/白/无色（决定成品品质，见 2.4）
  料位: [格1,格2,格3] // 三刀对应三个位置，每格独立标 有料/无料 及该处种水色
  皮壳线索: [松花?,蟒带?,癣?,雾?]  // 系统按真实内含生成、带噪声（见 2.3）
}
```
- **出生固化**：进料场时系统一次性骰定以上全部并写死，同 NPC 出生固化哲学。
- **三刀 = 三格**：每刀选一格开。切中"有料格"→ 见色，按该格种水色算收获；切中"无料格"→ 空（穿麻布/垮）。
- **AI 只描述**：皮壳外观、开切见到什么、收购人神态；**切没切中、种水色、价格全是系统裁决**。

### 2.2 场口（架空本地化 = 原石"批次来源"，决定基础赌性）
真实：不同场口皮壳/种水风格迥异（帕敢黑乌砂多出玻璃种、莫西沙脱砂、大马坎黄雾）。架空成三曲 + 雪山：

| 场口（架空） | 现实原型 | 赌性 | 基础种水倾向 | 说书人味 |
|---|---|---|---|---|
| 熊曲老坑 | 帕敢/老场 | 稳中偏好 | 种老，多出冰种以上 | 熊曲上游雪山冰川碛下来的老料，皮壳老结 |
| 鹰曲新场 | 新场石 | 波动大 | 忽好忽垮 | 鹰曲峡谷冲刷的新料，皮薄水灵，赌性最烈 |
| 狼曲水石 | 后江/水皮 | 偏小赌怡情 | 种嫩偏多，偶有惊喜 | 狼曲河床滚料，皮被水磨得干净，好看却难断 |
| 雪山老坑（稀有） | 莫西沙/公盘 | 大赌大暴 | 顶级玻璃种概率最高，但垮起来血本无归 | 雪山派禁地私采的料，一块难求 |

- 场口影响：真实种水/色的**基础分布**（雪山老坑把 `qualityDistribution` 的有效 luck 抬高、鹰曲新场加大方差）。价格也与场口挂钩（雪山老坑进场费最贵）。

### 2.3 皮壳 + 皮壳线索（决定"看得准不准" = 线索噪声）
真实皮壳五特征：**皮壳、松花、蟒带、癣、雾**。行话"皮壳老则种好、皮壳细则肉细"；"宁赌一线（蟒带）不赌一片"；蟒带上有松花赌高色概率大；但蟒成膏药状反而无色。

架空皮壳类型（沿用真实术语，够味）：

| 皮壳 | 现实 | 线索可信度 | 含义 |
|---|---|---|---|
| 黑乌砂 | 各场底层黑皮 | 低（难断） | 灰白糙手可能出玻璃种，也可能狗屎底，最赌 |
| 黄盐砂 | 黄砂皮 | 中 | 砂粒明显，肉眼可估个大概 |
| 白盐砂 | 白砂皮 | 中高 | 皮细肉多半细，相对好断 |
| 水皮 | 水石 | 低（磨掉了） | 皮被水磨光，颗粒没了，看不出内里 |

**皮壳线索机制**（这是玩法核心）：系统按真实内含，生成一组带噪声的线索文字，AI 据此描述。玩家凭线索猜哪格有料。
- **松花**（皮上绿点）：出现在"有料格"上方的概率 = 真实有料 × 场口系数 × (1 − 皮壳噪声)。有松花≈该处有色的正向信号。
- **蟒带**（缠石色带）：越粗越环绕 = 内部色越好的强信号；"膏药状蟒"是**假信号**（反而无色）——留给"看走眼"的坑。
- **癣**（黑斑）：与绿共生，既可能"活癣化绿"（好），也可能"死癣"（坏）——双刃信号。
- **雾**（皮肉之间过渡层）：黄雾/白雾/黑雾，暗示底色。
- **噪声来源**：皮壳类型（黑乌砂/水皮噪声大）+ 玩家**悟性**（悟性高→系统给的线索更贴近真相，等于"看得准"）。这让悟性在赌石里有真实作用。

### 2.4 种水 + 色 → 成品品质映射
真实分级：种水玻璃种>冰种>糯种>豆种>砖头；色帝王绿>秧苗绿>阳绿>晴水>白>无色。

架空映射到六品质（白绿蓝紫橙红）：
```
成品品质基线 = f(切中格的种水档 + 色档)
  玻璃种+帝王绿 → 红
  玻璃种/冰种+秧苗绿/阳绿 → 橙
  冰种+晴水 / 糯种+阳绿 → 紫
  糯种+晴水 / 豆种+阳绿 → 蓝
  豆种+白 → 绿
  砖头/无色 → 白（或废，垮）
```
**据为己有→委托料场做装备**（§3 三分支）里，成品品质**最终**由 `rollQuality(有效luck')` 决定：
```
有效 luck' = clamp( 玩家气运 + 切出料的品质档加成 + floor(手工费/阈值), 0, 10 )
30% 被偷（料没了）/ 10% 失败（料废）/ 60% 做好 → makeGameItem({ 上面20种里按品质匹配一件, quality: rollQuality(luck') })
```
- 复用 `equipment.js` 的 `qualityDistribution(luck)`（气运 0→10 在 `[50,30,10,8,1.5,0.5]`↔`[0,20,20,20,20,20]` 插值）。**这就是用户说的"关联运气的概率我们设计过"**。
- 30/10/60 三分支各自 AI 叙事（料场老师傅偷料被抓/失手崩了/精心雕琢成器）。

### 2.5 造假料（进阶，可后置）
真实：填绿玻璃、注色、灌铅配重骗手感。架空做成黑市摊子偶尔混入的假料：
- 玩家**智谋**高→系统给"识破"提示（手感偏轻/色根不自然/擦口见胶）。
- 识破可拒买或压价；没识破买了切开是假料 → 垮。给智谋一个用武之地，也给赌石加一层"防坑"深度。

## 2.6 多方竞价机制（收购环节的正式设计，替代原"单一收购人报价"）

> 灵感起点：美版真人秀 **Deal or No Deal**——银行家给一个报价，你选 Deal / No Deal，报价 = 剩余期望 × 折价系数。
> 但真实赌石摊子**从来不是一个人出价**。所以升级成「一群人竞价 + 局中局」，武侠味在人心不在公式。
> **核心**：每开完一刀，不是一个人出价，而是一群人在竞价；玩家要在嘈杂里判断谁真心、谁做局、谁在诈你。

### 2.6.0 定价地基（Deal-or-No-Deal 式，仍是骰点内核）
每个竞价者的报价都从同一个系统基准出发，再按各自性格加偏移：
```
基准报价 = 剩余未开格的期望价值 × 折价系数(<1)
  · 已开出的料越好 → 剩余期望越高 → 基准越高（诱惑落袋）
  · 剩格越多、越可能藏大料 → 期望高但方差大 → 折价系数越狠（风险贴现）
每个竞价者报价 = 基准 × 性格系数(见下) ± 噪声
```
玩家选「卖给谁 / 全不卖，继续开下一刀（No Deal）」。**报价高低是系统裁决；谁真心谁做局，靠玩家智谋判定 + AI 叙事表演。**

### 2.6.1 第一刀·擦窗后：围观者七嘴八舌（噪声型竞价）
擦出指甲盖大的窗，翠色若隐若现。围观赌客骚动，四类人插嘴（性格系数决定出价高低与可信度）：
- **小商贩（保守型）**：性格系数最低(~0.7)，全现金不啰嗦。嘴上永远贬低窗口，但**他肯出价=石里有货；他不出价=真废了**（反向信号，最可信）。
- **马帮头（冲动型）**：系数 0.8~0.9，嗓门最大爱抬杠，可能只图抬价快感、未必真买。
- **围观牧民（跟风型）**：纯噪声，没钱，喊完就讪笑"开玩笑"。存在意义=制造混乱。
- **锦官城差役（理智型，偶现）**：系数最接近真实期望(~1.0)，但只看中高档料，低档料不理。

### 2.6.2 第二刀·开窗后：正式竞价 + 老板回收（逐个报价，报完不改）
巴掌大窗面摊开，品质与裂纹基本可见。老板出来主持，有意者逐个报一次价、不能改。真正买家下场：
- **天都镇富商**：稳，接近市价；转卖锦官城金玉行，利润算死；见裂立刻压价/退出。
- **百花楼兰姐（偶现）**：出价未必最高，但带**附加条件**（例："料我要了，你去孟铁匠打磨好送百花楼，打磨费我出，另请你喝桂花酿"）。附加条件有时比银子值钱，看玩家当前需要。→ 落地用 `perk_xxx` / 情报物 / 好感承接。
- **锦官城官差**：略高于富商，但**只收武器胚料**；饰品/护甲胚料不竞价。
- **雪山派弟子（偶现）**：出价不高，但**以物易物**——付丹药 / 练功秘籍残页。急需提武功的玩家可能比卖钱划算。
- **黑风寨兄弟（极偶现）**：出价最低，但加一句"上次你帮寨子那事巴桑哥记着，这料让我，下次去黑风寨不用通报"。**人情债**，比银子难算。→ 落地挂 flag/reputation。
- **老板回收（保底）**：所有竞价都不满意时，可直接卖老板。回收价永远低于市价（他也转卖留利润），但**从不拒收任何料，哪怕开裂**——"裂了的料有裂了的用处，碎玉磨粉入药，废石铺路。天底下没有真废的东西，只有不认账的人。"

### 2.6.3 局中局（多方竞价的精髓——在人心不在公式）
全部靠**智谋判定**触发识破（见 §2.6.4 缺口）：
- **托儿（老板的局）**：老板安插的托儿假意出高价，逼真买家多掏钱。智谋通过→发现某人出价后偷瞄老板。识破可**点破**（托儿讪讪退开，真买家重估价格）；或**将计就计**卖给托儿（托儿当场愣住，老板出来圆场：认栽掏钱 / 赔笑"我替他买了"）。
- **买家串通（买家的局）**：两买家轮流压价，让你以为没人要，低价卖出后另一人说"你捡大便宜了"。智谋够高→竞价时看到两人交换眼色，识破。点破后串通者尴尬散开，剩下真买家重估——场面冷下来，玩家有冷静期重新谈判。
- **玩家自己做局**：好料时故意犹豫、暗示不卖→刺激买家加价；或把普通料拿去拍卖、在老板定起拍价时露失望脸→老板降起拍价→低起拍反而引发竞争、成交价更高。**做局有风险：被看穿则信誉（reputation）受损。**

### 2.6.4 拍卖会（每月十五·截胡与反截胡）
天都镇玉器轩每月十五办小型拍卖，专拍赌石坊开出的上等胚料。
- **触发**：`dayIdx % 30 === 14`（需先定义"月"=30 天，见缺口）且开出料 **≥ 蓝档**，玉器轩掌柜提议送拍："起拍价我定，流拍算我的，成交抽一成。"可拒（留现场竞价）可接。
- **起拍价**：掌柜按窗面品质定，通常比现场第一口价高两成。定太高→台下沉寂片刻（沉默即压力）。
- **竞拍者**：比现场有钱得多（锦官金玉行采买、天都大商号、偶有大理远道玉商），每口加价都有算计。
- **截胡**：若现场已和某买家（如兰姐）达成口头意向，拍卖出现更高价，玩家可反悔→原买家记恨、好感降；坚持按原价卖兰姐、放弃高价→兰姐记住，日后百花楼给额外折扣/情报。
- **故意流拍**：台下无人出价（可能买家串通压价）→掌柜宣布流拍。玩家可拿回现场卖，或拍后私下找台下买家谈（不当众出价≠不想要）。

### 2.6.5 落地缺口（下轮必须先补）
1. **智谋判定函数（不存在，必须新建）**：现有系统里智谋只是战斗/说服的静态加成，**没有主动骰点**。局中局全靠它。需建通用 `attributeCheck(attrValue, difficulty)` → 返回成功/失败 + 程度，供识破托儿/串通/假料复用。建议：`成功率 = clamp(0.3 + (智谋 - 难度)×0.1, 0.05, 0.95)`，难度按局的隐蔽度分档。
2. **"月"的定义（拍卖日）**：现有只有 `dayIdx = floor(time/24)`。定 30 天一月，`dayIdx % 30 === 14` 为拍卖日。
3. **竞价者 = 轻量临时对象**，不是 room.npcs 里的实体 NPC（避免污染在场系统）；性格系数表 + 偶现概率写进 `gambleStone.js`。兰姐/雪山派/黑风寨的"附加条件"回报接现有 `perk_`/`reputation`/情报物/以物易物。
4. **AI 分工**：竞价者的喊价台词、老板主持的话术、识破时的神态、圆场——全 AI 叙事；**报价数值、识破成败、成交结算全系统裁决**。守铁律，别让 AI 决定谁是托儿或成交价。

## 4. 系统层 vs AI 层：职责划分（对照现有 act 命令流）

> 用户要求：规划清楚赌石每一步"哪些直接系统层出、哪些走 AI"，并跟现有 act() 命令流比照。
> 总原则不变（项目铁律）：**AI 提议内容/叙事，系统裁决一切数值与结果**。
> 对照锚点：现有 act() 的分层已经是范本——classifyIntent(系统判类型) → 移动/方向由固定拓扑【系统裁决】(AI 不能决定去了哪) → AI 生成 output 叙事【AI】 → applyMvuCommands 裁剪好感/威望【系统裁决】。赌石照抄这个骨架。

### 4.1 全流程分层表

| 步骤 | 系统层直出（确定性代码，AI 不参与） | 走 AI（只叙事/润色，不决定结果） | 对照 act 里的同类机制 |
|---|---|---|---|
| **进场买石** | 扣银两、生成石头对象、**出生即固化**(场口/皮壳/种水色/三格料位/皮壳线索噪声) 全部 seededRand 骰定写死 | 描述这块石头的外观、皮壳卖相（据系统给的皮壳线索文字化） | 类比"移动"：目的地(去哪)是系统定的，AI 只描述路上见闻 |
| **看皮壳** | 皮壳线索的真伪、噪声大小（受悟性影响）由系统算好 | 把线索演成一段说书人相石口诀（"这蟒带缠得紧，怕是有色"） | 类比 inspect：系统给定信息，AI 措辞 |
| **开一刀（选格）** | **切中/切垮、切出什么种水色 = 系统裁决**（读出生固化的料位），不容 AI 改 | 描述解玉师傅下刀、石开见色/见棉的瞬间 | 类比战斗 resolveTurn：胜负系统算，AI 只写招式过程 |
| **每刀后多方竞价** | 每个竞价者的**报价数值**(Deal式基准×性格系数)、谁是托儿/串通、identity 折扣 = 系统 | 竞价者的喊价台词、神态、老板圆场、起哄——纯表演 | 类比说服 persuasion：hit/guard 系统判，AI 只说台词 |
| **识破托儿/串通** | **智谋判定 attributeCheck(智谋,难度) 成败 = 系统** | 识破/没识破的叙事表现（"那人出价后偷瞄了老板一眼"） | 类比说服的判定：系统裁决，AI 呈现 |
| **卖 / 据为己有（Deal or No Deal）** | 结算银两、料子归属、拍卖起拍价/成交价 = 系统 | 收购人拿钱走人、或料子被玩家收下时的反应 | 类比任务分支 choices：选项后果系统定，AI 演绎 |
| **委托做装备（30/10/60）** | **三分支骰(被偷/失败/成功)、成品品质 rollQuality(有效luck') = 系统**；扣手工费、延时取件 flag | 料场老师傅偷料被抓/失手崩了/精心雕琢成器的过程叙事 | **直接抄 ForgeScreen**：委托-延时-取件骰品质，全套现成 |
| **拍卖会（每月十五）** | 是否拍卖日(dayIdx%30)、竞拍者出价、截胡/流拍结果 = 系统 | 拍卖会现场气氛、掌柜主持、竞拍者暗中较劲 | 类比游走 NPC 投放：出不出现(概率)系统定，在场表现 AI 演 |

### 4.2 走 act() 还是独立 Screen？
- **赌石不走 act() 自由输入流**，而是**独立 building Screen**（GambleStoneScreen，抄 ForgeScreen/PersuasionScreen 的模式）——因为它是强结构化交互（选石→开刀→竞价→委托），不是自由文字行动。这跟战斗(DuelScreen)、说服(PersuasionScreen)同类：**都是从主界面弹出的独立结构化界面，不占 act() 的自由输入**。
- **每步的 AI 叙事，走独立的小型 callModel**（像 persuasion.js 的 runPersuadeTurn 那样），传入"系统已裁决好的结果"，让 AI **只负责把这个既定结果演成文字**。system prompt 里明确禁止 AI 改结果——同 persuasion "隐藏判定"的约束写法。
- **进出赌石坊本身**走 building 入口（天都镇料场 building），这一步跟 act() 的"移动到内层房间"复用同一套（前面已做的内层房间过滤 + building 面板）。

### 4.3 关键红线（照抄战斗/说服的成熟约束）
1. 石头里有什么，**出生即固化**，AI 全程读不到真相、改不了（同 NPC 出生固化、同战斗 foe 数据固化）。
2. 切涨切垮、成品品质、报价数值——**系统 seededRand/rollQuality 骰定**，AI 拿到的是结果，只负责叙事（同 resolveTurn 胜负、同 applyMvuCommands 裁剪）。
3. AI 若试图在叙事里"让这刀切涨"或"让收购人多出钱"——**无效**，因为数值不从 AI 的输出里读取，只从系统结算读取（同 room.name/exits 被系统强制覆盖，AI 写了不生效）。
4. 智谋判定(识破托儿)用**新建的通用 attributeCheck**（§2.6.5 缺口①），成败系统定——不问 AI"玩家识破了吗"。

### 4.4 落地时的 AI 调用清单（每处都是"喂结果、要叙事"）
- `narrateStoneAppearance(石头.皮壳线索)` → 相石描述
- `narrateCut(格号, 系统已定的切果)` → 开刀叙事
- `narrateBidding(竞价者列表+各自报价+托儿标记)` → 竞价现场（AI 演台词，不碰报价）
- `narrateCraft(三分支结果, 成品)` → 做装备过程（抄 ForgeScreen 取件叙事）
每个都像 runPersuadeTurn：system prompt 里塞"系统已裁决 X，你只把 X 演成说书人文字，不得改动 X"。
