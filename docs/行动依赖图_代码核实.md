# 行动依赖图 · 代码核实版

> 本文按项目铁律「信代码不信文档断言」，把**每一种玩家行动走哪条代码路径、依赖哪些函数、
> 触发哪些挂载与写入**逐条对照 `MudRPG.jsx` 及各模块源码画出。行号为实测。

---

## 零、两类行动的总分野

所有玩家行动分成两支：**走 `act()` 主循环**（重路径，含 AI 叙事 + 状态裁决 + 记忆写入），
和**旁路调用**（轻路径，自造精简调用或纯前端，不进主循环）。

```
玩家操作
 ├─ 走 act()（唯一主循环，L1785）───────────── 见 §一
 │    自由行动 / 移动 / 对话 / 战斗 / 23处建筑结算 / 任务节点 / 赌石谈价·成交
 └─ 旁路（不进 act）──────────────────────── 见 §四
      端详物品武学 / 相石看皮 / 私聊旁白 / 飞鸽传书 / 元问题help / 内层移动
```

## 一、act() 主循环的内部依赖链（L1785 起）

```
act(rawCmd, extraReplies, opts)
 │
 ├─【0 前置分流】
 │   ├─ opts.forceLayer 存在 → 明确移动信号，isTalk=false          (L1793,1820)
 │   ├─ buildCurrentSnapshot() 存"落子前"快照 → undoSnapshotRef     (L1801)
 │   ├─ interactMode==="whisper" → talkToNarrator() 私聊旁路 return  (L1803)
 │   └─ intent = isTalk ? UNKNOWN : classifyIntent(cmd)             (L1832)
 │        依赖 inputIntent.js：正则分类 MOVE/LOOK/COMBAT/META_QUERY/UNKNOWN
 │
 ├─【1 移动裁决】（AI 调用前，结果先定）
 │   ├─ 内层：hasInnerMap && innerRoomName && forceLayer≠outer      (L1976)
 │   │    → resolveInnerExit(room, innerRoom, dir)  ← innerMap.js
 │   │    → 命中则改 innerRoomName + describeInnerArrival + time+1 + return
 │   │      （纯前端，零 AI）                                        (L1977-2003)
 │   │    → forceLayer==="inner" 但无出口 → "此路不通" return       (L2007)
 │   └─ 外层：resolveExit(room.name, dir)  ← qucuoMap.js            (L2033)
 │        ├─ isNodeUnlocked(dest,{completedQuests,flags}) 门禁      (L2034)
 │        │    未解锁 → destinationLock="此路未通"                  (L2036)
 │        ├─ 已解锁 → destinationLock="固定地图，去X，你只管描述"   (L2051)
 │        └─ 无方向 → destinationLock="位置不变，exits必须等于…"    (L2067)
 │
 ├─【2 系统裁决·注入 prompt】（AI 改不了这些结果，只负责演）
 │   ├─ 拾取：35% && rollQuality(luck) → pickupNote                (L2100)  ← equipment.js
 │   ├─ 遭遇：rollEncounter(dest, luck) → encounterNote            (L2114)  ← encounter.js
 │   ├─ 采集：detectCollectPickup(cmd,room,items) 命中             (L2137)  ← quests/collect.js
 │   │    → setRoom 从地上抹去 + setInv 入袋 + collectNote"别重发"  (L2145)
 │   ├─ 任务节点：opts.forcedEvent → forcedEventNote"演已定情节"    (L2201)
 │   │    （调用方已先 forceAdvanceQuest 结算奖励，见 §二）
 │   └─ 其余注入：angryNote / emergenceNote / questStageNote / arrivalNote
 │
 ├─【3 拼 prompt】                                                  (L2231)
 │   ctx = 状态行(时间/房间/出口/在场NPC〔身携〕/物品/HP/七维/背包/装备/武功/因果劫数/flags)
 │         + pickupNote + destinationLock + angryNote + emergenceNote
 │         + encounterNote + questStageNote + collectNote + arrivalNote + forcedEventNote
 │   promptScope = gm?full : isSettle?settle : intent映射(move/talk/full/combat)  (L2459)
 │   userContent = ctx + distantBlock + recallBlock + reunionBlock
 │                 + infoDomainBlock + hist + proseRule + cmdSuffix               (L2469)
 │       ├ distantBlock  ← daySummary.js（远景日总结）
 │       ├ recallBlock   ← memory/recallEngine.js（向量召回，开 embedding 才有）
 │       ├ reunionBlock  ← npcAwareness.js（久别重逢命中才有）
 │       ├ infoDomainBlock← knowledge.js buildInfoDomainBlock（有在场NPC才有）
 │       └ hist          ← convo 窗口（行动N条／对话≥20条）
 │   sys = buildSysBase(...promptScope, opts)  ← 蓝绿灯分档，见 §三               (L2472)
 │
 ├─【4 rollback 快照】                                              (L2379)
 │   rollback = {room,char,dao,skills,inv,exp,pot,flags,mapData,time,varTree,convo}
 │   （不含 log —— log 不回滚）
 │
 ├─【5 try：AI 调用 + 解析 + 裁决】
 │   ├─ callMainOnce(nudge, narrativeOnly)  调 AI                  (L2447)
 │   │    流式 / 双调用（主叙事 + callExtraction 提取状态） / 截断自动重说
 │   ├─ parseMainResponse(rawText) 解 JSON + <deal>提取 + 截断救援  (L2390)
 │   ├─ MVU 好感度裁决：applyMvuCommands（±15 clamp）              (L2383附近) ← mvu.js
 │   │    + 反幽灵过滤：不在系统在场名单也不在已知角色表的名字 → 丢弃
 │   ├─ 赌石谈价闭环：dealResult && gambleTalkCtx → 见 §五          (L2726)
 │   ├─ 任务台本"夺舍"：命中 flag → 固定台本替换 output
 │   ├─ addLog(output) + 新面孔检测 + updateLastSeen
 │   ├─ 涌现人物 ensureNpcCombatData（老面孔继承 carriedItems）     ← npcGeneration.js
 │   ├─ setRoom 强锁 lockedDestName/exits（不信 AI 返回的 room）
 │   ├─ delta 裁决：items_add(首件对齐拾取quality) / items_rm / exp / pot / skill
 │   │    / flags_add → forceAdvanceQuest 推进 stage / 结算奖励
 │   ├─【记忆四链写入·任何档不省】
 │   │    S1 addLog(p.output)                    屏幕正文 + 电报行
 │   │    S2 setConvo(...assistant slice(0,500)) 对话历史（近景 hist）
 │   │    S3 writeNote(fire-and-forget)          向量小纸条 ≤50字   ← memory/note.js
 │   │         行动=公共(owner空)／对话=私有(owner=talkTarget)
 │   │    S4 registerFact(p.memory, witnesses)   事实账本         ← knowledge.js
 │   │         行动=在场目击／对话=仅 talkTarget 亲历
 │   └─ setTime+1 + roundsSinceLastSave++（驱动自动存档）
 │
 └─【catch】整体回滚 rollback.*（log 不回滚）
```

## 二、走 act 的入口一览（谁在调 act，实测）

| 入口 | 行号 | 调用形态 | scope |
|---|---|---|---|
| 打字自由行动 | 输入框 | `act(input)` | UNKNOWN→full |
| 方向移动·外层 | 方向键/地图 | `act(dir,[],{forceLayer:"outer"})` | MOVE→move | (L4404,5347,5349) |
| 方向移动·内层 | 方向键 | `act(dir,[],{forceLayer:"inner"})` | 纯前端 return | (L4393,5370) |
| 环顾四周 | 按钮 | `act("环顾四周")` | LOOK→talk | (L3348,4564) |
| 查看 NPC | 点击 | `act("look "+npc.id)` | talk | (L3206) |
| 邀战切磋 | 按钮 | `act("向X抱拳邀战…")` | COMBAT→full | (L3521) |
| 切磋总结 | 战斗结束 | `act("切磋结束。经过…")` | full | (L5646) |
| 任务节点❢ | 感叹号 | `act("❢"+title,[],{forcedEvent,forcedEventNpc})` | full | (L3120,3182) |
| 送礼 | 面板 | `act("把X送给Y",[],{settle:true,settleNpc:Y})` | settle+人设 | (L3687) |
| 拜师 | 面板 | `act("拜X为师…",[],{settle:true,settleNpc:X})` | settle+人设 | (L3599) |
| 住店/求医/秘籍/突破 | 面板 | `act(...,[],{settle:true})` | settle | (L3701,3707,3717,3724) |
| 点餐/打醮/读书/买书 | 面板 | `act(...,[],{settle:true})` | settle | (L3790,3802,3806,3817) |
| 存款/取款/质押/赎回 | 面板 | `act(...,[],{settle:true})` | settle | (L3826,3833,3840,3850) |
| 接护镖/接悬赏/交悬赏 | 面板 | `act(...,[],{settle:true})` | settle | (L3855,3860,3869) |
| 听传闻 | 面板 | `act("听掌柜说传闻…",[],{settle:true})` | settle | (L3954) |
| 铸剑委托/取货 | 面板 | `act(...,[],{settle:true})` | settle | (L3933,3948) |
| 赌石谈价 | 赌桌 | `act(content)`（谈价语境） | 谈价·轻量 | (L3882) |
| 赌石成交/委托 | 赌桌 | `act(...,[],{settle:true,settleNpc})` | settle | (L3891,3896,3898) |

**关键**：所有建筑交互都**先本地结算数值**（setChar 扣钱 / setInv 入袋 / setFlags 置位），
再拼一句自然语言走 `act()`，正文/convo/小纸条/账本/召回/好感度全自动挂上——**不自造 AI 调用**。

## 三、挂载分档（蓝绿灯，buildSysBase L89）

见 `开发_挂载分级与蓝绿灯设计.md`。要点：
- 🔵 蓝灯常驻：旁白身份 + 文体/格式铁律 + 篇幅 + proseRule + 硬编码地图铁律
- 🟢 绿灯：`gateScenario`（关键词OR状态双通道）、物件志(full且mayGrantItem)、
  MVU(settle看settleNpc/否则hasNpc)、认知隔离(scope≠move)、NPC lore(三源)、schema三档
- settle 档：砍物件志/认知隔离/全量schema/远景/召回；settleNpc 有值才留 lore+MVU+重逢

## 五、赌石专章（寄生在 act 上）

```
GambleStoneScreen.jsx（界面，不碰AI）
 │  import { birthStone, cutSlot, appraiseStone, rollBidders,
 │           rollCommission, readSkinClue } ← gambleStone.js（确定性数值内核）
 │
 ├─ birthStone(changKou,luck,seed)  开局定：种水/皮壳/三料位/裂/刀口（出生固化）
 ├─ cutSlot(stone,pos)              切一刀，前端本地算价值
 ├─ rollBidders(stone,luck)         派竞价者 + baseOffer
 │
 └─ 三回调抛回 MudRPG.jsx：
     ├─ onInspect → handleGambleInspect  §四旁路（唯一绕开 act）
     ├─ onTalk    → handleGambleTalk L3876
     │    存 gambleTalkCtx={bidderName,stoneId,baseOffer,cash,carry}
     │    setInteractMode("talk")+setTalkTarget → act(content)
     │      → AI 回 <deal>{priceMult,addItem}</deal>
     │      → act后段(L2726) gambleSettleNegotiation clamp[0.8,1.5]
     │        → 写 gambleNegotiation[stoneId][bidderName]=新价 → 清 ctx
     │    不关赌桌（关了 unmount→石头重生成→negotiation对不上 stoneId）
     └─ onSettle  → handleGambleSettle L3887
          先本地 setChar 结算银钱（sell加钱/forge扣200）
          再 act(叙事句,[],{settle:true,settleNpc}) 走主循环演成交
          forge 成败(success/stolen/崩废)由 res.result 分支决定演哪句
```

**一句话**：`gambleStone.js` 确定性算数值 → 界面展示 → **相石自造轻调用，谈价与成交
复用 act()**，靠 `gambleTalkCtx` + `<deal>` + `gambleNegotiation` 三者做谈价闭环。
