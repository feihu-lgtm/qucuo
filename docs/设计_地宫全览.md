## 二、探索循环（run 状态机）

`createDungeonRun` 起步即 exploring；`selectDungeonNode` 二选一 → `resolveDungeonChoice` 裁决 → `advanceExploring` 推进。

- **每步给两个节点**：池 A（战斗/机关/奇遇）+ 池 B（冒险者/秘宝/休整/奇遇/机关，剔除重复类）各抽一。
- **层推进**：走满 stepsPerFloor 升层；末层走满后选项只剩 BOSS。
- **判定公式**：`35 + (属性值 - DC) × 12`%，钳 [15,95]。DC 普遍 5-7，属性取 effectiveSpecial（身法/悟性/体魄/智谋/根骨/气运七维）。
- **结算**：victory/retreated 拿全额 loot；defeated 减半且保底 1 血；耗时 = floor 时辰；首通写 clearFlag；战斗嗑药按件扣 inv；战利品 makeItemSmart 实体化入背包。

## 三、七类节点

| 节点 | 机制 |
|---|---|
| combat | buildCombatNpc 经 ensureNpcCombatData 固数值，跳转懒加载 DuelScreen，赢拿 reward+被抢物返还 |
| trap | 二选一检定（各挂属性+DC），成功奖钱/经验/物品，失败扣 hp |
| event | 奇遇（研读经卷/盗墓遗囊/壁缝/香炉），混合检定与直接收益 |
| treasure | 秘宝（九宫锁/木架/库房），外层保底+内层高 DC 博装备 |
| rest | 回血(hpHeal/hpHealRatio) 或潜能+exp |
| adventurer | 见下节 |
| boss | 末层唯一节点，赢即 victory+clearFlag |

## 四、OC 冒险者节点（现行设计）

12 人池 `data/dungeon/adventurers.js`，字段 `{id,name,title,archetype,rainbow,stealBias,levelCap,gender,faction,brief,personality,fullBio,carry}`；`metAdventurers` 去重，另按日种子在世界据点随机游走。

两种情境：
- **ambush 狭路相逢**（你 loot>0 且对方 stealBias≥0.45 或 45% 随机）：迎战 / 智谋检定甩开 / 破财消灾(14两)
- **help 江湖奇遇**：帮开石门（身法检定，失败反水抢 35%）/ 冷眼绕过（stealBias≥0.5 可能被尾随抢 25%）/ 趁火打劫（必战）

反水结算：snatchPlayerLoot 抢 25-35% 银两或一件物 → 追（adv_pursue 打赢全数夺回+赏金）或认栽（adv_let_go）。帮成功且未反水：分你 28 两+修为，45% 概率赠其 carry[0]。

## 五、AI 与 UI 层

- `narrateDungeonEvent`（engine/ports）：每过一节把结算日志喂给模型润色一句旁白，纯装饰，无状态权力。
- `DungeonScreen`：本地 run 状态全在本屏 useState，关屏时 `settleDungeonRun` 原子落盘（captureUndo 先快照）。
- 战斗：懒加载 DuelScreen 通用决斗，applyDungeonBattleResult 收尾（win/flee/defeated 三路）。

## 六、与新稿的挂点

- **v5 OC 设定稿**（22人）→ 替换 adventurers.js 池 + 新增 persona/follower/kungfu/shop/stealables 字段。
- **入队稿** → adventurer 节点加「邀请入队/雇佣/好感」分支，入队者从 pickDungeonAdventurer 与 getWorldAdventurers 双池除名。

- **随从** → OC 出战时 follower 作描述层助战；3v3 暂不立项。
- **玩家抢 OC 装备**：stealables.equipment 带品阶走 makeItemSmart，sundries 走 SUNDRIES 无数值。
