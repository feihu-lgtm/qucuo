# 曲措乡·五神兵支线设计

> 五把红字神兵各配一条独立支线，每条支线**激活一处此前闲置的隐藏地点**。
> 本文档是设计存档；游戏侧已实装（`src/quests/qucuoQuests.js` 的 5 个
> `divine_*` 任务 + `items/catalog.js` 的 DIVINE_ARMS 神兵本体）。
>
> **三方对齐**（已校验）：每条支线 → 发放对应神兵（在 catalog）→ 点亮对应
> 隐藏地点 flag（在 innerMap 的 unlockCondition）。

---

**设计原则**：
- 神兵不进公共池/商店/掉落，**只能通过支线获得**（catalog 里 named，非 standardIssue）。
- 每条支线末阶 `onReach.items` 发神兵、`onReach.flags` 点亮隐藏地点 flag。
- 神兵支线全部**深挖三十年前真相**（霜天月=呼延大侠、地藏=桑杰大侠、不动明王杵
  和涅槃引=前任经师、虎啸=无名猎户），是主线终局真相的情感铺垫层。
- 每条留一个 flag 钩子，影响终局对应势力/角色的反应。

## 一、霜天月 → 「霜天问剑」（雪山崖底）

**前置**：完成 he_yuxie_line（虎胆·师母之情）。
**流程**：何雨谢托付 → 顶峰绝顶跳崖（复用外功/内功≥85 门槛）→ 崖底冰壁拔剑触发
呼延大侠残念三问 → 带回交何雨谢。
**神兵**：霜天月（红，forceFirst + freezeEnergyRecovery）。
**钩子**：`huyan_daxia_dying_wish` 影响终局雪山派站队。
**闲置地点激活**：雪山崖底（hushanya_cliff_unlocked，此前只有主线通道，现新增
此探索通道，两条并存不冲突——对应总纲 10.4「雪山崖底两条解锁通道」）。

## 二、地藏 → 「湖底的账」（贡措海密室）

**前置**：完成 mimixianshi_line（线二·秘密现世）。
**流程**：进密室见桑杰大侠枯骨面壁而坐 → 拔刀触发遗念「我本意是撕了这张纸，他
不信」→ 假地契与旧账/税册对比（印章与现任土司印同一枚，坐实三十年连续用假地契）
→ 三选一去向（李若由公开/才旦存档/柳青鸢立案）。
**神兵**：地藏（红，ignoreDefense + justiceStrike 对不义翻倍）。
**钩子**：`sangjie_daxia_wish` 影响终局桑杰朵杰对话分支；三选一各点不同势力 flag。

## 三、不动明王杵 → 「地宫问心」（白塔地宫）

**前置**：无硬前置，但 s1 线索三选一（行脚僧/药堂师父/住持）各有软条件。
**流程**：三渠道之一获地宫线索 → 守塔僧团三场连续切磋（绿→蓝夹击→紫首领）→
经卷三问（为何去贡措海/换你会否去/换你会否开口）→ 取杵。
**神兵**：不动明王杵（红，1.5倍反击 + immuneControl 免控 + 反击回气）。
**钩子**：crypt_q1/q2/q3 三答在住持后续对话被引用。

## 四、虎啸 → 「虎王猎场」（熊山温泉）

**前置**：完成 village5_laolieshu_chuanren（老猎户的传人）。
**流程**：老猎户取出三十年前无名猎户的弓胎（字条「待虎王」）→ 温泉边找到猎户遗骸
和刻石「非不能，是不忍」→ 猎杀吊睛虎王 boss 战（可与虎胆三重门同头虎王共战，
分取牙筋 vs 内脏，两线不冲突）→ 老猎户制弓。
**神兵**：虎啸（红，forceCrit 必暴击1.8 + lowHpBonus 残血增伤 + beastFear 降遇怪率）。
> **注**：beastFear 是战斗外效果（降低野外遇怪率），待接 encounter.js，当前
> 战斗内的 forceCrit/lowHpBonus 已生效。
**钩子**：`huwang_hunted` 影响村民台词。

## 五、涅槃引 → 「香火因缘」（荤食地下室）

**前置**：无硬前置，但 s1 需与喇嘛庙三NPC中至少两个有过深度对话。
**流程**：素斋伙计透露暗门 → 荤食地下室（灶台炖肉，破「和尚不吃肉」的意外场景）
找到香匣 → 开匣可选当场燃香（触发好感最高角色的幻影，AI 依 characterMilestones
关键词说一句符合设定的话，不编造）→ 住持次日大殿点破因缘，二选一存放。
**神兵**：涅槃引（红，selfSacrifice 燃血3.5倍 + rebirthOnce 每场复活一次）。
**钩子**：`xianghuo_yinyuan` 影响住持在终局真相揭露时的情感反应。

## 待接（诚实清单）

1. **beastFear**（虎啸降遇怪率）：战斗外效果，待接 encounter.js。
2. **虎王 boss 战数值**：s3 描述里的虎王专属技能（扑咬/虎啸/垂死反扑）需在
   npcSignatureMoves 或 npcGeneration 里定义虎王这个 NPC 的 moveset，当前只有
   任务文本，boss 本体战斗数据待建。
3. **幻影叙事/三问回答**：靠 AI 依 stage.description + characterMilestones
   关键词生成，flag 已记录，但"幻影说什么"是运行时 AI 生成，非硬编码。
4. **s1 软条件的严格判定**：如"与喇嘛庙三NPC中至少两个深度对话"目前靠 AI 依
   description 把握时机触发 completionFlag，未做硬性系统计数（符合总纲 7.1
   "任务触发靠 AI 判断时机"的既定做法）。
