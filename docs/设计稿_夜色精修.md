# 设计稿·夜色精修

> 本轮界面大改的设计依据。可交互原型见 [夜色精修_界面原型.html](夜色精修_界面原型.html)（浏览器直接打开），GPT 素材提示词见 [美术_夜色素材提示词.md](美术_夜色素材提示词.md)，线描图标在 `src/ui/primitives/iconPaths.js`。

## 一、总纲

主界面拆成明暗两线：明线是少侠亲眼所见的正文，暗线是系统替他记下的账，以批语的形式写在正文页边。好比《红楼梦》的正文与脂批，说书人讲故事，批书人在旁边记恩怨、记谁知道了什么、记这一回合系统怎样定的案。

明线只放故事里看得见、摸得着的东西：说书正文、对话、地名、你的行动、新到的人、地上之物、到手的东西、来信和任务提示。暗线放一切数值和幕后记账：好感增减、心账落条、旧账、事实诞生与知晓者、判官定案、因果授信、体感态势、在场活人切片、队友关系、起居注、日总结、旁白个人线，以及气血、内外功、经验、潜能、银两的变动。

视觉延续“夜色精修”：底色近黑，正文宋体，朱红只给主行动、当前所在和未读。新增一条规矩，**正文用宋体，批语用楷体**，两条线一眼可分，不靠颜色、也不靠边框区分。

界面骨架全部用代码写（CSS 与 SVG），不用位图；GPT 只画代码画不出的五类素材：舆图底卷、地点头图、人物小像、建筑头图、物品类别图。

### 禁用清单

| 不再用 | 理由 | 改成 |
| --- | --- | --- |
| 盖章、落印一类的动画 | 丑 | 地名只做淡入和一条细线展开 |
| 石纹、木纹、纸纹贴图做的按钮和格子 | 与线描风格冲突，显脏 | 平面色块加一像素细线 |
| 一排描边方框按钮 | 像调试工具 | 文字按钮，分组之间用竖细线隔开 |
| 界面里的 emoji（💗 💡 📖 🗒 🛠 等） | 各平台渲染不一，显廉价 | 线描图标（Icon 原语） |
| 绿色系统行、蓝色提示条、粉色旁白同屏 | 强调色各说各话 | 每种颜色只负责一件事 |
| 每段正文外套框，框角再挂一遍时间戳 | 割裂正文，时间戳重复 | 正文不套框，每回合只在分隔行写一次时间 |
| 像素字体做正文 | 中文长文阅读吃力 | 像素字体仅留作设置里的可选项 |
| 渐变、发光、投影 | 与夜色风格冲突 | 只用平面色和细线 |

### 字与线

| 用途 | 字体 | 字号与行距 |
| --- | --- | --- |
| 叙事正文 | 宋体 | 16 至 17 像素，行距 1.95，首行缩进两字 |

### 图标

线描 SVG，24×24 视框，1.5 线宽，颜色跟随文字色，由 `Icon` 原语渲染（`import { Icon } from "src/ui/primitives"`，`<Icon name="根骨" />`）。键名直接取数据值：七维取 SPECIAL_KEYS，武学门类取 SKILL_TYPE（招式、内功、轻功），招式路数取 moveType（攻击、防御、状态、回气、疗伤），修炼阶段取 STAGES（入门、小成、大成、圆满、登峰造极）。每门武学不单独配图标，按路数显示。只有四枚带语义色：已上阵朱红、已成青绿、已错过朱红字、登峰造极金色。

## 四、主屏幕：明暗两线

主屏仍是天地、江湖、侠客三栏，变化在中间：江湖栏左边是正文，右边是一条批语栏，两者按回合对齐。批语栏有合、略、详三档，合上时正文居中。

| 区 | 宽（以 1440 像素计） | 内容 |
| --- | --- | --- |
| 顶栏 | 通栏，50 像素高 | 左：“天都·曲措”、时辰环、第几日、时辰、第几回合、节气。右：入册、图鉴、日志、存档、设置；竖线后夜间、音乐、教程、上报四个图标；再隔开是来信（带未读数）和状态点（已保存、推演中、用时）。回滚挪到江湖栏标题右侧，调试与创造模式收进设置的开发档 |
| 天地栏 | 310 像素 | 此地、周遭两面 |
| 江湖栏·正文 | 约 560 像素 | 只放明线，宋体 |
| 江湖栏·批语 | 约 260 像素，左侧细线 | 只放暗线，楷体 |
| 侠客栏 | 330 像素 | 人物、任务、武学、行囊、羁绊、江湖六面 |

一个回合的正文：分隔行写“第三日　辰正　第五十七回合”并拖一条细线，时间只写这一次；“你”字起头的行动行，可折叠；说书正文，对话里的人名为金色；明线事件排在正文之后，新到之人是人物签，到手之物是得物卡，来信是信笺卡，任务进展是青绿任务提示；接口中断、重试只在回合末尾一行标签色小字里出现。

一个回合的批语：顶端与正文分隔行齐平；每条以两字类名起头，数字增减照色板上色；悬停某条批语时，正文对应回合整段微微提亮。

| 档 | 显示的批语类 |
| --- | --- |
| 合 | 不显示批语栏 |
| 略 | 好感、心账、数值、队友、事实诞生、威望与声誉、起居 |
| 详 | 略批全部，加旧账、知晓者明细、听意、定案、授信、体感、活人、日终总结 |

手机上不分栏：每个回合末尾一行“批 · N”，点开后批语在该回合下方展开，楷体缩进一格；合、略、详放进江湖标题行的菜单。

## 五、日志与卷宗

主栏只写玩家需要读的东西，机器层的东西一律进卷宗。江湖栏只有两档：**正文**读故事，**卷宗**一行一事地查账、查错、看机器明细。合、略、详三档批语等推演快照落地后再接入正文档。

### 主栏八条规矩

| 规矩 | 做法 | 位置 |
| --- | --- | --- |
| 报错一句话 | 接口与系统故障只写「天机不畅（接口额度已尽），本轮未计入。」，带「看卷宗」入口；额度、密钥、地址这类改设置才会好的，再给「接口设置」入口。玩法内的拒止（潜能不足、背包空）不算故障，改成次要色轻提示 | utils/apiErrors.js 的 presentError；ui/components/LogEntry.jsx |
| 同因合并 | 同一原因连续失败只留最后一条，标「×N」；玩家每次的行动行照常保留。中间有回合成功就重新计数 | domain/rules/log/turnErrors.js |
| 重试不进主栏 | 自动重试、截断重说只挂在顶栏状态灯上（turnMonitor.note），成功就消失，全部失败才落一条报错 | engine/runTurn.js |
| 时辰戳只标变化 | 换日或换时辰写全「第3日·辰正　第57回合」；同一时辰（辰初、辰正同属辰时）只写「第58回合」；时间没走不写。现实时间只在悬停提示里 | ui/panels/center/feedModel.js |
| 账目合行 | 同一回合连着的得物、数值、好感、武学行合成一行「账」，不再插在正文之间 | 同上 |
| 回滚连日志一起撤 | 回合失败回滚时，撤掉本回合写进主栏的进房、新人物、半截正文；玩家的行动行、报错、来信保留。此前状态回滚了日志却留着，屏幕上的位置和真实位置错开了二十多回合（FUZZ200 第 57 至 78 回合） | domain/rules/log/rollbackLog.js；engine/playTurn.js |
| 进房描写去重 | 同一间房的固定描写、同一据点的「远处」，再次进房不重印；「来到此处」与「四周」每次都留 | domain/rules/map/mapNarration.js 标 mapNote；feedModel.createMapNoteFilter |
| 连续失败的行动折叠 | 一串没有回音的行动加最后一条系统故障，收成一组：只显示最后一句和「×N」报错，前面的收进「另有 N 句行动未计入」，点开可看 | feedModel.foldFailedRuns |

### 脱敏

上游报错可能带回密钥别名或残片（如「Key=xxx (sk-...)」）。脱敏前移到入口：传输层构造报错时、AI 观测记录失败时、错误分类时都先脱敏，主栏、存档、卷宗、全流程日志、调试包都见不到原文。读档时把旧存档日志里的残片也洗一遍。HTTP 422 等状态码带 budget、exceeded、quota 一类措辞时，按「额度用尽」处理，不再提示检查接口地址。

### 卷宗

| 项 | 规矩 |
| --- | --- |
| 数据 | 主栏日志来自存档；每条日志带 tid（所属回合的追踪编号），按 tid 拼上内存里的全流程追踪。追踪只留最近 40 个前台回合，后台调用另计 40，互不挤占；更早的回合展开时注明「机器明细已过期」 |
| 每回合一块 | 块头写时辰与「你　……」；正文收成一行；账、异常、提示、系统行各自成行 |
| 过滤 | 只有三个：全部、账、异常；另有一个「机器」开关，打开才显示 AI 调用（模型、耗时、用量、成败）与系统步骤（判官、回滚等） |
| 操作 | 鼠标点一行展开详情；键盘 j、k 上下，回车展开 |
| 节点顺序 | 追踪节点按真实发生顺序排列，能看出前哨 → 判官 → 主叙事 → 尾章 → 提交的因果 |

## 六、动效

动效只在发生事情的那一刻出现，平时界面是静的；没有盖章、弹跳和无限循环的闪烁。系统设置了“减少动态效果”时全部关掉。

| 时刻 | 动效 | 时长与缓动 |
| --- | --- | --- |
| 走进新据点 | 地点头图淡入并上移 8 像素；地名随后淡入；地名下细线从左展开 | 头图 600 毫秒，地名延后 200 毫秒，细线 400 毫秒，缓出 |
| 舆图跟随 | 小舆图平移使新的所在点居中；所在点朱红波纹 | 平移 500 毫秒；波纹每 2.6 秒一次 |
| 说书正文流式到达 | 每句从轻微模糊到清晰、从透明到不透明 | 每句 500 毫秒，模糊 4 像素到 0 |
| 批语出现 | 正文写完后，批语逐条从左侧细线处淡入 | 每条 300 毫秒，间隔 120 毫秒 |
| 数值变化 | 批语里的数字从旧值滚到新值，侧栏同步 | 400 毫秒 |
| 好感跨档 | 档名淡出旧档、淡入新档；刻度轴三角滑到新位置 | 档名 300 毫秒，三角 500 毫秒 |
