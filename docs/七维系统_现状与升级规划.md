# 七维系统 · 现状盘点与升级规划

> 目的：①盘清七维（根骨/悟性/体魄/魅力/智谋/身法/气运）现在到底有啥用（不能是摆设，
> 契诃夫之枪）②现有升级途径有哪些 ③规划现有建筑如何承接七维永久升级，使前期全 7-8、
> 中后期全 10 且可溢出（装备加成突破 10）。

---

## 1. 七维现状：各维度现在有啥用（代码实证）

| 维度 | 当前实际作用 | 生效位置 | 摆设程度 |
|---|---|---|---|
| **体魄** | ①战斗伤害力量系数 0.8~1.2（体魄0→0.8，10→1.2）②气血上限的胖瘦浮动（hpFromNeigong 的 base=60+体魄×8） | resolveTurn.js:41、npcGeneration hpFromNeigong | ✅有用 |
| **根骨** | 防御力系数 0.8~1.2（防御类招式生效） | resolveTurn.js:28 | ✅有用 |
| **身法** | 同类型招式对撞的先手判定（速度） | resolveTurn.js:100 | ✅有用 |
| **气运** | ①装备/掉落品质分布（0→10 从全白到均分红）②切磋掉 carry 概率③赌坊输赢④锻造成品品质 | equipment.js qualityDistribution、赌坊、锻造 | ✅有用 |
| **悟性** | 采集类任务成功率（如设陷阱诱捕：悟性+熟练度决定） | qucuoQuests.js:510 | ⚠️用得少（仅个别任务） |
| **智谋** | **几乎没读**——仅装备 sixDim 里作为数值存在，无机制消费 | 无实际读取 | ❌基本摆设 |
| **魅力** | **几乎没读**——衣饰/看戏能加，但只在"AI 叙述引用外貌"这类软效果，无硬机制 | 软效果 | ❌基本摆设 |

**结论**：体魄/根骨/身法/气运 四维已接进战斗与掉落，是硬机制；悟性 只在零星采集任务；
**智谋、魅力 目前基本是摆设**——这违反契诃夫之枪，规划升级途径的同时必须给它们真实用途。

### 1.1 缺口①：智谋、魅力要有真实机制（配合升级才有意义）
- **智谋**：建议接入——说服系统的"识破托儿/看穿谎言"（赌石局中局 attributeCheck 也要用）、
  任务里的谈判/识破陷阱判定、商铺讲价成功率。
- **魅力**：建议接入——说服初始戒心降幅（魅力高，NPC 天然戒心低些）、送礼好感加成、
  跑马会/情感线好感上限或速度、部分 NPC 初见态度。

## 2. 现有七维升级途径（代码实证）

| 途径 | 类型 | 幅度 | 现状 |
|---|---|---|---|
| **食物/服务 buff**（饭馆点菜、看戏、茶馆） | ⏱临时（duration 回合数，过期清除） | +1~+2，持续 20~100 回合 | ✅已通（buffSystem 读写闭环） |
| **战前餐**（pendingCombatBuff） | ⏱一次性（仅当场战斗） | 体魄/外功等 | ✅已通 |
| **装备 sixDim 加成** | 🔁持续（装备着就生效，可突破10） | 各维 ±1~+3 | ✅已通（effectiveSpecial = 基础+装备） |
| **拜佛顿悟**（喇嘛庙大殿） | 🎲永久（概率+1） | 描述称"偶尔顿悟，七维可能增益" | ⚠️需确认是否真发放永久点 |
| **奇遇/渡劫/悟道** | 🎲永久（单次≤1点） | 系统 prompt 允许 AI 改 special | ⚠️靠 AI 自觉，无稳定途径 |

**结论**：**临时途径成熟（食物/装备），但"永久+1"缺稳定的、玩家可主动规划的途径**——
现在只有"拜佛看运气"和"AI 奇遇随缘"，玩家没法有计划地把某一维练到 10。这是规划的核心缺口。

---

## 3. 规划：现有建筑承接七维永久升级（前7-8 → 中后10+溢出）

设计原则（守铁律）：
- **系统裁决数值**：升级点数、成功率、消耗都由代码定，AI 只演叙事。
- **每维一个"主修"建筑 + 通用途径**：让玩家能有计划地专精，也能广撒网。
- **前期便宜快（练到7-8）、后期昂贵慢（冲10）、装备再溢出（10+）**。

### 3.1 各维度 → 主修建筑/途径映射（用现有建筑）

| 维度 | 主修途径（现有建筑改造/接入） | 机制设计 |
|---|---|---|
| **体魄** | 村口大公鸡练级点 / 大草甸历练 / 饭馆硬菜 | 战斗历练累积：每赢 N 场平民切磋，体魄永久+1（递增门槛） |
| **根骨** | 喇嘛庙"打坐修行"/ 温泉 | 花时间（回合）+功德/银两，冥想累积进度条满则+1 |
| **身法** | 后山平台跑马会 / 玉泉寨校场 | 参与跑马/摔跤，名次决定身法进度 |
| **悟性** | 喇嘛庙藏经阁"参悟" / 学武学时 | 读经/参禅累积；学武学到 Lv 里程碑附赠悟性 |
| **智谋** | 天都镇"棋馆/账房" / 赌石识托 | 对弈胜局、识破骗局累积（需先给智谋真机制，见缺口①） |
| **魅力** | 戏楼看戏 / 百花楼 / 衣饰铺 | 看戏累积（现在只临时buff→改成看满N场永久+1）；华服穿戴 |
| **气运** | 喇嘛庙祈福 / 特殊奇遇 | 功德祈福小概率+1；或稀有物品/剧情永久+1（气运最难升，最珍贵） |

### 3.2 升级曲线（前7-8 → 中后10 → 装备溢出）

**基础七维天赋 5（DEFAULT）起步**。目标曲线：
- **前期（1-2据点范围）**：主修途径便宜，任一维练到 **7-8** 不难。门槛递增：5→6 便宜、6→7 中等、7→8 略贵。
- **中期**：8→9 昂贵（需要跨据点资源/较多时间），全维 8 是中期标志。
- **后期**：9→10 最贵（需稀有材料/剧情节点），全 10 是后期成就。
- **溢出**：基础封顶 10，但**装备 sixDim 加成不设上限**（equipment.js:197 已支持突破10），
  所以"全10 + 装备"可达 12-15，中后期靠神兵/宝饰堆溢出。

建议进度门槛（永久+1 所需"进度点"，进度点由对应活动产出）：
```
5→6: 10   6→7: 20   7→8: 40   8→9: 80   9→10: 160   （每级翻倍，10最难）
```
前期活动每次产 2-5 进度点（练到8约需累计70点，前期可达）；后期9→10需160点，逼玩家反复历练或找稀有捷径。

### 3.3 落地优先级
1. **先给智谋/魅力真机制**（缺口①）——否则升它们没意义。
2. **拜佛顿悟改成稳定进度制**（根骨/悟性/气运）——把"看运气"变成"可积累"。
3. **战斗历练接体魄、跑马接身法**——复用大公鸡/跑马会等现有点。
4. **看戏从临时buff升级为"看满N场永久+1魅力"**。
5. 统一一个 `attributeProgress` 状态（各维进度点）+ `gainAttribute(维, 点数)` 系统函数，进快照存档。

### 3.4 待与作者确认
- 智谋/魅力具体接哪些机制（3.1 是建议，需拍板）。
- 升级曲线数值（3.2 的翻倍门槛）是否合适，还是要更快/更慢。
- 气运是否保持"最难升、最珍贵"（它直接影响掉落/赌石，升太快会破坏经济）。
