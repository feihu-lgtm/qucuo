# 天都·曲措 · 任务线导览

> ⚠️ **开发中说明**：任务系统的**框架、节点、判定、结局分支已全部跑通**，
> 但**具体叙事文本尚在打磨**——对话、任务节奏、情感高潮的文字还很粗糙。
> 本文介绍的是**设计蓝图与已实现的任务骨架**，实际体验以游玩为准。
>
> 核心母题：四条剧情线表面互不相干（狼咬死人、旧信曝光、官差寻人、虎胆抵税），
> 但**最终都汇向同一个引力源——鱼定土司府三十年的"合理化"盘剥**。

## 一、四条主线母题

| 线 | 表面事件 | 真正指向 |
|---|---|---|
| **土司杀子** | 银灰独眼狼王之死 | 锦官城借机渗透设税点——不义"顺水推舟"发生 |
| **秘密现世** | 一封旧信曝光 | 伪造地契是三十年盘剥的**制度性根源**——不义的起点 |
| **雪山之劫** | 官差寻人 | 唯一深入雪山派内部秘密的线，独立张力（"喘息线"） |
| **虎胆三重门** | 土司借虎胆抵税 | 管家一句"明年照收"——不义在**日常层面**持续 |

> **设计原则**：土司桑杰朵杰不是脸谱反派，他的不义以"合理化的制度性剥削"呈现
>（税赋、地权、官府渗透）。真正让人愤怒的是管家这类"忠实执行不义"的个体，
> 以及扎西、卓玛这些具体受害者的脸孔。

## 二、虎胆三重门（三线交叉 + 隐藏全收集）

全游戏结构最精巧的一组——**同一件"虎胆"，牵出三位女性、三条并行支线，外加一条隐藏的全收集线**，玩家的选择决定最终结局。

| 支线 | 委托人 | 关系 | 主题 |
|---|---|---|---|
| **师母之情** | 呼延雪（雪山派师母） | 求药引 → 采雪莲 → 情感高潮 | 师徒/师母之情 |
| **牧民之婿** | 卓玛（玉泉寨） | 寻扎西 → 狩猎/疗伤 → 抵税 → 免税 | 牧民疾苦、爱情 |
| **花主之伴** | 兰姐（天都镇欢喜堂） | 阳台相会 → 守宫砂 → 水晶砂 → 仪式 | 花主的过往与羁绊 |
| **全收集（隐藏）** | 无委托人 | 集齐三线关键物 → 最终抉择 | 隐藏结局分支 |

三条线可以分别推进，也可以走隐藏的"全收集"路线触发特殊结局。这是**多结局判定系统**最集中的体现。

## 三、村线：界石下的旧账

鱼定村的六段递进支线，从"路见不平"到"界石重立"，一步步揭开地契伪造的旧账——**秘密现世母题的落地**。

`村1·路见不平` → `村2·界石下的旧账` → `村3·藏汉两姓的婚事` → `村4·杂货商人的进货难` → `村5·老猎户的传人` → `村6·界石重立`

新手友好的入门线，穿插熊山除患（老猎户的学武任务）等独立小任务。

## 四、山线：狼曲与黑风寨

从狼曲遇匪开始，一路追查到隐藏据点黑风寨，收束于"狼烟旧账"——**雪山之劫母题**。

`山1·狼曲遇匪` → `山2·妹妹的消息`（获"半块银锁片"）→ `山3·上山`（凭银锁片由少年引路进黑风寨）→ `山3.5·劫药` → `山4·管家的通缉令` → `山5·狼烟旧账`（收束）

> 黑风寨是**隐藏据点**：不完成山线就进不去。寨内不见杀气，倒像寻常村子——
> 老人晒药、妇人纳鞋底，只有岩壁上的寨规提醒这里的来历。

## 五、欢喜教线

天都镇欢喜堂展开的一条长线（10+ 节点），从"香中异"入教，层层深入到与土司府/锦官城暗线的对决。

`香中异` → `比武招贤` → 深入了解五连（采买香料 · 跑马会邀请 · 供养仪式 · 药钵边的故事 · 弟子的过去）→ `管家的探子` → `锦官城的暗线` → `管家的突袭` → `决战前夜`

与花主兰姐的羁绊线（虎胆三重门·花主之伴）交织。

---

## 六、锦官城官线：凤隐于青

关系全乡与外界势力博弈的一条线，带**分支抉择**。

`官1·凤隐于青（信任积累）` → `官2·归途` → 二选一分支：
- **官2-A·投靠·还恩** —— 倒向锦官城
- **官2-B·中立·压制** —— 保持独立

选择影响终局七方势力的格局。

## 七、玉泉寨爱情线

玉泉寨牧民聚落的五段线，从帮小牧童找牦牛的日常，一路走到贡措海圣湖畔的爱情高潮。

`小牧童的牦牛` → `李若由的商队账` → `丹增的马鞭` → `卓玛的青稞酒`（爱情线前置）→ `贡措海的约定`（爱情线高潮）

卓玛是可攻略角色，也是"牧民之婿"支线里扎西的关系人——两条线互有牵连。

## 八、五神兵支线

散落全乡的五件神兵，各有一段独立获取任务，串起不同据点的隐藏往事。

`霜天问剑`（雪山）· `湖底的账`（贡措海）· `地宫问心`（白塔地宫）· `虎王猎场`（熊山）· `香火因缘`（喇嘛庙）

## 九、可攻略角色与好感度

六位核心角色各有**完整人设 + 30/60 好感度里程碑**档案。好感度系统的独特之处：

> **好感度只调整"叙事文风的亲近度"，不改变人物性格或剧情走向。**
> 说书人是全知的单一叙述者——好感低时叙述严格公式化，好感高时连日常叙事里
> 都会渗透情绪。好感满 100 触发特殊里程碑。

| 角色 | 所在 | 关联主线 |
|---|---|---|
| 梅朵 | 鱼定土司府 | 土司之女，父女道德对照组 |
| 呼延雪 | 雪山派 | 师母之情（虎胆三重门） |
| 卓玛 | 玉泉寨 | 玉泉寨爱情线 + 牧民之婿 |
| 兰姐 | 天都镇欢喜堂 | 花主之伴 + 欢喜教线 |
| 才旦 | 鱼定村 | 村线相关 |
| （第六位见游戏内） | — | — |

> **特别彩蛋**：游戏里还有一个"旁白"角色——她全程知晓世界里发生的一切。
> 与她私聊、告白之后会发生什么……玩到后面自己发现 🤫
