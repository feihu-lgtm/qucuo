## 二、血刀门（大草甸·敌方·邪恶门派）

**定位**：邪派，以杀养刀，以血淬刃。不是门派——是一群疯子。没有山门，没有规矩，只有一条：刀见血才能收。盘踞在大草甸深处一处废弃的猎户营地，周围三里寸草不生，土是红的。

**位置**：大草甸内层新增房间「血刀营地」，从草甸深处往西。

**内层房间**：
| 房间 | exits | 备注 |
|------|-------|------|
| 血刀营地 | e:草甸深处 | 无锁，但进去就触发敌对遭遇 |

**房间描述**：
```
desc: "草甸深处往西三里，土色忽然变了——不是黑土，是红的，像被血浸透了又晒干，反复浸反复晒。废弃的猎户营地改成了屠宰场，木桩上挂着风干的肉条，分不清是兽是别的什么。地上插着十几把刀，每把刀柄上都缠着发黑的布条——那是血干了之后的颜色。空气里铁锈味重得呛人。"
```

**NPC（全部敌对）**：

- 血刀门徒×3（蓝档）：没有名字，只有编号。初七、十三、廿三。

## 六、吸血特效（饮血狂刀 + 血刀大法）

**effect 字段**：`{ lifesteal: 0.25 }`

**结算逻辑**（combat/dealDamage 后追加）：
```
if (attackerWeapon.effect?.lifesteal || moveSkill.effect?.lifesteal) {
  const ratio = attackerWeapon.effect?.lifesteal || moveSkill.effect?.lifesteal;
  const heal = Math.round(actualDamage * ratio);
  attacker.hp[0] = Math.min(attacker.hp[1], attacker.hp[0] + heal);
  // 叙事追加：「刀身嗡鸣，血色沿刃回流——你面色红润了几分。」
}
```

**数值**：
- 饮血狂刀：lifesteal 0.25（25%伤害转回血）
- 血刀大法（习得后作为招式）：lifesteal 0.15（15%，比刀低，因为不挑武器）
- 两者叠加时取高不叠加（0.25），防止无限回血
