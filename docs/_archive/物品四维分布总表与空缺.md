# 曲措乡·物品分布总表 + 空缺（按流通性质分类，落到具体品名/据点/店铺）

> 口径：当前 catalog 全 **263 件**（含新录 100 件食品药品）。逐件读 desc 判定后分三类流通性质。
> 关键修正：**不是所有物品都能当商品卖**。带具体人名的私人信物、遗物、定情物、任务凭证，
