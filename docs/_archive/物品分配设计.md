# 曲措乡·物品分配设计（NPC携带 + 商店铺货）

> 目标：让140件物品库真正"活"在世界里——具名物归具名人，其余NPC和商店
> 从**公共池**按"地域 + 身份 + 品阶"抽取，做到锦官城和村子货色不同、
> 镖师和乞丐身上不同、低阶点和高阶点档次不同。
>
> 本文档只梳理**设计思路**，不含代码。确认逻辑后再实现。

---

## 一、现状（为什么要改）

| 系统 | 现状 | 问题 |
|---|---|---|
| 商店 | `QUCUO_SHOPS[shopKey].items` 每店手写死物名+品质 | 跟140物品库完全脱节；改货要逐店手改；没有随机性/刷新 |
| NPC掉落 | `CARRIED_ITEM_POOL[品质]` 一个全局池按品质随机 | 不分NPC身份、不分地域；乞丐和镖师掉一样的东西 |
| 具名物 | 已通过 `makeItemSmart` 支持，但没人"发"给谁 | 具名物躺在库里，NPC/商店都不会自动带出 |

改造核心：**引入"标签化公共池 + 按上下文抽取"机制**，替代两处的硬编码/无差别随机。

---

## 二、总设计：三条分配轨道

物品进入世界有三条独立轨道，各管一摊，互不打架：

```
① 具名轨道（点对点，最高优先）
   具名NPC ←→ 指定具名物
   例：柳青鸢带青鸢/青鸢尾、巴桑带断念、老猎户带熊山猎刀
   数据源：residentNpcs.js 的 carry 字段（已存在）+ 本次补全
   规则：谁带什么写死，打死掉什么、能偷什么都是它

② 公共池轨道（随机抽取，覆盖绝大多数）
   杂鱼NPC / 商店 ← 按【地域+身份/店型+品阶】过滤公共池 → 随机抽
   数据源：140物品库 catalog.js（含标签）+ 公式匿名兜底
   规则：本文档重点，见第三、四节

③ 剧情轨道（任务发放，硬指定）
   任务奖励 / 关键道具 ← 任务数据直接指定具名物
   例：村3婚事给"红线"、村6给"界石下的土"、半块银锁片
   数据源：qucuoQuests.js 的 rewards（已存在）
   规则：不走随机，任务给什么就是什么
```

**优先级**：具名 > 剧情 > 公共池。一个NPC若在①里有指定carry，就不走公共池。

## 三、公共池怎么建：给物品打"分配标签"

140件已有的 `tags`（杂货用）和分类/品质不够用于分配，需要**补一层分配元数据**。
不改物品本身的数值/特效，只加"这件东西属于哪些地域/身份/店型"的归属标签。

### 3.1 三个分配维度

**维度A·地域（region）**——决定"在哪买得到/谁身上有"
```
村镇     鱼定村、玉泉寨（藏地牧区风味：皮具、猎具、糌粑、藏银）
市镇     天都镇（三教九流：铁器、药、市井杂货、地下秩序货）
官城     锦官城（最丰富最高档：官造、精铁、绸缎、成套制式）
宗教     喇嘛庙、白塔（法器、念珠、药材、经卷）
门派     雪山派（门派制式剑、御寒裘、练功服）
山野     黑风寨、大草甸、熊山（匪货、兽材、猎具、缴获品）
```
一件物品可属于多个地域（如"精铁短刀"村镇+市镇+官城都有），也可以是
某地独有（如"欢喜堂持斋牌"只在天都镇）。

**维度B·身份/店型（role / shopType）**——决定"什么人/什么店有"
```
NPC身份：
  平民      牧民、村民、脚夫、小贩（白绿档日用/杂货，几乎无武器）
  武人      镖师、护院、巡捕、山贼、门派弟子（绿蓝档武器护甲为主）
  高手      门主、护卫头子、长老、教主（紫橙档，可能带具名物）
  宗教      僧人、朝圣者（法器、念珠、袈裟）
  官吏      差役、都事随从（制式官造、腰牌）
  江湖闲杂   说书人、乞丐、艺人（白档杂物、无战力物）

店型：
  杂货铺    白绿档 日用+杂货+低阶护身
  武器铺/铁铺 绿蓝档 武器护甲为主（孟记铁铺、铸剑坊）
  药堂      药材食品（misc，疗伤类）
  当铺/古玩  杂项+饰品，偶有高阶（玉器轩、聚宝当铺）
  门派商坊   门派制式货（雪山派商坊）
  成衣/绸缎  护甲/衣物（云锦成衣、绸衣）
  钱庄/官市  高档，验货类
```

**维度C·品阶权重（tierWeight）**——决定"档次高低"
不是硬性只出某档，而是给每个"地域×身份"一套品阶概率分布：
```
低阶点（村口杂货铺、乞丐）：白60% 绿30% 蓝10% 紫0 橙0 红0
中阶点（天都铁铺、镖师）：  白20% 绿40% 蓝30% 紫10% 橙0 红0
高阶点（锦官官市、门主）：  白5% 绿20% 蓝35% 紫30% 橙8% 红2%
```
这样"锦官城偶尔能淘到紫橙好货，村口基本只有白绿"自然成立。

### 3.2 标签存哪

不污染物品数值定义，单独建一张**分配表** `src/items/distribution.js`：
```js
// 物品名 → 分配归属（只管"谁能拿到"，不管数值）
export const ITEM_DISTRIBUTION = {
  "熊山猎刀":   { regions:["村镇","山野"], roles:["平民","武人"], shopTypes:["杂货铺","武器铺"] },
  "锦官坊标兵剑": { regions:["官城"],       roles:["官吏","武人"], shopTypes:["武器铺","官市"] },
  "欢喜堂持斋牌": { regions:["市镇"],       roles:["宗教"],        shopTypes:["当铺"] },
  // …具名物一般不进公共池（走具名轨道），但"制式通货"必进
};
```
> 制式30件是公共池的**主力**（本就是"量产通货"）；百物录里的非剧情向普通物
> （如"熊山猎刀""大草甸套索"这类人手一把的）也可以进池；真正独一份的
> 具名宝器（断念、青鸢、月照…）**不进公共池**，只走具名/剧情轨道。

## 四、抽取逻辑：给定上下文，抽出货单

### 4.1 商店铺货 `rollShopStock(shopKey)`

```
输入：shopKey（对应某店，带 region + shopType + tierProfile）
过程：
  1. filterCatalog + ITEM_DISTRIBUTION 过滤出"这个 region×shopType 能卖的候选"
  2. 按该店 tierProfile（品阶概率）滚动决定每件出不出、什么档
  3. fixed（招牌必出，如药堂必有止血散）+ floating（概率出摊，读各自 chance）
  4. 生成 N 件（店越大 N 越多）
输出：货单（具名物走 makeItemSmart 吃专属值，其余走公式）
```
> 顺带修交接任务7的 bug：现有 `rollShopInventory` 的 floating 概率写死0.5、
> 没读各件 chance——新逻辑直接按各自 chance 掷骰。

### 4.2 NPC携带 `rollNpcCarry(npc)`

```
输入：npc（带 role + 当前 region + levelCap）
过程：
  1. 若 npc 有具名 carry（residentNpcs）→ 直接用，不走公共池（具名轨道优先）
  2. 否则：按 role 决定携带风格（平民少而杂、武人带兵器、高手带好货）
  3. 按 region 过滤候选池
  4. 按 levelCap 映射品阶权重（高阶NPC能带紫橙）
  5. 抽 1~N 件（role/levelCap 决定数量）
输出：carriedItems（打死掉落/可偷）
```

### 4.3 地域怎么传进来

NPC 当前所在 region、商店所属 region，都能从 `qucuoMap`/`innerMap` 的
据点归属反查（据点→region 的映射表，一次性建好）。游走NPC按当前落脚据点算。

## 六、实现分步（确认思路后再做）

1. **建 region 映射**：据点→region（村镇/市镇/官城/宗教/门派/山野）
2. **建 distribution.js**：给制式30 + 百物录里的通货物打 region/role/shopType 标签
3. **建 tierProfile**：低/中/高阶点的品阶概率分布表
4. **写 rollShopStock**：替换 `qucuoShops.js` 的硬编码 + 修 floating chance bug
5. **写 rollNpcCarry**：替换 `CARRIED_ITEM_POOL` 全局随机，接进 `ensureNpcCombatData`
6. **具名NPC补 carry**：residentNpcs 里给该带具名物的NPC写上（柳青鸢青鸢等）
7. **验证**：同一件"精铁短刀"在村铺和官市都能出但档次分布不同；乞丐和镖师掉的东西不同

## 七、几个要奶奶拍板的点

1. **具名宝器进不进公共池？** 我倾向：独一份的（断念/青鸢/月照…）**不进**，
   只走具名+剧情；人手一把的通货型具名物（熊山猎刀/大草甸套索）**可进**。对吗？
2. **商店要不要"刷新"？** 每次进店重滚 floating，还是固定一批不变？
   （现有 `rollShopInventory` 是每次重滚，倾向保留）
3. **NPC掉落 vs 携带**：打死掉的和能偷的是同一批（现有逻辑），保持？
4. **品阶权重具体数值**：上面第3.1的百分比是我拍的草案，要不要按你的手感调？
5. **地域粒度**：用我列的6类region够不够，还是要细到"每个据点一套"？
