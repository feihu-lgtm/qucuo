### ✅ 第 1 步已完成：DuelScreen 战斗内道具栏
- select 阶段新增"⊙ 用道具"入口，展开列出背包里**战斗内可用**的消耗品（只列 A 档
  即时效果：hpRestore/energyRestore/dispel/rebirthOnce；B 档故意不列）。
- **实现模型**：服药 = 消耗玩家本回合行动。`handleUseItem` 把药的即时效果构造成一个
  临时"疗伤型"状态招（type=STATUS、energyCost=0、带 hpRestore/energyRestore/
  dispelSelf），交给 `handleSelectMove(pseudoMove, consumedItem)` 走**完全相同**的
  回合结算——服药这回合玩家不攻击、NPC 照常出招、净值决定续航。零新增特殊分支。
- 假死保命（rebirthOnce）用独立 ref 记本场续命一次，与装备版涅槃引各自独立可叠一层。
- `onFinish` 新增第五参 `usedItems`，MudRPG 接收后从 `inv` 按名逐件扣除（无论胜负都扣）。

### ✅ 第 2 步已完成：探索态"用物品"总闸
- `catalog.js` 新增 **`useConsumable(consumable, char)` 纯函数**（AI 不参与，数值算死）。
  探索态与战斗态能力边界：
  - `hpRestore`（比例回血）→ 探索态主力效果，按最大气血比例回、夹上限，血满则拒绝服用。
  - `energyRestore`（回气）→ 真气是纯战斗内概念（每场重置的 [10,10]），探索态**无对应
    持久字段**，故不生效，提示"须在切磋中服用"。
  - `dispel`/`rebirthOnce` → 解异常、假死同样是战斗内机制，探索态引导去战斗中用。
  - `sixDimTemp`/`hpRestoreOverTime`/`combatBuff`（B档）→ 返回 ok:false 提示"待实装"，
    **第 3 步接 buffSystem 时才处理**。
  - 返回 `{ ok, hpDelta, note, reason }`。
- `MudRPG.jsx` 在 localCmd 之后拦截**"用/服/吃/喝/嗑 <物品名>"**命令：背包里精确匹配到
  一件消耗品才处理（对象型物品带 consumable，字符串型用 CATALOG_INDEX 按名兜底），
  调 useConsumable → 应用 hpDelta（setChar 改血）→ 扣背包一件 → 推进一回合。没匹配到
  背包内消耗品的（如"吃饭""用剑劈他"）一律放行给 AI 叙事，不误伤。帮助文本已补一行。
- useConsumable 九种分支已单测通过（回血/血满拒绝/复合药/纯回气引导/假死/解异常/
  B档待实装/空物/超上限截断）。esbuild 打包校验通过。

### ✅ 第 3 步已完成：接 buffSystem（B档临时增益）
- **关键发现**：buffSystem 此前是"只写不读"的死 buff——`handleServiceOrder`（饭馆点菜）
  早已用 makeBuffFlag 把 buff flag 写进 flags（且已用 time 计时），但 `parseActiveBuffs`
  全项目零调用，读取端从未接通，所以 buff 挂了不生效。第 3 步补的正是**读取/应用端**。
- **探索态读取端**：MudRPG 里 `effectiveSpecialNow = applyBuffsToSpecial(char.special,
  flags, time)`（char/flags/time 任一变即重算）。状态面板显示"基础→有效"及每条 buff
  剩余回合数。计时基准一律 `time`。
- **过期清理**：监听 time 的 useEffect 里每回合 `cleanExpiredBuffs`，只清 buff_ 开头的
  flag、剧情 flag 原样保留，且仅在确有过期项时才 setFlags。
- **战斗态**：DuelScreen 的 `playerChar` 现在收到的是 `{...char, special:
  effectiveSpecialNow}`，七维 buff 战斗中自动生效。
- **战前餐 pendingCombatBuff**：DuelScreen 进场用 `resolveCombatBuff` 应用——起手气血
  按 hpBonusRatio 抬高本场上限（不是叠满血被夹回）、起手真气 +energyBonus、外功
  +waigong（当临时外功点数叠进 atkFromWaigong）、攻击招式倍率 +moveMul。第1回合顶部
  显示药力提示。战斗结束（onFinish）无论胜负清除 pendingCombatBuff（一次性）。
- **探索态吃 B 档药**：useConsumable 补齐 sixDimTemp（写 buff flag，默认持续 30 时辰
  单位）、combatBuff（存 pendingCombatBuff，mergeCombatBuff 可叠多份）、hpRestoreOverTime
  （探索态无逐回合结算，**降级为即时回一笔** = ratio×turns）。MudRPG 用药块对应
  应用 res.sixDimBuffs / res.combatBuff。
- buffSystem 读写闭环 + B/C 档 useConsumable 已单测通过。
