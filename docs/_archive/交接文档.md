## 二、待办任务 + 解决措施

### 任务1：拜师接 AI 主叙事（重做假成功）
- **现状**：`handleNpcLearnSkill`(~2196) 结算后用写死文案，依赖数组 `[varTree, flags, addLog]`。
- **措施**：结算（去重、`setChar` 加招、打 `learnedFromMaster`）后，改为调 `act(\`拜${npc.name}为师，${npc.name}将平生所学「${moveBrief}」倾囊相授，我凝神习得\`)`（`moveBrief`=招名+原型）；删掉写死的 desc 文案；保留"（习得N招…）"sys 硬确认；依赖数组补 `char, act`。`act` 定义在 line~123，作用域可用。参照 `handleBuySkill`（买秘籍习得武功）的现成范式——它就是"setChar 结算 + act 陈述"。

### 任务2：maxTokens 保底（重做假成功）
- **位置**：`presetSystem.js` line~137。
- **措施**：`if (preset.maxTokens != null) overrides.maxTokens = Math.max(preset.maxTokens, apiCfg.maxTokens || 4096);`
  理由：酒馆预设 openai_max_tokens 若设得很小会顶穿本地字数换算上限（含4096地板），导致主叙事被 length 截断。取较大值保底。

### 任务3：调试面板加外功/内功（重做假成功）
- **位置**：`MudRPG.jsx` 调试面板金钱那个 `<div>`(~2946)。
- **措施**：在金钱 input 后加两个 input，`char.waigong`/`char.neigong`，onChange `setChar(c=>({...c, waigong: parseInt(e.target.value)||0}))`（内功同理）。样式抄金钱 input。

## 三、关键架构约定（改动时务必遵守）
- **"AI 提议内容，系统裁决数值/拓扑"**：AI 绝不直接改状态；所有机制结算走确定性代码。
- 战斗：`resolveTurn` 吐跨回合字段 → `DuelScreen` 存进下一回合 side。NPC 专属招只挂 `{archetype, name, desc}`，特效由 `moveArchetypes.js` 原型×levelCap 自动算（不逐个手写）。
- 地图：`QUCUO_MAP`(14大地点) + `innerMap.js` INNER_MAP(小地点)，两套 key 一致。
- 好感度存 `varTree.角色.{名}.好感度`，认识的人存 `varTree.世界.已认识人物`。
