## 与参考项目的差异（一句话）

参考项目是 SillyTavern 取向的多页面独立前端（`index.html` + 一堆 `module/*.js`），我们是**单页 React + Vite**、
逻辑集中在 `MudRPG.jsx` 一个主组件里，按领域拆成上面这些模块。两边**记忆召回**思路同源
（我们的 `memory/recallEngine.js` 就是照它家 `memory-recall.js` 写的），但我们**尚无**它那套
**滚动摘要 / 周总结**（`summary-*`）与 **IndexedDB 存档**（`idb-snapshot`）——这正是接下来最值得借鉴的两块。
