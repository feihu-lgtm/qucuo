# 源码文件树

当前 `src/` 下共 491 个 js/jsx 文件。

## 依赖规则

`ui → app → features/engine → domain/core/utils`。
`infra` 仅通过 `app/ports` 接入；本次只记录现状，不新增规则检查或强制执行。

## 依赖边界现状

旧版审计曾记录 **169** 条跨层依赖和 **53** 条 infra 外部导入；仓库中没有找到生成这两个数字的可复用计数器。当前可执行基线、统计口径与守卫规则见[护栏说明](./护栏.md)。

完整旧路径→新路径映射见 [`file-tree-moves.json`](./file-tree-moves.json)。

核心字段的写入方、读取方与 MVU 权限见[核心字段表](./核心字段表.md)。
