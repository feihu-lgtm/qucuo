# 路遇随机事件设计（400 件）

## 一、要解决的问题

现有路上的随机性只有三套：势力过路人（`rules/map/encounter.js`）、势力伏击（`rules/map/ambush.js`）和势力张力（`rules/conflict/tension.js`）。过路人是唯一的高频事件，形态单一：撞见一个扛旗的人、可能捎一句传闻。路上没有天灾、商队、求救、比武、奇遇，也没有能带走的美人、同伴、兵刃和武学。

本设计新增 20 类、每类 20 件、共 400 件路遇事件，全部建在现有接口上：判官事实码、天机券编译器、邀同行、势力声誉、传闻人物。

## 二、做法：系统骨架 + 说书人填空

与判官链同一个分工。

| 环节 | 谁定 | 内容 |
| --- | --- | --- |
| 触发与抽取 | 系统 | 地头（节点名或地形标签）、时辰、交情门槛、传闻是否在册、冷却、稀有度 |
| 来人 | 系统 | 一律从现有池子取：同伴与美人从游走冒险者里抽，普通来人身份由事件定、姓名由过路人姓名库生成，传闻回收从传闻册取 |
| 三个可行之事 | 系统 | 主行动（检定六维与难度）、次行动（类别给定的稳妥做法）、离开 |
| 成败与得失 | 系统 | 掷检定，奖励码解析成事实 |
| 场面与人物 | 说书人 | 照「路遇铁律 + 类别提示词 + 事件情节核 + 已定事实」写戏 |
| 兵刃、武学的名字 | 说书人 | 在尾章 SEAL 填空，由 `compileEmergentItem`、`compileEmergentSkill` 编译成真东西 |

一次路遇分两段：

1. **照面**：进入节点时抽中事件，`buildRoadEventNote` 让说书人写出处境，停在抉择之前，列出三个可行之事。
2. **结算**：玩家选定后，`resolveRoadEvent` 掷检定并产出事实，`buildResolutionNote` 让说书人照已定事实写结果，并给待命名之物起名。

## 六、人物从现有池子取

事件只写处境，人由池子出，不新造具名人物。

| 来人类型 | 件数 | 来源 |
| --- | --- | --- |
| 人物槽（同伴、美人） | 47 | 游走冒险者（79 位，均有立绘、武学、随从，走现成招募链路） |
| 身份来人 | 215 | 身份由事件定，姓名性格由过路人姓名库生成，沿用防撞名守卫；编队停在本节点且角色对得上时，取编队的势力 |
| 传闻人物 | 12 | 传闻册 |
| 无固定来人 | 126 | 古迹、天象、野兽等 |

人物槽的规则：
- 只抽未入队、性别与就近势力符合、游走范围包含本节点的冒险者；游走册显示此刻就在本节点的人，权重乘 5。
- 抽中后结算时同步游走册位置（`rosterSync`），同一个人不会两处现身；没被邀走的人留在游走册里，日后还能重逢。
- 池子里没有合适的人，这件事就不触发。
- **美人槽只取成年的人。** 冒险者档案没有年龄字段，按游戏自己的标记判断：只取带 `intimacy` 设定且未 `forbidden` 的人，并排除生平里出现未满十八岁字样的人，测试钉住。目前符合的有 9 位，游走范围集中在天都镇、锦官城、雾隐寨、鱼定村、玉泉寨、广汉一带，喇嘛庙、白塔、打箭炉、丹霞城、雅江、天龙营一位也没有。要让美人事件在更多地方出现，需要给更多冒险者补亲密设定或放宽游走范围，这是内容决定。

## 八、触发与平衡

- **触发**：沿用 `rollEncounter` 的节点触发率。命中后 60% 换成本表事件（`ROAD_EVENT_SHARE`），40% 仍是原来的势力过路人。势力伏击优先级不变。
- **抽取权重**：稀有度 1/2/3 的权重为 10/4/1；气运每高于 5 一点，稀有度 3 的权重加 10%。
- **冷却**：同一件事十日内不重复，同一类事一日内不重复。
- **只遇一次**：主行动奖励含永久六维、武学、同伴、美人、兽伴的事件自动只遇一次，测试钉住。已在队里的同名人物不会再遇。
- **门槛**：用活世界蓝图的谓词格式写。S 类只在与相应势力交恶（声誉低于 -10 或 -20）时出现，与不共戴天档的伏击（-60 以下）错开；T 类只在 `varTree.世界.传闻人物` 非空时出现，来人从传闻里指定。
- **覆盖**：每个地图节点白天至少有 25 件可抽，测试钉住。

不自建账本：只遇一次记在 `flags`（`road_once_<编号>`），冷却从 `varTree.世界.事件录` 里的路遇条目推算。

路遇是蓝图插头 1 的消费方：读活世界的投影，写回活世界能消费的东西，不自建平行账本。现阶段已与 `WO-25C`（#688 五表注册校验）、`WO-25D`（#693 `evalWorld` 谓词口径）以及 `#691`（人物四元生活状态 `人物动态`）对齐：

| 方向 | 内容 |
| --- | --- |

| 读·局势卡 | 类别对局势卡有权重倍数：伤药紧俏多求救与毒症，茶马云集多商队与市井，山道封锁多敲诈、少商队，江湖戒严多官差与摩擦，香客盈门多朝圣 |
| 读·编队 | 离线编队停在本节点、角色对得上（商队、巡哨、游骑、朝圣、门派弟子）时，该类事件权重翻倍，来人取编队势力 |
| 读·人物动态 | 游走冒险者照面时若 `varTree.世界.人物动态[name]` 已有生活状态（伤势、银囊、心境，见 `#691`），自动带入 `lifeHint` 供说书人接戏 |
| 写·张力 | 势力摩擦类按选择改两家张力：调停成功 -10，失败或暗中相助 +8（`tension.js` 由此有了写入方） |

| 写·游走册 | 冒险者来人同步位置，与 #685 的驻足锁规则一致 |
