## 一、核心母题与势力分布

### 1.1 核心母题

四条剧情线表面上是互不相干的恩怨（狼咬死人、旧信曝光、官差寻人、虎胆抢手），
但最终都汇向同一个引力源：**桑杰朵杰治下土司府的不义，是怎样用"看似合理"
的方式盘剥曲措乡三十年的**。

- **线一（土司杀子）**：桑杰朵杰借银灰独眼狼王之死，让锦官城看到渗透（设收税点）的机会——不义以"顺水推舟"的方式发生。
- **线二（秘密现世）**：伪造地契是土司府三十年盘剥的**制度性根源**——不义的起点。
- **线四（虎胆三重门）**：土司借虎胆抵税，管家一句"明年照收"——不义在**日常层面**持续发生，牧民永远还不完。

第三条支线（雪山之劫）是唯一不直接涉及土司府、而是深入雪山派内部秘密的线，
起到"喘息"和"另开一条完全独立张力"的作用，避免玩家觉得所有线都在重复同一个反派。

**设计原则**：桑杰朵杰本人不需要、也不应该被写成脸谱化反派——"父女道德对照组"
这条设定必须保留。他的不义应该始终以"合理化的制度性剥削"呈现（税赋、地权、
官府渗透），而不是搞破坏式的纯粹恶。真正让玩家共情愤怒的应该是管家这类
"忠实执行不义制度"的具体个体，以及扎西、卓玛这类具体受害者的脸孔。

跑马大会作为周期性事件，进一步延展了这个母题：这是桑杰朵杰唯一一次
"扮演明君"的年度表演，他既要向锦官城展示"治理有方"（维持渗透谈判的筹码），
又要向百姓展示宽容大度（维系统治合法性）。**大会的热闹程度本身就是一面
测量土司权力盛衰的仪表盘**——子夜之变若处理失当，就是权威流失的具体量化锚点。

> 第七方势力，见本节表格及终局机制的对应修正）。注意鱼定村（村民/村长/
> 才旦这一系）跟"鱼定土司府"（桑杰朵杰）是两个完全独立的势力，只是共用
> 同一个地理据点——前者是被治理的普通百姓，后者是治理者本身，二者立场

### 1.3 鱼定土司府：实力构成（补强，此前完全空白）

> 此前文档里桑杰朵杰和管家是仅有的两个具名人物，土司府作为终局对抗的
> 最终目标，却完全没有任何具体的军事/经济规模数据——跟已经写得很具体
> 的黑风寨（四十余人+寨规）、欢喜教（内院外院中院+确切人数）相比明显
> 失衡。本节补齐这个缺口，并新增一个**护卫头子**角色，与管家形成"文武
> 分工"：管家管钱粮税赋、日常盘剥这类"文"的事，护卫头子管武装、终局
> 对抗这类"武"的事，避免管家一人又管钱又管兵、权力过于集中不合理。

#### 经济基础

- **草场与牧场**：土司府名下直辖草场若干处，分布在大草甸周边与狼曲
  上游（与黑风寨活动范围部分重叠，这也是土司府一直想彻底清剿黑风寨
  却始终没能得手的现实原因之一——黑风寨占据的山头本就在土司府势力
  边缘地带，官军进剿要跨过不完全属于自己的地界，师出无名又劳师动众）
- **田地**：鱼定村及周边台地的部分农田由土司府直接收租，是"合法税赋"
  之外的另一块直接收入
- **牲畜**：土司府自有牦牛、绵羊等牲畜约数百头，由专门的牧户代为
  放养，每年秋后统一收拢入库或售卖——这批牲畜的规模和"管家借虎胆
  抵税"这类具体盘剥手段放在一起看，能让玩家直观感受到土司府的经济
  体量远超玉泉寨、鱼定村这些普通百姓能想象的程度

#### 武装力量

- **骑手·三十人规制**：土司府豢养约三十名骑手，日常用途是护送税粮、
  巡视草场牧场边界、必要时充当仪仗（比如跑马大会开场的土司府方阵）。
  战力介于普通民壮和正规军之间，装备统一，是桑杰朵杰"面子工程"的
  重要组成部分——跑马大会上土司府骑手方阵的排场，直接呼应第四章
  "大会热闹程度=土司权威仪表盘"这个核心设计
- **巡捕营·约二十人规制**：更接近正规武装的常备兵力，负责府内值守、
  缉拿要犯（此前已有的"土司府巡捕营"设定，如管家手下、冒充雪山派
  弟子用的擒拿手，均出自这支力量）。二十人规模不算庞大，但训练和
  装备优于骑手，是终局对抗时玩家真正需要认真对待的战斗力量
- **管家的私人手下**：不计入上述两支正式编制，是管家自己招揽、只
  听命于他个人的一小撮人（此前文档里多次出现的"管家的手下""管家
  安插的眼线"均属此列），人数不多但做事不择手段，是管家个人恶意的
  直接延伸，跟骑手/巡捕营这两支"土司府正规军"性质不同

#### 土司桑杰朵杰：深藏不露的真实实力（本轮修正设定）

**旧设定作废说明**：此前版本反复出现"土司本人战力不高"这一表述，
本轮予以修正——桑杰朵杰的真实武学传承自其父**桑杰大侠**（现任土司
之名正是当年老土司留给儿子的烙印，见第二章"三十年前死斗"真相全文），
当年桑杰大侠是治乡宽厚、人人称颂的真正高手，这份真本事传给了儿子。

桑杰朵杰继位后，对外始终维持"我战力不高、事事仰仗护卫头子"的姿态，
这是刻意为之的烟幕，不是谦虚也不是退步——一个真正深藏不露的人，
表面上的温和随和跟骨子里的自我合理化习惯，恰好是同一层伪装的两面：
他习惯让别人以为拿捏得住他，实际上无论是权术还是身手，他都留着
没有示人的底牌。这份深藏不露，跟他"温和外表下习惯性自我合理化"的
既有性格设定不冲突，反而互为表里——两者共同的核心，都是"从不让人
看清他真正的底线在哪里"。

支线场景（"夜闯偷虎胆"等）里桑杰朵杰不会亲自出手拦截玩家，这是场景
设计层面刻意维持中等难度、避免支线过早暴露终局底牌的安排，不代表
他打不过——真正的实力应该保留到终局对抗（如果剧情走向需要土司本人
亲自下场）才揭示。

#### 护卫头子：格桑顿珠（新增角色）

**身份**：桑杰朵杰的护卫头子，统领骑手与巡捕营两支武装力量，是土司
府对外展示的武力门面——终局对抗时，玩家表面上要跨过的"最后一道防线"
是他。**但真相是：桑杰朵杰本人深藏不露，一身武艺传自其父桑杰大侠
（详见第二章"三十年前死斗"真相），只是从继位起就习惯性地对外摆出
"我战力不高、事事仰仗护卫头子"的姿态**——此前版本"土司本人战力不高"
是需要修正的旧设定，格桑顿珠的存在并不是在填补桑杰朵杰本人武力空白
的缺口，而是他刻意维持的一层烟幕，让人误以为土司府的武力天花板只是
护卫头子这一层，真正的底牌始终没有示人。

**来历**：格桑顿珠不是本地人，是桑杰朵杰当年（尚未继位、还是世子时）
外出游历，在一场镖局与马匪的冲突中救下的落魄武人。当时格桑顿珠孤身
一人重伤濒死，桑杰朵杰没有多问来历便收留疗伤，此后格桑顿珠以命
相报，跟随桑杰朵杰回到曲措乡，一路做到护卫头子之位。这份"知遇之恩"
是理解他这个角色的核心——他对桑杰朵杰的忠诚不是对"土司"这个身份
的效忠，是对"当年那个肯收留一个陌生落魄武人的年轻人"的私人报恩，
这跟管家"忠实执行不义制度"的性质完全不同，是另一种更纯粹、也更
悲剧性的忠诚。

**性格与行事**：话不多，治军严整，骑手和巡捕营在他手下没有克扣军饷、
欺压百姓这类常见的军中弊病（这一点跟管家私下的做派形成对照——同样
是土司府的人，格桑顿珠这支武装反而是相对"干净"的一支）。他不参与
管家的私下盘剥和收税勾当，甚至私下并不认同管家的做法，但从不表露，
因为"这是主家的家务事，不是护卫该管的"。

**与真相的关系**：格桑顿珠不知道三十年前雪山崖底和贡措海密室的真相——
他是在那场悲剧之后才被桑杰朵杰（老土司之子，尚是世子）收留的，对
"父亲当年到底是怎么死的"这件事，他和现任桑杰朵杰一样，只知道一个
含糊的说法。若终局真相大白，格桑顿珠的反应应该是**震惊与动摇**——
他效忠的这份知遇之恩，建立在他以为"主家一直是受害者、雪山派是加害
者"这个简化认知上，一旦得知真相远比这个复杂（老土司本意是自证清白、
双方都有责任、这三十年的仇恨本身建立在一场误会与意气之争之上），
他的立场可能动摇，这为终局战设计了一个"是否可以说服格桑顿珠临阵
倒戈或至少放水"的分支空间，具体设计留待后续展开。

**终局定位**：玩家在终局对抗桑杰朵杰之前，大概率要先过格桑顿珠这一
关——他不是那种听命令就会不假思索举刀的打手，如果玩家能拿出三十年
真相的确凿证据（第二章"线三·真相修正"篇章解锁后获得的物证，比如
呼延大侠/桑杰大侠双方的遗物、住持的证词），有机会说服他至少保持
观望、不死战到底，这是终局战难度和结局走向的一个重要变量。

#### 与既有设定的衔接

- 黑风寨"对土司府不共戴天"这条设定不变，但补充一层地理现实——土司
  府草场边界与黑风寨山头部分重叠，是双方长期僵持而非速战速决的原因
- 虎胆三重门"夜闯土司府偷虎胆"节点（土司本人此时不会亲自出手拦截，
  管家会挡在前面）不变，格桑顿珠的武装力量此时可以理解为并未被惊动
  或不在府内当值，避免这个此前已经写定的中等难度节点因新增护卫头子
  而变得逻辑冲突——护卫头子的真正登场应该保留到终局战，不提前消耗
  在支线里；桑杰朵杰本人深藏不露的真实实力（见第二章真相）同样不该
  提前在这类支线场景里露底，他"不出手"是刻意维持人设，不是打不过
- 管家的"私人手下"与格桑顿珠统领的骑手/巡捕营是两套不同的人马，
  文档后续如果继续扩写管家相关内容，需要注意不要把两者混为一谈

**剧情脉络**：

住持的师兄。他在信里说，自己去贡措海不是为了朝圣，是为了毁掉湖底的东西。

何雨谢看完信，沉默了很久。她对呼延雪说："这封信不能留在雪山派。"但呼延雪
已经告诉了行脚僧。

行脚僧回寺禀报住持。住持没有惊讶。他早就猜到了。三十年，他一直不敢去贡措海
确认——如果师兄是为了销毁这份假地契而死，那他这三十年的沉默，就是共谋。

李若由在玉泉寨听到风声。她没哭，也没骂。她只是问了玩家一句话："你知道牧民
为什么一直穷吗？我们不是懒，也不是笨。我们以为是自己命不好。"

**终局方向**：假地契还在贡措海底。谁去取？取了之后烧掉还是公开？住持想赎罪，
土司想毁灭证据，李若由想让真相大白。三种不同的了结方式，玩家只能选一个。

### 线三：雪山之劫

**剧情脉络**：

都事派人摸上了后山平台。不是来打，是来找人。他在锦官城等了五年，终于等到
一条可靠的消息：上司最后出现的地方，是后山平台的跑马会。那年跑马会，雪山派
也有人参加。

何雨谢接待了官差。她说雪山派从不下山参加跑马会。但她在说谎。她知道掌门当年
偷偷下过山。掌门为什么下山？她没问过。现在官差找上门了，她才意识到，掌门
这几年的沉默和回避，可能不是修炼出了岔子，而是心里有事。

呼延雪什么都不知道。她只看到师母一夜之间老了许多。

梅朵听说锦官城的人上了后山平台，直接骑马冲上去。她不管失踪的官差是谁，她只
知道——跑马会是她的地方，谁也不能在那里撒野。

都事本人没有上山。他在锦官城等消息。他对身边的老兵退伍汉说了一句话："我不是
来收税的。我是来接人回家的。"

### 线三·真相修正：三十年前的雪山崖底（终局前置篇章）

> 本节是对线三"掌门下落不明"这一悬念的最终真相补完，同时修正了此前对
> 喇嘛庙住持的定性（从"知情不举的共谋者"改为"少年目击惨案后的愧疚恐惧
> 者"），并新增"雪山崖底"据点。**本篇章的解锁前提是线二+线三均已完成**，
> 是四条支线之外、真正意义上的主线终局引子。

**真相全文**：

三十年前，雪山派掌门（呼延雪、何雨谢口中从未点破姓名的"掌门"，此处
定名**呼延大侠**）与鱼定土司**桑杰大侠**（现任土司桑杰朵杰之父，也是
现任土司之名的直接由来——桑杰朵杰这个名字，正是当年老土司留给儿子的
烙印）曾在雪山之巅有过一场决定性的死斗。

当年的桑杰大侠是个真正意义上的好人，治乡宽厚，是本地人人称颂的"桑杰
大侠"。他发现自己府上留存的一份地契是被前人伪造的罪证（详见线二），
但他的本意**不是隐瞒或毁灭证据，而是想借跑马会之机把呼延大侠引出来，
当着他的面亲手撕毁这份假地契，自证清白**——桑杰大侠自己也痛恨这份
不义的遗产，想用一场公开的姿态跟过去做切割。

但呼延大侠此前已经风闻地契之事，认定桑杰家治乡不仁不义，一见面话不投机，
两人意气之争演变成了真刀真枪的死斗。刀剑无眼，一言不合动了真火，双双
殒命。

**桑杰大侠死在贡措海底密室**——这处密室正是线二里藏着伪造地契的同一个
地方，也就是说贡措海湖底既是"三十年前罪证的藏匿处"，也是"三十年前
惨剧的第一现场"，两条线在同一个物理空间里交汇。

**呼延大侠身受重伤，坠入雪山崖底，伤重不治**——这处崖底是本次新增的
据点（见下方"雪山崖底"）。

**唯一的目击者**是当年还是懵懂少年的喇嘛庙住持（此刻尚未继任住持之位，
是前任经师的师弟）。他亲眼目睹了这场死斗的全程，吓得转身逃跑，但逃跑
途中鬼使神差地救了坠崖重伤的呼延大侠一程（具体是"发现坠崖后偷偷送去
一口气、留下他没死透的最后线索"这类程度的救助，不是完全救活）。

这段经历成了他此后三十年不敢面对的心结——**不是共谋，是恐惧和愧疚**：
他亲眼看着两位大侠殒命，自己却因为害怕而没有能力、也没有勇气把真相
说出来，任由外界流传"呼延大侠下落不明""老土司暴毙"这类含糊的说法
三十年。前任经师后来发现的地契秘密，某种程度上也是师弟当年目睹惨剧后
留下的心结外溢——师兄想去贡措海查清楚师弟当年到底看见了什么，才因此
遇害。

**这条真相彻底改写了住持的人物弧光**：他不再是"知情不举的共谋者"，
而是"一个背负着少年时代无法弥补的恐惧、终于要在垂暮之年直面真相的
老人"。这个定性修正需要同步更新第一章势力分布表和第三章人物档案。

**现任土司桑杰朵杰的黑化根源**：他是这场悲剧的遗孤，年幼丧父，继承的
土司之位背后是一段被刻意模糊、始终没有真相的血案。他不知道（或者不愿
相信）自己父亲当年的本意其实是"当面撕毁假地契、自证清白"这样体面的
姿态，只知道父亲死在了雪山派手上、死在了一场说不清道不明的纠纷里。
这份没有得到解释的丧父之痛，加上土司之位带来的绝对权力，共同催生了
他今天的横征暴敛——他不是天生的恶人，是被"父亲死因始终没有真相"这件
事扭曲了三十年的第二代。

### 新据点：雪山崖底

- **地理定位**：参照"熊山/狼曲山贼窝"已验证的实现方式，不作为拓扑图新
  节点，而是挂在"顶峰"或"山洞"下的箱庭子结构——呼延大侠当年就是从雪山
  之巅坠落于此，物理上应该紧邻顶峰/山洞这一组已有节点
- **内容方向**：玩家需要先完成线二（拿到贡措海密室相关的地契/物证）和
  线三前置任务（机关图纸、掌门活动痕迹等）才能解锁进入这处崖底的触发
  条件；崖底应留存呼延大侠的遗骸/遗物，作为"揭露真相"这一终局环节的
  关键物证之一，与贡措海密室的老土司遗骸/遗物构成一组呼应的物证对
- **氛围基调**：不同于虎胆三重门"网状博弈"的基调，这里应该是全篇最
  沉重、最接近"考古式真相揭露"的场景，建议参照"任务8·听雨悟剑"里
  "环境暗示、不需要直接对话就能感受到情感重量"这种手法

### 终局：斗地主式的七方势力博弈

**解锁前提**：线二（秘密现世）+ 线三（雪山之劫，含本篇真相修正）均已
完成，是唯一同时依赖两条支线才能触发的内容，其余支线（线一、线四）
不是终局的硬性前提，但完成度会影响过程中的资源/情报储备。

**核心机制**：真相大白之后，桑杰朵杰得知自己父亲当年的真实死因和本意
（或者选择继续掩盖真相、狗急跳跳），矛盾正式激化为一场对抗现任土司
的终局战。玩家需要团结曲措乡境内的七方势力：

| 势力 | 拉拢方式 | 若未拉拢的后果 |

**关于鱼定村这一方的特殊说明**：鱼定村（才旦/村长这一系）跟"鱼定土司府"
（桑杰朵杰）是两个独立势力，只是共用同一个地理据点。鱼定村作为普通百姓
势力，天然缺乏武装对抗能力，它的"拉拢成功"更多体现在**信息与后勤支持**
（村民自发通风报信、隐藏行踪、提供补给）而不是直接参战，"未拉拢"的后果
也相应更温和（沉默中立，而非倒戈相向）——这跟其余六方"可能被反向拉拢
成为敌对武装"的设定有本质区别，不能套用同一套后果模板。

**斗地主式博弈的判定逻辑**：不是单纯的"好感度够了就自动加入"，而是
**每个势力都有自己独立的"最终任务"**，完成该势力的最终任务是拉拢的
硬性条件之一，好感度/声誉只是解锁最终任务的门槛，不能替代。如果玩家
好感度不够、或者势力最终任务没有做完，存在三种可能结果：
1. 该势力被桑杰朵杰反向拉拢，成为终局战的敌对方（鱼定村除外，见上）
2. 该势力选择保持中立（需要玩家主动完成一次"说服中立"的对话/任务，
   不是没做完就自动中立，中立本身也是需要争取的一个选项）
3. 该势力因为立场天然与土司对立（比如玉泉寨长期被压迫），即使玩家没有
   刻意拉拢，也有较高概率天然倾向玩家一方，但仍需要一定的好感度门槛
   打底，不是无条件白给

可以对七方一视同仁地实施，不存在某一方因资源匮乏而先天弱势的问题。

平行的编号体系——注意"村1·路见不平"与"任务1·路见不平"**同名但不是
同一个任务**：任务1（熊山口岔路，土司府差役借狼王之名敲诈，伏笔指向
线一雪山派回话）挂靠在线一·土司杀子；村1（管家设卡查虎胆温泉线索，

`quest_village_01` vs `quest_line1_01`）避免误判。

#### 村1·路见不平 → 「熊山口的不平事」

- **接取人**：老猎户（鱼定村口）
- **任务类型**：`QT_TALK`
- **接取条件**：首次与老猎户对话时触发。老猎户上下打量你一眼："外乡来
  的？正好，有件事老朽不便出面，你或许能帮上忙。"
- **任务概述**：老猎户告诉你，最近熊山口（鱼定村通往大草甸的岔路口）
  不太平。土司府的管家带人在那儿设了个卡，说是"查验货税"，实际上是
  拦路抽水。过路的牧民和商贩敢怒不敢言。昨天，玉泉寨的一个牧民赶着
  牦牛经过，被扣了三头，说是"税不够"。牧民理论了两句，管家的手下把
  人打了。老猎户说："老朽在村里住了四十年，没见过这么不讲理的。土司
  府收税有定数，哪来的'岔路口查验'？这事土司本人未必知道，但管家是
  他的左膀右臂，村里没人敢管。"
- **任务流程**：
  1. **前往熊山口**（鱼定村→大草甸方向，自动触发场景）：岔路口，管家
     的两个手下拦着赶马人阿旺（游走人口），正在翻他的货驮。阿旺忍气
     吞声，赔着笑说"各位爷，真没有了"。手下甲："没有？你从锦官城贩
     的茶叶呢？藏一包出来，罚十倍。"手下乙注意到玩家，喝问："看什么
     看？过路的交十文铜钱，不过路就滚回去。"
  2. **选择介入方式（核心分支）**：
     - **A. 直接动手**（武力解决）：打退管家手下。阿旺感激涕零，告诉
       你管家最近频繁派人来熊山口，不只是收税——好像在找什么东西。
       具体找什么他不清楚，但听说管家私下问过猎户关于"熊山温泉"的事。
     - **B. 讲理周旋**（智谋/魅力判定）：援引土司府的税制旧例，指出
       岔路口设卡不合规矩。管家手下理亏但嘴硬："你等着，我回去问管
       家。"两人撤走。阿旺悄悄告诉你，管家在找熊山上的一处温泉，据
       说是虎王常出没的地方。管家想要虎胆——不是献给土司，是自己要用。
     - **C. 袖手旁观**：阿旺被讹走一包茶叶。事后阿旺在鱼定村碰到玩家，
       还是会说起管家在找温泉的事，但语气冷淡许多："那天你要是帮了
       忙，也不至于——"
  3. **回禀老猎户**：不管选哪种方式，老猎户听完都会若有所思："温泉？
     虎王？管家要虎胆做什么……那东西能炼药，也能炼蛊。管家跟天都镇
     那边走动频繁，老朽早就觉得不对。这事还没完。"告诉你可以去喇嘛庙
     打听虎胆药用（伏笔：引向何雨谢线），或去玉泉寨问扎西知不知道温
     泉的事（伏笔：引向扎西线）。
- **奖励**：阅历+2、阿旺好感度（A线+30，B线+20，C线+5）、老猎户好感+15、
  日志标记"管家的私心"（非正式任务，指向虎胆三重门的三方交汇点）
- **设计注记**：管家的"岔路口设卡"同时触发三件事——压制商贩（引出村4
  杂货商人的进货难）、寻找虎王温泉（引出虎胆三重门）、展示土司府内部
  裂缝（管家背着土司行事，为后续父女裂痕铺垫）。分支不是善恶对立，是
  手段差异，没有"错误选项"；C线的好感惩罚很小，只是语气冷淡——不做
  惩罚性惩罚，而是让玩家意识到"没做的事也有回响"。

#### 村2·界石下的旧账（才旦视角）

- **接取人**：才旦（鱼定村内游走/固定时间段在村口附近）
- **任务类型**：`QT_MYSTERY`
- **接取条件**：完成村1后，与才旦对话。需先替她给老孙饭馆送一篮子糌粑
  才能打开话匣。
- **任务概述**：才旦告诉你，村口界石下面埋着一样东西。她小时候亲眼看见
  前任村长（她阿爸）半夜把一包东西塞进界石底座下面，死前只留一句话：
  "界石若是倒了，鱼定村也就散了。"管家最近在界石附近转悠，才旦怀疑他
  在找那包东西，请玩家帮忙先挖出来。"土司府管家不是鱼定村的人。村里
  的事，该由村里人决定。"
- **任务流程**：
  1. **夜探界石**：挖出油布包，里面是前任村长记的私账——土司府对外
     宣称每年收牲口税两成，实际收四成，多出的三成进了管家私库。前任
     村长知情但没有告发，反而每年从管家私账里分一笔"封口费"。最后
     几页笔迹慌乱："土司不知情……界石若是倒了，鱼定村也就散了——不是
     界石倒，是我倒。我不能倒。还有人看着。"
  2. **面对真相（核心分支）**：
     - **A. 交给才旦**：她沉默良久，问"我阿爸不是坏人，他只是不想惹
       事。你说，他也是坏人吗？"自答："他是村长，不是圣人。"她锁起
       账册，但当晚在歇马居找玩家："管家也在查这件事，这本账或许能
       让他退一步，但我需要你在场——你是外乡人，他不敢对你动手。"
     - **B. 自己保管**：才旦要求玩家承诺——将来若需要这本账，要站在
       鱼定村这边，不是土司府，不是锦官城。
     - **C. 埋回去**：才旦不怪玩家，但说"下次见面，我不会当你是朋友。
       不是恨你——是不敢信你。"
  3. **后续触发**：A/B线解锁后续"管家的对峙"场景（在虎胆三重门扎西线
     后期触发）：手持账册面对管家，A线才旦在场管家忌惮退让，B线玩家
     独自承担但获才旦绝对信任。C线不触发任何后续，才旦好感归零，无法
     再接她的任何任务。
- **奖励**：阅历+3、才旦好感（A+60，B+40，C归零，均为**增量**，与第
  三章"好感度达到60触发少女的心愿"这一固定里程碑是两个独立概念，不要
  混淆——这里的+60是这次任务本身让好感度数值上升60点，不代表好感度
  会直接跳到60这个绝对值）、获得关键物品"旧
  账册"（仅A/B线，作为面对管家的谈判筹码）

#### 村3·藏汉两姓的婚事

- **接取人**：鱼定大娘（鱼定村内游走，出现权重最高，65）
- **任务类型**：`QT_TALK`
- **接取条件**：无前置任务，直接触发
- **任务概述**：鱼定大娘的儿子（汉族，姓孙）看上了张商人（游走人口，
  布料商）的女儿卓嘎（藏族）。两个年轻人私定终身，但两边父亲都不同意——

  1. **分别说服两位父亲**：老孙真正的心结不是族里老人（早死光了），是

     藏人。张商人年轻时被汉族合伙人骗过，说服关键是"不是所有汉人都
     一样，就像不是所有藏人都信喇嘛庙"。

     驻足观看两天以上小孙会朝玩家点头一笑。
  3. **婚事结局**：两位父亲都松口后，鱼定大娘在老孙饭馆张罗婚礼，没有
     媒人聘礼嫁妆。张商人："我女儿嫁过去什么都不带，你们对她好是她
     应得的，不好她随时能回寨子。"老孙："那我也不收聘礼，这顿饭不
     收钱。"两亲家因"谁更该吃亏"差点又吵起来，鱼定大娘打圆场："都不
     要，那就都送。"
  4. **玩家的位置**：婚礼当天老猎户坐角落，才旦帮忙端盘子，杂货商人
     送两包盐当贺礼。小孙敬酒说"多亏你"，卓嘎往玩家手里塞糌粑，糌粑
     底下压了一截红线。
- **奖励**：阅历+2、鱼定大娘好感+50、老孙好感+30、张商人好感+30、获得
  物品"红线"（饰品·白，无属性加成，装备介绍："熊曲、鹰曲、狼曲，三条
  水都流进一条曲水。水都不分家。"）、之后在鱼定村歇马居住宿老孙会主动

#### 村4·杂货商人的进货难

     - **C. 谈判**（凭村1交情或已持有村2旧账册）：亮出底牌威胁，管家

     的萌芽）；B线——绕路图免费提供给全村，土司府私铺客人开始流失；
     C线——管家亲自到村口找玩家："账册的事，我们可以谈谈，你不急，
     我有的是时间"（为后续管家对峙埋时间点）。
- **奖励**：阅历+2、杂货商人好感+40（三线一致）、跑腿费（货价四成
  结算铜钱）、之后杂货摊对玩家永久八折

  "熊山手绘地图"，解锁熊山隐藏地点"温泉"（直接连通吊睛虎王刷新点）

#### 村6·界石重立

- **接取人**：才旦
- **任务类型**：`QT_CHAIN`（总结性任务，串联前5个）
- **接取条件**：完成村2（A或B线均可），且完成村3、村4中至少一个
- **任务概述**：才旦发现界石底座开始松动——可能是管家设卡时动了地基。
  她要重立界石，且要把村里帮过忙的人的名字刻上去："界石是鱼定村的人
  立的，也该鱼定村的人重立。"名单：老猎户、鱼定大娘、杂货商人、老孙、
  张商人、赶马人阿旺。
- **任务流程**：
  1. **通知名单上的人**：各自反应——老猎户"是该重立了"；鱼定大娘要
     包一锅糌粑；杂货商人主动提出在界石边支个摊放公用盐；老孙（若完成
     村3）提议立个小石墩给新嫁入鱼定村的人"先站一站"。
  2. **重立那天**：众人到场，老孙和张商人为石墩位置拌嘴（"歪了"／
     "歪了好看，留个盼头"）。才旦递给玩家凿子，请刻一排字，三个选项
     （情感倾向非线性）："三水归乡"（才旦认可并加刻正面）、"不问来处"
     （老猎户第一个点头）、"站一站再走"（才旦笑说"这像我说的话，但
     这回是你说的"）。才旦请鱼定大娘先上前："以后路过的孩子看见它，
     就当看见老身了。"
  3. **才旦的独白**：众人散去后，才旦回答此前"阿爸是不是坏人"的问题：
     "他不是坏人，也不是好人。他是村长……他的手，写的是所有人的
     名字。"她说出"我想当村长……我们鱼定村，总不能一直怕下去"——
     这句话是说给界石听的，不是说给玩家听的。
- **奖励**：阅历+4（全套任务里最高，作为总结性任务）、才旦好感锁定
  100（无论此前是60还是40，都封顶）、鱼定村所有参与NPC好感各+20、
  获得物品"界石下的土"（饰品·白，装备介绍："不是武功，不是财物。
  是有人在这地方站过。"）、鱼定村声望+1（系统层数值，影响终局势力
  博弈判定，第一版暂做标记用）、**才旦被村民推举为下一任村长**（非
  土司任命，土司府未正式认可也未反对；管家闻讯冷笑，梅朵听闻未表态——
  这两处反应本身是留给后续剧情的钩子，不在本轮展开）

### 线四：虎胆三重门

**恩怨核心**：没有人有仇。但所有人都需要同一件东西——吊睛虎王的胆。这就够了。

**起点**：老猎户在鱼定村口告诉玩家，熊山上的吊睛虎王还活着。虎胆这东西，有
三个用处——入药能解旧毒，入蛊能养百花，献给土司能免一整年的税。老猎户说，
已经有三拨人来找他打听过虎王的下落了。

**三方的诉求**

**何雨谢（雪山派掌门师母）**：多年前被阴毒内力所伤，每到雪季便咳血。虎胆
入药可拔毒。但她不让任何人声张，因为雪山派掌门不在，她若倒了，门派就散了。
只有呼延雪知道师母半夜咳醒的次数。

**扎西（玉泉寨老牧民）**：土司府今年加了三成牲口税。扎西拿不出。他听说虎胆
可以献给土司抵税，一个人扛着旧猎叉进了熊山。女儿卓玛在寨子里等了三天，没等
到人。

**百花门主（天都镇）**：天都镇西头的百花楼，明面上是酒楼，暗地里养蛊炼香。
门主是个从昆明来的女人，没人知道她的真名，都叫她"兰姐"。她要虎胆不是为了
卖钱——是用来炼一味蛊，名"百花引"。据说炼成之后，闻过的人都会对她言听计从。
这件事，只有天都镇的说书人陈七隐约猜到了。

**外貌锚点**（本轮新增，此前设计文档未写具体外貌）：身形窈窕，是苗族女子
的骨架和身段，常年一身盛装——银饰层叠、绣纹繁复的苗族衣裙，行走时环佩
叮当，这份盛装既是她百花门主的排场，也是她刻意用来遮掩"从昆明流亡而来"
这段来历的伪装，越是华丽张扬，越不容易被人往深处细想。

**网状任务结构**

拿到虎胆的方式：
- 直接猎杀（需要战力）
- 从老猎户处学陷阱术（需要悟性）
- 向行脚僧打听虎王的巢穴弱点（需要福缘，行脚僧会告诉你虎王在熊山北坡的一处
  温泉边，关节有旧伤）

三方各自的任务线（参考NCR/军团/豪斯，互斥但可以交叉到一定阶段）：

**何雨谢线**：
1. 呼延雪在雪山派门口拦住玩家，问是否愿意帮师母
2. 去喇嘛庙达摩药堂找药引，药堂师父说缺一味熊山雪莲
3. 采雪莲时遇到守塔僧团，需要帮他们修好地宫机关才能放行
4. 拿到虎胆后，何雨谢在雪山派内室服药，阴毒发作时有一段CG——她撑了这么多年，
   第一次露出虚弱。呼延雪在外面守着，手指抠进门缝里，不说话。

**扎西线**：
1. 卓玛在玉泉寨入口拦住玩家，说她爹进山了，三天没回来
2. 进熊山找到扎西，他被熊拍伤了腿，困在一处岩洞里
3. 帮他猎虎或帮他治伤。如果帮他猎虎，他会把虎胆让给玩家（他只要税能免就行）
4. 陪他把虎胆送到土司府。梅朵在门口看见卓玛，两个女人对视了一眼——梅朵认出
   她是当年的玩伴，卓玛没说话，低下了头
5. 土司收了虎胆，免了扎西的税。但管家在旁边加了一句："明年照收。"卓玛攥紧
   拳头，扎西拉着她走了。

**百花门主线**：
1. 天都镇的说书人陈七在讲一段百花门的艳情段子，提到兰姐在找一样东西
2. 去百花楼见兰姐，她开门见山：要虎胆。报酬随你开
3. 帮她炼蛊需要三样辅料：大草甸的燕羊胎、白塔地宫的守宫砂、贡措海的水晶砂
4. 每取回一样，兰姐会透露一点百花门的来历——她不是自愿来曲措乡的，是被人从
   昆明赶出来的。她的蛊术师父死前说了一句话："百花引炼成之日，就是你能回去
   的那天。"
5. 三种辅料集齐，兰姐当玩家的面炼蛊。炉火映在她脸上，她突然问玩家："你知
   不知道百花引对炼蛊的人自己也有用？我要让人听我的话，是因为我这辈子被人
   摆布够了。"

**虎胆的流转路径（全收集隐藏线）**

触发条件：学识+福缘双10（需要奇遇/修炼堆上去）。

1. 先把虎胆给扎西，陪他去土司府抵税
2. 土司收下虎胆，摆进府库。玩家需要夜闯土司府，把虎胆偷出来（或打土司掉落——
   此时土司本人不会亲自出手拦截，管家会挡在前面）
3. 梅朵发现是玩家偷的，但她没有声张。她只说了一句："下次来，走正门，我请你
   喝茶。"她不在乎那颗胆。她在乎的是父亲连这种东西都要抢牧民的。
4. 把偷回来的虎胆送到百花楼。兰姐问，已经干了的虎胆还能不能用？兰姐说，泡在
   百花引里三天就能复效。三天后，蛊成。兰姐没有给自己用——她把百花引送给
   玩家，说："我已经不想回昆明了。这东西给你。你想让谁听你的话，就让谁闻。
   包括我。"
5. 带着百花引回到雪山派。何雨谢已经病得起不了身。她不认识百花引是什么，只
   知道这不是虎胆。玩家可以选择：用百花引控制她（黑化路线），或者把兰姐教
   的方法告诉呼延雪，用百花引当药引，配合虎胆的残效，也能拔毒——效果慢一点，
   但不需要控制任何人（正向路线）。

**终局分支**

| 结局 | 条件 | 结果 |
|---|---|---|
| 花主之伴 | 帮兰姐炼成百花引，不偷回虎胆 | 兰姐留在曲措乡，百花楼成了玩家的第二个家。她不再提回昆明的事 |
| 牧民之婿 | 帮扎西抵税，虎胆留在土司府 | 卓玛请玩家去玉泉寨喝青稞酒。扎西说，这是他有生以来第一次不欠任何人 |
| 师母之情 | 虎胆直接给何雨谢治病 | 阴毒拔除后，她第一次下山，到鱼定村吃了一碗老孙饭馆的面。呼延雪说，师母笑了 |
| 全收集·后宫 | 学识+福缘双10，按扎西→土司→兰姐→何雨谢顺序完成全部流转 | 四方都欠玩家一份情。虎胆被用了三次——抵了一次税，炼了一味蛊，救了一条命。兰姐在百花楼等，卓玛在玉泉寨等，何雨谢在雪山派等。她们互相不知道对方的存在。但说书人陈七已经开始编新的段子了："话说那侠客，一颗虎胆走四方，三颗真心换不回——" |

**设计注记**：三方任务线可以并行到一定阶段（辅料收集），但虎胆本身只有一颗，
给谁决定了终局走向。全收集线需要极高的属性门槛，保证首通玩家必定要面临选择。

天都镇通过这条线正式接入主线——百花门的设定给"补给站"加了一层情报和地下
秩序的维度。

玉泉寨的牧民不再是"等待被拯救的受害者"，扎西主动进山猎虎，卓玛在山下拦人
求助，他们有行动力。

何雨谢这条线的核心是"撑着"。不敢让人知道自己病了，不敢让人知道掌门不在，
不敢把雪山派的重量放下来。虎胆对她不是药，是允许自己被人帮的借口。

**配套支线任务**：

#### 任务16·盗亦有道 → 「白塔地宫的分赃规矩」

- **奖励**：交还分支：声誉+4（正道）；封口费分支：额外银两奖励+
  声誉-3（正道）、+2（地下势力）

**设计说明**（四条线共通）：以上20个任务全部来自20类支线任务清单，

节点的道具/情报/flag，避免孤立的一次性内容；任务类型（type字段）严格
对照现有 `questTypes.js` 21种编码，接入 `qucuoQuests.js` 时直接复用现有的
`checkQuestCompletion` 判断逻辑，不需要新增任务类型。

#### 呼延雪（雪山派小师妹）

**人设**：好静不好动，说话少，情绪波动很小，习惯用沉默代替回应，但一旦认定
的人会异常依赖，对武学之外的事物反应迟钝，需反复确认才明白言外之意。

**外貌锚点**：皮肤是常年不见烈日的雪白，和她师门"苦修"的印象形成反差；发间
别着一支雪山派外门弟子共有的银色发簪，是唯一的门派身份标记，样式朴素；说话
前总要先怔怔地看你两秒才开口，像是要先把话在心里过一遍；即便隆冬也很少见她
主动裹紧衣物，仿佛不太在意寒冷。

**30档·沉默的赠予**（brief：她第一次主动开口找你）：

这天你在后山平台附近闲逛，远远看见呼延雪蹲在一块背阴的石头旁，手里摆弄着
什么，见你走近也没有起身，只是往旁边挪了挪，空出一块石面。

你在她身边坐下，她把手里的东西推到你面前——一小截打磨得很光滑的雪松木，看
得出来花了不少工夫，边缘细细地刻着几道纹路，说不上是什么图案，像是随手刻的。

"无聊时候刻的。"她说这话时眼睛看着别处，声音比平时更轻，"你要是不嫌弃，就
拿着吧。"

你接过木牌，入手温润，能感觉出常年被摩挲的痕迹——这东西她大概带在身上很久
了，此刻却给了你。

她见你收下，也不多说什么，重新望向远处的雪山，只是那截沉默维持了很久，却
不像从前那样让人觉得疏离。

**60档·雪山下的独白**（brief：她说起了自己很少提的过去）：

夜里落了小雪，呼延雪难得没有回房歇息，独自站在后山平台的栏杆边，望着雪山派
的方向出神。你走过去时，她没有像往常那样警觉地回头，只是往旁边让了让。

"我以前，"她开口，声音很轻，几乎要被风雪盖过去，"也不是一直这么沉默的。"

她说起小时候在雪山派刚学艺时的样子——那时候她还爱说话，甚至有点闹腾，直到
一次走火入魔的惊险经历，让她开始习惯用沉默去过滤自己所有的情绪波动，"说得
越多，心越乱，练功的时候尤其如此。"

"后来大家都当我是这样的人了，我也就懒得解释。"她转过头看你，眼神里带着一点
探究，"你是第一个，愿意等我把话说完的人。"

雪落在她的肩头，她没有拂去，只是继续望着雪山，像是终于把一件藏了很久的事情，
轻轻放下了一角。

#### 何雨谢（雪山派掌门师母）

**人设**：温和、操持门派内外事务，对晚辈有天然的关怀和照拂欲，说话带长辈的

**60档·掌门师母的心事**（brief：她第一次在你面前流露疲惫）：

深夜的内堂，只有你和何雨谢两人。她正对着一堆门派账目和书信发愁，见你进来，

"这些年，"她揉着眉心，声音里带着难得的疲惫，"门派内外的事，大大小小都要过
我的手。外人只当我是个体面的掌门师母，却不知道这份体面底下，是多少个不能
喘气的夜晚。"

她说起这些年为了维系门派内外关系所做的种种周旋，语气里没有抱怨，只是纯粹
的疲累，"有时候我也想，什么时候能有个人，让我不必事事都撑着。"

说完这话，她似乎自己也愣了一下，随即摇摇头，重新扬起惯常的温和笑容："叫你
听我这些琐事，倒教你见笑了。"

但你知道，这一晚，她卸下了一点点，只给你一个人看。

山势；冬天呼出的白气比旁人更浓，是常年在雪地里守猎养出的粗重呼吸。

**30档·山中往事**（brief：他第一次讲起熊山的旧年头）：

老猎户难得停下手里打磨兽夹的活计，招呼你坐到火堆边，递给你一块烤得焦香的
兽肉。

"跟你相处这些日子，也算摸清你的脾性了，"他抽了口旱烟，慢悠悠地开口，"不是
那种城里来的、只图新鲜的公子哥。"

他说起年轻时在熊山打猎的旧事——那时候熊山的野兽比现在凶悍得多，他也险些
丢了性命，"后来学乖了，进山前都要先拜一拜山神，图个心安。"

"这些年轻人啊，"他看着你，浑浊的眼里透着一丝欣慰，"愿意坐下来听我这老头子
唠叨的，也没几个了。"

**60档·传承的分量**（brief：他愿意把看家本领教给你）：

老猎户把你叫到他的木屋，郑重地取出一副磨得发亮的兽夹和一张手绘的熊山地形
图，图上密密麻麻标注着他多年摸索出的野兽出没规律。

"这些东西，"他的语气少见地严肃，"本来是我压箱底的本事，寻常人我是不外传的。"

"但你这些日子，是真心把我这糟老头子当回事，不是逢场作戏，"他把地形图塞进
你手里，"拿去吧，往后进山，能少走不少弯路，也能保住你的小命。"

"熊山认人，也认心，"他磕了磕烟斗，"你这份心思，配得上这份东西。"

### 5.1 狼曲山贼窝：黑风寨（完整版，替换此前的骨架建议）

#### 势力设定

**名称**：黑风寨（对外称"狼曲响马"，玉泉寨牧民私下叫他们"山那边的"，
不愿在寨里直呼其名，怕招来晦气）。

**地理定位**：狼曲上游、玉泉寨背后的一座未命名山，实现上不作为拓扑图
新节点，挂在"玉泉寨"或"狼曲路途"下的箱庭子结构/随机遭遇池，跟熊山
（熊曲）、喇嘛庙一系（鹰曲）并列，填补三条支流的最后一块拼图。

**真实身份与来历**：黑风寨的核心成员，本是十年前土司府加征"戍边税"
（一项从未真正用于戍边、只是加税借口的名目）时被逼得走投无路的玉泉寨
牧民与鱼定村佃户。带头的是**巴桑**——原本是玉泉寨一户普通牧民家的
次子，家里的牦牛在那年被土司府差役牵走抵税，父亲当场气病，不到半年
过世。巴桑没有走告官、没有走忍气吞声，他上了山，纠集了七八个跟他一样
被逼到绝境的人，第一次下山"借"回来的东西，只够全寨人吃三个月的糌粑。

黑风寨如今约有四十余人，其中约三分之一是当年跟巴桑一起上山的老人，
其余是这些年陆续投奔来的——有还不上土司税赋的、有被管家手下打断腿
赶出村子的、也有个别单纯图财的江湖亡命徒（巴桑不喜欢这类人，但赶不
走，只能设法压着他们别做得太过分）。

**巴桑本人**：三十出头，脸上有一道被土司府巡捕营的刀砍的旧疤（十年前
上山那晚留下的），说话不多，做决定很快，从不虐杀。他有一条不成文的
寨规——"不抢救命的口粮，不伤妇孺，不碰玉泉寨的人"（黑风寨从不打劫
自己的老乡）。这条寨规让黑风寨在打劫对象上非常克制：他们真正的目标
是土司府的税粮车队、锦官城的官家货运，以及个别民愤极大的富商——玉泉
寨、鱼定村这些普通百姓的商队,反而是黑风寨"顺手"护送过的对象（不收
护送费，只是路过顺路，但商队主人心知肚明是黑风寨罩着才平安过路）。

**巴桑与家人**：他还有一个妹妹**卓央**，没有跟他上山，留在玉泉寨嫁给了
本地一户人家（此名与鱼定村村3"藏汉两姓的婚事"里提到的卓嘎——张商人
之女、嫁入鱼定村老孙家——是两个完全不同的人物，特意避开同名以免混淆
两人的家庭背景和居住据点）。巴桑每年会想办法给妹妹送一次东西，从不
现身，只让手下留下东西就走，卓央知道是谁送的，但从不声张，也从不
拒收。

**组织形态**：黑风寨内部分工简单——巴桑说了算的核心决策层（约五六个
最早跟他上山的老兄弟），负责打探消息的"眼线"（散布在玉泉寨、天都镇、
锦官城的几个眼线，多是曾经在这些地方讨生活、被逼上山之前留下的旧
关系），以及负责实际打劫的"刀口"（战力较强的青壮，约二十人）。寨里
还有几个老弱妇孺——是跟着家人一起上山的，不参与打劫，负责寨内后勤。

**寨规**（延续巴桑"不抢救命口粮、不伤妇孺、不碰玉泉寨人"的原则，
补充完整）：
1. 不抢救命的口粮
2. 不伤妇孺
3. 不碰玉泉寨、鱼定村的寻常百姓
4. 打劫所得先紧着寨里老弱，再论功分配
5. 不通敌卖友（这条是巴桑对内部"图财的亡命徒"那批人立的，专门防止
   有人为了钱财出卖寨里弟兄的行踪）

**与各方的关系**：
- **对土司府**：不共戴天。巴桑对桑杰朵杰没有个人恩怨（他恨的是十年前
  那场加税，土司府换了人也一样恨），但对管家有额外的私怨——当年牵走
  他家牦牛的差役头目，正是如今的管家
- **对玉泉寨**：克制的守护关系，不打劫、有时暗中护送，但玉泉寨官方
  （若有村长/头人）不敢承认与黑风寨有任何往来，怕被土司府问罪
- **对锦官城/都事**：都事柳青鸢知道黑风寨的存在，但六年来一直没有
  大举清剿——她的判断跟对欢喜教的判断是同一种逻辑，"真正该查的是
  逼他们上山的税，不是山贼本身"，但公务上她必须做出"缉拿匪患"的
  姿态，于是常年"雷声大雨点小"，象征性派兵搜山却总"找不到"寨子
- **对天都镇（欢喜教/百花门）**：往来不多，井水不犯河水。欢喜教内院
  弟子里有一位同样叫"桑杰"的玉泉寨出身弟子（见深入了解五"弟子的
  过去"），经核对**这是同名不同人，两人没有关联**——特意说明避免
  被误认为同一角色，欢喜教的桑杰有自己独立完整的人物弧光（被管家
  诬陷→梵衍那所救→留在欢喜教），不需要也不应该跟黑风寨产生交叉，
  保持两条支线各自的完整性
- **对雪山派/喇嘛庙**：几乎没有往来，黑风寨不惹这两方，这两方也懒得管
  山贼的事

#### 与终局七方势力博弈的关系

黑风寨**不在**终局七方势力名单里（鱼定村/百花门/雪山派/喇嘛庙/玉泉寨/
天都镇/锦官城），它的定位更接近一个**独立的、可拉拢但不参与站队博弈
表决的武装因子**——黑风寨不会主动选边站，但如果玩家完成了黑风寨专属
任务线并取得巴桑的信任，可以换来终局战时"黑风寨袭扰土司府粮道"这个
额外的战术加成，属于锦上添花的补充，不改变七方博弈的核心结构。

- **任务概述**：狼曲河谷狭窄处，五骑从岩壁后转出，不吆喝不亮刀。
  带头的是三十来岁精瘦汉子，左脸一道旧疤："过路留下买路钱。两成——
  你要是玉泉寨的人，或者带着玉泉寨的信物，不用给。"身后四骑排成扇面，
  训练有素。一个年轻喽啰憋不住说"大哥，万一是假装的"，被瞪回去：
  "假装的人说不出玉泉寨有几头牦牛。"
- **任务流程**：三种应对——**交钱过路**（疤脸汉子收钱后给一块桃木牌，
  "以后走这条路，亮牌就不收第二次"）；**交手**（点到为止，打完扔木牌，
  "不错，但下次别逞能"）；**亮出玉泉寨相关信物**（若已完成扎西线或
  丹增马鞭任务获取熟人凭证，他把收的过路费倒还一半，"自己人，早说"）
- **奖励**：阅历+2，物品"黑风寨木牌"（桃木牌，刻狼头印记，背面刻
  "说话算话"四字），日志标记"黑风寨的规矩"。若亮信物，额外获得
  巴桑的好感——他自报姓名后不等回应便带人离开

#### 山2·妹妹的消息

- **前提**：完成山1，且到访玉泉寨至少两次
- **任务概述**：玉泉寨一户毡房外，年轻妇人**卓央**在晒牛粪饼，每逢
  生人经过会下意识停手辨认。鱼定大娘私下透露她哥在山上当山贼，每年
  秋天有人在她门口放一袋青稞不留名，她知道是谁。玩家若此前见过巴桑，
  会注意到卓央的眉眼和他极像——同样浅褐色眼睛，同样抿嘴时下巴微抬
- **任务流程**：玩家此前在寨中帮过卓玛/丹增/阿索任意两人（呼应5.4节
  玉泉寨支线），卓央第三次偶遇时主动开口："你在狼曲见过他？他脸上的
  疤还在不在？"自答"在，那年被巡捕营砍的，我爹就是那之后没撑住的"。
  她交出半块银锁片（阿妈遗物，她和巴桑一人一半，断口是旧痕，背面刻
  "央"字，另半刻"桑"字），求玩家带去给巴桑看一眼，不用带话，"只让
  他看看，他认得"
- **奖励**：阅历+2，关键物品"半块银锁片"，卓央好感+20。此后每年秋天
  她不再藏起门口收到的青稞

#### 山3·上山

- **前提**：持有半块银锁片，再次进入狼曲路途
- **任务概述**：上次遭遇地点这次只有一个十五六岁少年蹲在岩壁上，
  看到玩家和木牌银锁片，说"巴桑哥说这几天有人会来。就是你"，带路
  钻进灌木遮住的羊肠小道。山坳里的木寨寨门不关，老人晒草药、妇人
  纳鞋底——不像匪窝，像村子
- **任务流程**：巴桑在寨后岩洞（无虎皮大椅，只一块青石板摊着狼曲
  地形图）见玩家，接过银锁片看了很久塞进怀里，"她让你带来的？"不等
  回答便转开话题，讲起寨子来历——十年前"戍边税"从未用于戍边，牦牛
  被牵抵税，阿爸气倒半年后死，他没告官（告官的人后来被管家手下打断
  腿），"我爹咽气前说，穷归穷，别学他们那样"。岩壁上刻着木炭字寨规——
  不抢救命口粮、不伤妇孺、不碰玉泉寨的人，"不是写给你看的，是写给
  新来的人看的"
- **奖励**：阅历+3，巴桑好感+20，情报"黑风寨的真实构成与寨规"，巴桑
  把银锁片还给玩家，"下次卓央问，就说我看到了"

#### 山3.5·劫药（本轮新增，衔接山3与山4之间的情感递进）

- **前提**：完成山3，且与巴桑好感≥20，再次上山触发
- **任务概述**：巴桑不在寨里，老人煎的药反复熬得没味——寨中几个
  骨伤、肺病、烟熏坏眼的老人急需药材，但土司府在熊山口设卡后药材
  成了管控物资，卖给山贼要追责。巴桑一个人在岩洞坐了很久，第二天
  带人直奔鱼定村西头药铺——那是管家小舅子开的、专做管控药材生意
  只卖有土司府签条买家的铺子
- **任务流程**：巴桑把刀横在柜台上不动手，"你卖药，我买，按市价加
  一成……我不砸你的铺子，也不动你的人。我就站门口，让你的客人不敢
  进门"。掌柜满头大汗又不敢报官（管家的走私账本上也有这家铺子的
  份）。玩家可协助谈判（若已完成锦官城线可暗示柳青鸢也盯着这家）或
  直接帮忙搬药，最终以正常价买到雪山续断（治骨伤）、枇杷膏（清肺）、
  决明子（敷眼）。巴桑临走多留一块碎银："茶钱。刚才刀搁你桌上，
  吓着你了。这不是赔礼——是让你记住，我们来买药，你卖药，公平交易"
- **奖励**：阅历+3，巴桑好感+25，回寨老妇人当场给骨伤老人敷药（"比
  昨天好"），获得物品"土司府管控药铺的走私线索"（若已获管家密信可
  互相印证增强证据链）。巴桑临别："下次来，寨子里有药味——不是焦的"

#### 山4·管家的通缉令

- **前提**：完成山3.5，主线进行到管家与土司府裂痕加深阶段
- **任务概述**：管家得知黑风寨劫了自己小舅子的药铺，震怒——不是
  为了损失，是等于打了他私人的脸。他瞒着土司私雇约十五人锦官城
  亡命徒，准备趁夜不留活口摸上黑风寨。消息被天都镇兰姐截获（亡命
  徒在百花楼喝花酒漏了嘴），她派人给巴桑递话
- **任务流程**：巴桑两手准备——老弱撤后山岩洞，青壮在狼曲河谷设伏。
  玩家两个选择：协助布置绊马索火油陷阱；或去锦官城拖延亡命徒出发
  （若已完成官2-A或官2-B，柳青鸢默许，冷笑一句"管家的胆子比他的
  俸禄涨得快"，给一份城门值守换岗时间表）。若拖延成功，巴桑以逸待劳，
  亡命徒摸黑进谷折了大半，剩下的被堵在隘口——巴桑不杀俘，收兵器
  放归，"回去告诉管家，下次自己来"
- **奖励**：阅历+4，巴桑好感+25，获得"雇佣兵队伍情报"（终局时可作
  管家私自动用武装的旁证）。若寨中老弱无伤亡，巴桑赠玩家缴获的佣兵
  头子佩刀——"官府的人雇山贼杀山贼。这把刀，你留着当个笑话看"，获得
  物品"锦官城佣兵刀"（武器·蓝，刀柄刻"孟记铁铺"——**与5.4节玉泉寨
  任务三"丹增的马鞭"里同一家铁铺的铜箍圈材料形成有意的世界一致性
  交叉引用，两条独立支线各自引用同一家曲措乡真实存在的商铺，不是
  巧合冲突，是加分的细节呼应**）

#### 山5·狼烟旧账（收束任务）

- **前提**：完成山4，主线推进至终局前夕——土司府与多方矛盾已公开化
- **任务概述**：巴桑请玩家进岩洞，多了一口旧木箱——十年税册，不是
  偷的，是黑风寨截下土司府往锦官城送的年税车队所得。册子记录十年
  戍边税明细：三成进管家私库，五成留土司府账面，只两成象征性上缴
  锦官城，锦官城从未核对过。"我爹那年被牵走的两头牦牛，记在第三册
  第四十二页……他气不过，是因为差役牵牛时把他推倒在地，周围站满了
  人，没人敢扶"
- **任务流程**：巴桑交出税册，不为报仇，"给谁看，你定。才旦要重立
  界石，她需要知道村里人当年交了多少冤枉税；柳都事在查土司府的账，
  这税册能帮她补上最后一块拼图；梅朵想改土司府的规矩，她得先知道
  她爹的规矩有多烂"。三选不互斥。唯一要求："给他们看了之后，不必
  提我的名字……我爹的名字也在册子上。提册子，就是提他了。"他翻出
  一张泛黄缴税收据，按着一个褪色但指节分明的手印，背面写着一个藏文
  名字
- **奖励**：阅历+5，巴桑好感封顶，关键物品"土司府十年戍边税税册"
  （交才旦：公开账目动摇土司在鱼定村的威信；交柳青鸢：作为官方施压
  依据；交梅朵：她沉默看完后对父亲说"戍边税的事，我知道了。回去
  再跟你算"）。终局战术加成"黑风寨袭扰土司府粮道"，土司府后勤支援
  延迟两回合。巴桑托人带话："木牌还在你身上吧？在的话，这次不收你
  过路费。"

### 黑风寨支线：嘎则与雪团（白虎养妹情感线，本轮新增）

> **命名说明**：这个角色最初设计时曾与土司府护卫头子"格桑顿珠"共用
> "格桑"这个词根，两者阵营完全对立（一属黑风寨，一属土司府武装），
> 容易在剧情提及或玩家口语简称时造成混淆。经与设计者确认，此角色
> 正式定名为**嘎则**，与"格桑顿珠"彻底区分，人设与情节全部保留不变。

#### 人物档案：嘎则

巴桑的养妹，十七岁，寨子里叫她"虎丫头"。**来历**：十七年前，巴桑的
阿妈在狼曲上游救了一个受伤的年轻女人，女人怀里抱着刚出生的婴儿，
身上裹着一块完整的白虎皮，皮毛还带余温——一只垂死的白虎腹部被山石
砸穿，临死前生下幼崽。女人自称从雪山另一边逃难而来，把虎崽和自己的
孩子裹在一起取暖走了几十里，到狼曲边上撑不住了，死前把两个孩子都
托付给巴桑的阿妈。阿妈把婴儿当亲女儿养大，把虎崽和她放进同一个摇篮——
虎崽吃羊奶，嘎则也吃羊奶，喝同一个碗，睡同一张皮。虎崽睁眼看到的
第一个人是嘎则，嘎则学会的第一个动作是摸虎崽的耳朵。后来虎崽长成
半大的白虎，嘎则叫它**雪团**。

**外貌**：高挑，长发乌黑但鬓边天生一绺纯白，像被雪染过。眼睛极淡的
琥珀色，寨里老阿雅婶说"那是白虎的眼睛，被母虎的血沾过，看人看物都
不带杂念"。皮肤冷白——常年跟雪团一起睡，虎的体温比人低，她也跟着凉，
手脚四季都凉，只有笑的时候暖和。

**性格**：真单纯，不是装的也不是被保护出来的——她在寨子里活了十七年，
见过缺粮、见过死人、见过哥哥满脸是血被人背上山。但她看世界的逻辑
不一样：不是利益、不是规矩、不是人情世故，只有"这个人对我好不好"。
她不记仇，因为她的记忆里没有"仇恨"这个分类，但她记得谁给过阿雅婶
一包药、谁在巴桑发烧时守了一夜。她走路没声音（雪团教的，白虎脚垫厚
踩枯叶不响，她练了十几年，巴桑至今不知道她何时站到自己背后）；吃肉
先撕条给雪团再吃自己的；打架不用招数抄起什么扔什么，准头极好（从小
和雪团扑着玩练出来的）。

**软处**：怕两件事——怕雪团死（有次雪团被兽夹伤到前腿，她守三天三夜
没怎么睡，把巴桑送来的饭分一半给雪团）；怕巴桑死（这个她不说，但每次
巴桑下山行动，她会一直站在寨门口到他回来，有次巴桑晚归一天半，她就
站了一天半，回来时只说"菜凉了"就转身热菜，巴桑后来对老兄弟说"我每次
下山，都觉得自己欠她一顿饭"）。

**与终局七方博弈的关系**：嘎则与雪团不参与任何势力站队判定（同黑风寨
整体定位一致，见前述"与终局七方势力博弈的关系"），是纯粹的情感线角色。

#### 虎1·迷途

- **前提**：完成山3"上山"后，狼曲河谷随机触发
- **任务概述**：野兽低吼从胸腔震出，一头成年白虎侧卧溪边，左前腿
  夹着猎人的铁制兽夹，伤口化脓起不了身。旁边蹲着一个少女徒手试着
  掰开兽夹，指缝渗血一声不吭。发现来人抬头，眼里没有恐惧只有警惕——
  不是怕你伤她，是怕你伤虎
- **任务流程**：玩家施以援手撬开兽夹，她快速撕下自己袖口布条给虎
  包扎，手法熟练。完事后用额头碰虎鼻尖，藏语轻声说了句话，才转向
  玩家："它叫雪团。我是嘎则。你认识巴桑吗？他是我哥。"她不知怎么
  道谢，解下虎脖子上的旧铃铛塞给玩家："雪团说这个给你。它不会说话，
  我替它说了。"回程雪团一瘸一拐，她扶着虎一起走，全程不回头看玩家，
  但玩家若停下脚步，她会立刻察觉侧耳听
- **奖励**：阅历+2，嘎则好感+25，物品"虎铃"（饰品·白，铃舌歪了响声
  闷闷的，"其实雪团什么都没说，是她觉得雪团应该谢谢你"）

#### 虎2·下山

- **前提**：完成山3.5"劫药"后，巴桑请玩家带嘎则下山采办止咳草药
  （寨中老弱过冬急需，巴桑抽不开身，嘎则自告奋勇但他不放心她独自去
  玉泉寨），"这丫头三年没下过山。跟着你，我放心——不是放心你，是
  放心雪团。雪团认的人，跑不偏。"
- **任务概述**：嘎则牵雪团走在玉泉寨土路上，逐一认出巴桑提过的地方
  （丹增伯父的蒙古包、卓玛姐的毡房、阿索的牦牛"白云"），全记得只是
  没见过。雪团尾巴偶尔扫过她脚踝，她不躲
- **任务流程**：杂货铺门口一个外来商客没见过白虎，惊叫"老虎下山
  吃人了"，周围外乡人慌乱有人摸刀。嘎则挡在雪团前，蹲下抱住虎脖子
  把脸埋进毛里反复说"不是的"，抱虎的手发抖，雪团一动不动用尾巴圈住
  她。人群散去后，若玩家是男性，嘎则会突然攥住玩家的手，把手指扣进
  自己的手指里："就是喜欢你啊。你帮我救了雪团。你是好人。寨子里的
  阿雅婶说，好人不能等。"若玩家是女性，嘎则会挽住手臂靠在肩上，"她们
  都有姐姐。我没有……你是女的，可以当我姐。"
- **奖励**：阅历+3，嘎则好感+30。止咳草药带回寨中全寨老人分到一碗，
  雪团自此被玉泉寨的人认识（卓玛托人带牦牛肉干上山，注明给"白老虎"；
  李若由把"留意山里遗留猎具"加进下次商队采购清单）

#### 虎3·不还

- **前提**：主线终局前，嘎则好感≥55，触发条件为她得知玩家即将离开
  黑风寨
- **任务概述**：嘎则坐在寨门口石头上，雪团趴脚边下巴搁她膝上。她把
  雪团挪开让出半个位置拍了拍。若玩家坐下，她解下手腕上白虎乳牙系
  在玩家手腕上，低头辫子垂下挡脸看不清表情。系完抬头，眼眶红但没哭，
  指指乳牙又指指雪团的嘴——这枚是雪团小时候换下的牙，现在给你了。
  把玩家袖子拉下盖住乳牙
- **任务流程**：她靠在玩家肩上闭眼，"阿雅婶说，山下的人走了就不回来。
  但是我说你不一样。"睁开一只眼偷看反应，又闭上，"你要是真的不回来，
  我就让雪团去找你。雪团认得你的气味——你上次在寨子里吃饭掉了半块
  糌粑，它闻过了。"玩家若承诺归来她点头不再说话；若沉默她也点头，
  幅度更小，"也行。那你把雪团记住——它比人好记。"
- **奖励**：阅历+3，嘎则好感封顶，物品"虎乳牙"（饰品·蓝，耐久不
  磨损，根部缠着嘎则辫子上拆下的彩线，"不是借，是不还"）。终局后若
  留在曲措乡，嘎则每隔三天骑雪团来鱼定村找玩家，"人还没到，铃铛先响"，
  丹增见状："那丫头骑虎的样子，比她哥骑马还稳。"

### 5.2 天都镇地下邪教：欢喜教（完整版，替换此前的方向占位）

> **方向变更说明**：此前v3文档在此处只给了骨架建议——"邪教可设计成与
> 前朝有关的残余势力，呼应线二伪造地契的历史纵深"。这次设计者拍板选择
> 了完全不同的具体方向：**天竺流亡教主聚财谋反**，跟"前朝"这条线索没有
> 直接关联。这不是矛盾，是设计者在骨架建议之外做出的选择，比原方向更
> 具体、人物更立体，本节以此为准，原"前朝残余势力"方向作废。

#### 势力设定

**名称**：欢喜教（对外称"天都商会"，天都镇本地人只知道有一群"做香料
生意的印度人"）

**教义源头**：天竺欢喜法门，经缅甸、大理传入西南。传到曲措乡这一支已
经和原教旨相去甚远——原教旨讲"以欲制欲"，这一支教主讲"以欲制人"。
核心教条三条：一是"身即坛城"（身体本身就是庙，不需要盖寺院）；二是
"乐施即乐得"（让人快乐的同时，你就得到了他）；三是"无路则开"（没有
路的地方，欢喜教来开路）。

**真实目的**：聚财、敛人、谋反。教主的目标不是曲措乡，只是把这里当作
三不管地带的跳板——土司管不全、官府进不来、喇嘛庙只盯自己的山头。他
要攒够钱和人，回天竺夺回失去的东西。

**教主：梵衍那**（不是本名，是天竺故地地名，以故乡为号）。六十余岁，
皮肤黝黑，须发皆白，会说五种语言（含带大理口音的汉话）。年轻时是天竺
某小邦王子，被叔父篡位后流亡，在大理住十年、缅甸住五年，最后辗转来到
曲措乡。选择天都镇的表面理由是"这里气候像大理"，真实理由是这里没人
查他的来历。对外自称香料商人，"百香斋"（天都镇的香料铺）实际是他开的。

**圣女：罗琦**（梵衍那起的名字，意为"光明"。**注意与百花门"兰姐"是完全
独立的两个角色，容易因为都在天都镇、都是地下秩序头目而被误认成同一人——
罗琦是欢喜教圣女、天竺与大理混血，兰姐是百花门主、苗族出身，外貌、势力、
情感线全部各自独立，不要混淆**）。梵衍那的义女，二十出头，
母亲是天竺人和大理白族的混血。梵衍那在大理收养她，教她读书、经商、
识人。十四岁能替梵衍那谈香料生意，十六岁开始打理天都镇香堂日常事务。
梵衍那对她说："你是我最利的刀，也是我唯一的软肋。"罗琦从不当面回应
这句话，但每次有人来香堂闹事，她都会在对方茶里下药，剂量刚好让人忘记
自己为什么来，不会让人忘记回家的路。

**组织形态**：梵衍那是教主，罗琦是圣女兼实际管事，权力范围远超一个
"义女"该有的——教主年纪大了，大部分日常决策是她在做。教内年轻一代
更听她的话（教主说天竺话他们听不懂，圣女说汉话藏话都带大理口音，好听）。

据点两处：明面是**百香斋**（正经生意，账目经得起查），暗面是后院
**欢喜堂**（改建过的小佛堂，供的是一尊天竺旧神像，"欢喜佛的前身"，
罗琦私下说"其实是他小时候拜过的神"）。

信众分三层：
- **外院**——普通香客，不知道欢喜教存在
- **中院**——供养人，定期捐钱换"特制香料"（轻微上瘾的药香，不致命但
  让心情变好）。罗琦手里有一份供养人名单，记录每个人的把柄
- **内院**——真传弟子（约二十余人），住百香斋后院，对外说是香料作坊
  伙计。三个从大理跟来的老人，其余本地收的。不需要药控制——教主对
  他们有恩（大部分是他在路上捡的、救的、收留的），罗琦认为"恩情比药
  更难戒"

**与别派的关系**：
- **百花门（兰姐）**：互相知道底细，井水不犯河水。兰姐："那个老印度
  要是敢把香料卖进百花楼，我就把他的百香斋熏成蚊香。"梵衍那："她的
  蛊术是从天竺传过去的，论辈分，该叫我一声师叔祖。"真假无人知晓
- **喇嘛庙**：梵衍那不去，说"我们的寺庙在自己身体里"，但每次经过白塔
  方向都故意绕路——年轻时在大理接触过一个藏传僧人，具体缘由不明
- **锦官城（都事）**：梵衍那非常在意都事，因为都事在找一个失踪的官员，
  找了五年，"这样的人不会停下来，他迟早会查到天都镇"。见下方任务线
  "锦官城的暗线"这一具体交叉设计
- **土司府**：每年送一次礼，不多不少，刚好让土司记住名字但不觉得值得
  查。罗琦负责送礼，每次特意穿素色不带首饰、说藏话不带大理口音。梅朵
  见过她一次，对才旦说"那个卖香料的印度姑娘，看起来比锦官城来的官差
  还谨慎"
- **古道会**（新增势力，仅在天都镇地下活动，拜路神，管商路上的事——
  骡马安全、货物平安）：与欢喜教达成非正式默契，各管各的地盘，代表
  人物马三娘。这是本次新增的又一个天都镇地下势力，跟欢喜教、百花门
  三方并存，天都镇的地下秩序层次比此前设想的"两股势力"更丰富

#### "比武招贤"机制

对外说"以武会友，广结善缘"，实际借比武筛选两种人：可以控制的（武功
不错、有求于人、意志不坚定——熬成内院弟子）与不能控制的（太强/太清醒/
后台太硬——不能留也不能得罪，罗琦会送一包混了追踪花粉的"土产"香料，
"以防万一"，目前未曾动用）。

场地在百香斋后院空地，每月初五举办。规则：连胜三场可跟"教主的女儿"
（罗琦）切磋一场，胜了她欢喜堂大门就对你敞开——但目前无人胜过。不是
她武功多高，是连打三场的人已经累了，且她会在比武前给对方倒一杯特制茶。

游戏内呈现为天都镇一处独立地点"百香斋比武场"，每月初五可参加，也可
向罗琦申请私下切磋（需好感度门槛）。战斗复用现有回合制切磋系统，罗琦
战斗数值固定强度，不受任务进度影响。获胜奖品"欢喜堂秘藏"内容随玩家
进度变化——未触发暗线是普通药材香料，已触发则带情报价值。

#### 欢喜教任务线：香中劫

> 与本文档"任务18黑店风云""任务19江湖易容""任务20叛徒的密信"（原天都镇
> 本地支线，见第二章线四·虎胆三重门末尾）是并行关系，不冲突。玩家可能
> 先接触虎胆三重门的百花门主线，再触发这条独立的欢喜教任务线，两条线
> 共享同一个天都镇场景但服务不同势力（百花门 vs 欢喜教）。

**任务一·香中异**

- **前提**：玩家至少两次经过天都镇，且至少与一位游走商人（张商人/
  李掌柜/油嘴小贩中任意一人）有过对话
- **任务概述**：天都镇弥漫奇异香气，闻之心神松弛，但有老商贩私下嘀咕——
  闻多了睡得死沉，醒来钱包在哪都记不清。张商人的老主顾在天都行脚楼
  住三天，退房时少了两锭银子想不起是花了还是被拿了
- **任务流程**：李掌柜压低声音指路——去天都行脚楼要"地字号房"（隔壁
  就是百香斋后墙）。入夜后后墙传来极轻的杵臼声，持续约一个时辰，香气
  子时最浓。推开后窗可见百香斋后院有白衣身影在月下碾药
- **奖励**：阅历+1，线索"百香斋的夜半杵声"与"每月初五比武招贤"，
  李掌柜好感+10

**任务二·比武招贤**

- **前提**：完成任务一，或任意月初五前三天到达天都镇自动触发
- **任务概述**：百香斋前院搭擂台，管家手下一个姓马的差役也在人群中
  抱着胳膊观望。参赛者各色人等，其中一个"专程来品香"的愣头侠客其实
  是真心来的，另有一个冒充者用土司府巡捕营擒拿手打斗，可被识破
- **任务流程**：连胜三场（或识破冒充者替代一场战斗）。第三场后罗琦
  端茶示意，压低声音说明茶是为了压一压内堂更浓的香，不是下药。入内
  堂后罗琦开门见山：最近比武总有人混进来，不是冲品香，是冲百香斋的
  香料账本，需要帮手
- **要求**：参加比武招贤连胜三场（或识别冒充者）→ 接受罗琦委托
- **奖励**：阅历+2，罗琦初步信任。识破冒充者额外好感+10，且后续管家
  情报更早解锁；连胜后不喝茶硬闯导致头晕，罗琦事后道歉赠"醒神丹"×3

**任务三·管家的探子**

- **前提**：完成任务二，罗琦委托调查管家手下动向
- **任务概述**：名录上有锦官城差役（供养人之一，"靠不住"但未撕破脸）
  和两个管家眼线——一个借"收山货"名义打探进货路线（每月初十必去
  玉泉寨收牦牛皮），另一个混在百花楼常客里试图从兰姐处套话
- **任务流程**：翻眼线住处得管家亲笔密信——内容不只是查香料，管家
  写"若查得私藏兵器或结社名册，速禀，不必报土司"，意味着他要私自
  掌握欢喜教把柄留作私用。另一条线索需去找兰姐交涉——**兰姐的条件是
  玩家跑一趟大草甸取燕羊胎**（与虎胆三重门·百花门主线的辅料收集节点
  是同一件事，两条任务线在此交叉，若玩家已完成该节点可直接跳过跑腿
  环节）。兰姐透露混入百花楼的探子只知道百香斋有问题、不知具体什么
  问题，并补充"半年前就有人在百花楼打听过罗琦，那人不是管家的人——
  是锦官城的"，为任务四埋线
- **奖励**：阅历+3，关键物品"管家密信"，兰姐好感+20，开启锦官城暗线
  入口。罗琦看信后态度从"避让管家"转为"可以利用他的恐惧"

**任务四·锦官城的暗线**

- **前提**：完成任务三，获得"锦官城半年前调查罗琦"情报，前往锦官城
- **任务概述**：文渊书肆老板记得半年前有人（手指很粗不像读书人）查过
  天竺文汉文对照佛经，借阅签名是化名"罗"——**指向老兵退伍汉**
- **任务流程**：在锦官城暗巷偶遇老兵退伍汉（需完成任务11江湖问诊的
  前置条件，或直接触发偶遇），问到"罗"字他神色出卖了自己。约到官道
  上确认无人后松口：都事的上司当年在天都镇附近失踪，最后跟一个自称
  卖香料的印度商人（梵衍那）谈过话。都事查了五年查到梵衍那头上，但
  没有动他——因为梵衍那在大理曾救过一个流亡命官，那人正是都事上司的
  旧交，都事因此陷入两难。老兵退伍汉最后说："梵衍那救过的那个人，是
  我以前的营官。这事不该我来办……告诉他，有个老兵欠他一份人情，但我
  只能欠着，还不了。"
- **设计说明**：这条"都事的上司失踪与梵衍那有关"是都事同时在查的
  **第二条独立线索**，跟本文档线三"都事寻找失踪上司、最后线索指向
  雪山派"这条既有主线**并行不冲突**——都事本就是在多头调查，本篇
  不取代雪山派线索，只是补充了都事这条调查线的另一支
- **奖励**：阅历+4，"锦官城借阅记录"与"都事的矛盾立场"关键信息，
  老兵退伍汉好感+30。带回情报后罗琦沉默良久："他不是来杀我们的"——
  语气比害怕更复杂，像内疚，因为她不想欠都事人情但已经欠了

**任务五·管家的突袭**

- **前提**：完成任务三（持有管家密信）且完成任务四，管家情报积累足够
  后自动触发（下次到达天都镇时）
- **任务概述**：百香斋被土司府巡捕营贴封条（理由"私售违禁香料"），
  非管家亲自带队，是手下姓马的差役领头。欢喜堂未被攻破——兰姐带人
  堵在巷口撑了一夜，援引"天都镇规矩，土司府封铺子需先过镇上商会点头"
- **任务流程**：三重压力并行处理——劝住梵衍那不要武力驱逐（他已召集
  弟子准备动手，罗琦拼命拦阻，一动手欢喜教就从暗中博弈变成公开对抗，
  正中管家下怀）；处理管家手下马差役（武力威慑，或亮出管家密信施压——
  马差役认出笔迹脸色骤变）；回应兰姐的条件（百花楼在天都镇地位独立，
  以后针对天都镇商业的查封需经五家商号联名同意）
- **奖励**：阅历+5。成功劝住梵衍那，罗琦好感+25；用密信逼退马差役，
  管家两日后亲自到天都镇"澄清误会"但态度虚伪行动上退让，且结清茶钱
  一分不少（不留把柄）；接受兰姐条件，天都镇商会成为独立势力因子
  （系统层记录），百花楼好感+30；拒绝，兰姐不恼但说"你欠我一个人情，
  以后还"——这个伏笔在虎胆三重门百花线终局可触发额外分支

**任务六·决战前夜**

- **前提**：完成任务五，欢喜教暂时稳住局面。此任务是欢喜教任务线的
  收束节点，需与虎胆三重门终局或主线终局的时间线对接
- **任务概述**：梵衍那在后院露天（不在佛像前）召集全部弟子，手持父亲
  留下的断剑，说自己这一生做了三件事——离开天竺（失败）、活下来
  （运气）、收了你们（上天补偿）——宣布教主之位正式传给罗琦。罗琦
  跪下接的不是权杖印信，是那截断剑
- **任务流程**：罗琦接任后要做三件事——解散"教"的身份、更名"天都
  药坊"只做药材香料生意；主动向都事呈报完整香料贸易记录，用透明化
  换都事"不再追查"的台阶（都事欠梵衍那人情，这是给他的下台阶）；
  退还所有供养人银两解除关系，其中最难缠的一个（管家安插的眼线，
  "不要钱，要百香斋倒"）需要玩家陪同处理
- **奖励**：阅历+6，罗琦好感封顶（若之前累积足够，本任务确定情感线
  立场）。若三件事全部完成得当，都事托老兵退伍汉送来一张盖印但收件
  人空白的通关文书——"他让我们自己填名字，这张纸是给我们留一条后路"，
  获得关键物品"空白通关文书"（可在主线终局用作撤离/转移关键人物的
  凭证）。欢喜教正式转型天都药坊，退出江湖势力竞争，但保留对玩家的
  个人羁绊

**欢喜教任务线收束：终局站位**（与主线终局衔接）

欢喜教（天都药坊）在贡措海终局时的立场由任务线中的选择决定：

- **覆灭欢喜教（帮管家）**：罗琦离开曲措乡（后文情感线独白见结局分支
  表）。天都镇更容易被土司府控制，百花门成为镇上唯一地下势力
- **以身入局（帮梵衍那）**：欢喜教兑现中立承诺，终局时天都镇不对任何
  一方提供后勤支持，管家无法从天都镇调运物资到贡措海。罗琦以个人身份
  出现在终局场景，不参与战斗，但关键时刻提供一条情报或一件物品
- **邪教千金上位（帮罗琦）**：天都药坊正式独立。罗琦终局时主动找玩家，
  告知管家在天都镇留下的最后一条暗线位置（从前供养人处挖出），让管家
  终局时少一个退路。终局后罗琦留在天都镇经营药坊，情感线可继续发展

#### 深入了解阶段（五个可自由触发的支线，插入在任务二与任务三之间）

> 这五个任务不强制按顺序完成，但全部完成后才能推进到任务三；设计意图
> 是让玩家在正式卷入势力冲突之前，先对欢喜教的日常生活和罗琦的个人
> 世界建立情感认知。全部完成后，任务三罗琦的委托措辞会从"我找你不是
> 白找，你去跟兰姐谈"变为"以前这种事我不会交给外面的人。你是第一个"，

**共通设计原则**：
- 欢喜教不是传统意义上的"邪恶"邪教——不搞人祭、不逼人自残、不作恶。
  梵衍那的"谋反"本质是亡国遗老攒钱回乡，信徒是一群混不下去的自救者。
  管家要剿他不是因为他坏，是因为他不交税
- 罗琦不是赵敏或黄蓉的翻版——心思机敏但底色疲惫，从大理到缅甸到曲措乡
  一直在替一个老人收拾烂摊子。爱上玩家不代表她变得柔弱，只是终于找到
  一个不需要她收拾烂摊子的人
- 欢喜教与百花门的区别：兰姐卖情欲，罗琦卖安心；兰姐的控制手段是蛊，
  罗琦的控制手段是恩；一个是"你需要我"，一个是"你欠我"。游戏可以让
  玩家自己判断哪种更危险，或者两种都不如真心

#### 势力背景：都事柳青鸢

锦官城都事，姓柳，名青鸢。锦官城人当面叫"柳都事"，背后叫"柳娘子"——
不是不敬，是她的名字在衙门档案里被墨迹涂改过，没人知道她真名。她在
锦官城六年了，比任何前任待得都久。前任们要么急着调走，要么被曲措乡的
事磨到心灰意冷主动辞官。她不急——**她的上司六年前在曲措乡失踪，生不
见人死不见尸**（这就是本文档线三"都事寻找失踪多年的上司"这条既有
设定的完整来龙去脉）。上司对她有知遇之恩：他是第一个让她穿男装考吏部
试的人，那年她十九岁。

**外貌与行事风格**：柳青鸢极美，美到锦官城混混打架看见她经过都会收起
刀子散去——不是怕官威，是不好意思当着她的面打。她深知自己的脸是武器，
从不轻易用，永远穿大一号官袍，袖口挽两圈，领口扣到最上面一颗，步子
迈得比一般女子大，说话音量压得比一般男子低。锦官城百姓只在每年正月
十五灯会见过她穿女装，那年她穿月白放一盏河灯，说"今年这盏，还是没人
收。明年再放。"

**风格参照王熙凤**：府里府外一把抓，凶起来是真凶，体贴起来也真体贴。
老兵退伍汉是她从战场死人堆里捡回来的，骂他最多也最护着他。她定的税额
比前任少三成——不是体恤商贾，是"税太重，人就跑光了，没人我收谁的税"。
她的算盘打的是一盘六年的棋，终点是一个她不知道还能不能找到的人。

**与各方关系**：
- **对土司**：礼数周全，信尾每次加一句"望贵府查收附件"，附件是什么
  从不写、桑杰朵杰也从不问——两个聪明人之间的默契，她知道土司怕她，
  土司知道她不怕他
- **对喇嘛庙**：不去，"我拜的庙在江南，那座庙的和尚不收香火钱"。住持
  送的佛珠她收了串在腕上不摘，"收下，他就不好意思说我是'不洁之物'"
- **对雪山派**：没上过山，但每年冬天让老兵送一车炭去后山平台不署名
- **对欢喜教**：知道百香斋不只是香料铺，但不查——"那个印度老人要是真
  想造反，不会在天都镇开铺子"
- **对管家**：评价只有六个字，"一条狗，牙很利"

## 七、基础设施缺口与实现建议（已核对现有代码）

现有任务系统（`src/quests/questTypes.js` + `qucuoQuests.js` + `questEngine.js`）
分类体系已经很完整（21种任务类型），但引擎状态机目前只支持"单个任务、扁平
单一进度、单一完成判定"。逐条列出缺口和**具体的字段/函数级实现建议**（不是
空泛的"需要更强系统"，是可以直接照着写代码的设计）。

### 7.1 任务链 / 任务树（优先级最高）

现状：`questProgress = {questId, status, progress}`，一个任务是一条扁平记录。

**具体实现建议**：

```js
// 任务实例新增 stages 数组
{
  id: "he_yuxie_line",
  exclusiveGroup: "虎胆归属",  // 见 7.2
  stages: [
    { id: "s1_hu_yanxue_ask", description: "呼延雪在雪山派门口拦住玩家", completionFlag: "quest_heyx_s1" },
    { id: "s2_find_yaoyin",   description: "去达摩药堂找药引",           completionFlag: "quest_heyx_s2" },
    { id: "s3_pick_xuelian",  description: "采雪莲遇守塔僧团机关",       completionFlag: "quest_heyx_s3" },
    { id: "s4_cg_moment",     description: "何雨谢服药CG",               completionFlag: "quest_heyx_s4", isCgMoment: true },
  ],
}

// questProgress 新增 currentStageIndex 字段
{ questId, status, currentStageIndex: 0, progress, startedAt, completedAt }
```

`checkQuestCompletion` 增加对 stages 的判断分支：当前 stage 的 `completionFlag`
出现在 `gameState.flags` 里，`currentStageIndex` 前进一位；全部 stage 完成后
整个任务才标记 `completed`。这跟现有 `flags_add` 机制完全兼容，不需要改动
AI 输出格式。

### 7.2 互斥关系声明（虎胆三方线的核心机制）

现状：完全没有"任务A和任务B互斥"的概念。

**具体实现建议**：

```js
// 任务实例增加 exclusiveGroup 字段（同组内互斥）
{ id: "he_yuxie_line", exclusiveGroup: "虎胆归属", ... }
{ id: "zhaxi_line",    exclusiveGroup: "虎胆归属", ... }
{ id: "lanjie_line",   exclusiveGroup: "虎胆归属", ... }

// questEngine.js 新增函数
export function lockExclusiveSiblings(allProgress, quests, completedQuestId) {
  const completed = quests.find(q => q.id === completedQuestId);
  if (!completed?.exclusiveGroup) return allProgress;
  return allProgress.map(p => {
    const q = quests.find(x => x.id === p.questId);
    if (q?.exclusiveGroup === completed.exclusiveGroup && p.questId !== completedQuestId) {
      return { ...p, status: "locked_by_exclusive" };
    }
    return p;
  });
}

// 隐藏全收集线的"绕过互斥锁"判定，单独写一个函数，不复用普通互斥逻辑
export function canBypassExclusive(gameState) {
  const xueshi = gameState.char?.special?.悟性 ?? 0; // 或对应"学识"字段
  const fuyuan = gameState.char?.special?.气运 ?? 0;  // 或对应"福缘"字段，需确认具体属性名映射
  return xueshi >= 10 && fuyuan >= 10;
}
```

在提交虎胆给某一方（比如扎西线 s3 完成、虎胆已交付）的那一刻调用
`lockExclusiveSiblings`，除非 `canBypassExclusive` 成立才跳过锁定。

**待确认**：文档里"学识+福缘双10"这两个属性，需要对照现有 `char.special`
的实际字段名（目前已知有 根骨/悟性/体魄/魅力/智谋/身法/气运，没有"学识"
"福缘"这两个确切命名，需要设计者确认这是要新增两个属性，还是"学识"="悟性"、
"福缘"="气运"这样的既有属性别名）。

### 7.3 关键道具的"当前持有者"追踪（虎胆流转的核心）

### 7.4 多结局判定与记录

现状：`flags` 是纯字符串数组，没有统一的"这局到底触发了哪个结局"裁决逻辑。

**具体实现建议**：

```js
// 新建 endingResolver.js
export const ENDINGS = [
  { id: "全收集·后宫", priority: 0, condition: (gs) => canBypassExclusive(gs) && gs.flags.includes("quest_all_four_done") },
  { id: "花主之伴",     priority: 1, condition: (gs) => gs.flags.includes("quest_lanjie_done") && !gs.flags.includes("item_虎胆_recovered") },
  { id: "牧民之婿",     priority: 1, condition: (gs) => gs.flags.includes("quest_zhaxi_done") && gs.flags.includes("item_虎胆_stayed_tusi") },
  { id: "师母之情",     priority: 1, condition: (gs) => gs.flags.includes("quest_heyuxie_done") && gs.flags.includes("item_虎胆_used_on_heyuxie") },
];

export function resolveEnding(gameState) {
  // 按 priority 从小到大（隐藏结局优先）检查，第一个成立的即为最终结局
  const sorted = [...ENDINGS].sort((a, b) => a.priority - b.priority);
  for (const e of sorted) {
    if (e.condition(gameState)) return e.id;
  }
  return null;
}
```

在每次可能触发结局的节点调用，一旦判定成立立刻写入
`flags: [...flags, "story_ending_" + resolvedId]`，防止后续被覆盖判断。

## 十、两层地图架构：外层大地图 + 内层据点箱庭（本轮新增，架构性决定）

> 此前"箱庭"这个词只出现在给AI看的system prompt文字里（`presets/qucuo.js`
> 第12/16行"据点=箱庭"），没有任何真实代码结构支撑——`QUCUO_MAP` 里每个
> 据点就是一个扁平的 `{x, y, desc, exits}` 对象，没有内部空间层次。本章
> 是对这个缺口的正式架构规划：游戏地图从此确立为**两层结构**，两层坐标
> 系统各自独立，不混用。

### 10.1 两层架构总述

- **外层（大地图）**：现有 `QUCUO_MAP` 里的13个据点，坐标系统和连通
  关系保持不变，这一层解决"曲措乡境内从哪到哪"的问题
- **内层（据点箱庭）**：每个据点内部再挂一套完整的子房间地图，有自己
  独立的局部坐标、出口、方向移动——这一层解决"在这个据点具体待在哪个
  角落"的问题，是这次新增的部分
- **位置状态记录**：玩家当前位置从单一 `room.name` 字符串，扩展为两层
  组合（大据点+子房间），比如"鱼定村·老孙饭馆"，两个字段独立存储，
  不是拼接字符串，避免解析歧义
- **进出锚点**：每个据点内层都有一个"锚点房间"——大地图移动进入这个
  据点时的默认落脚位置，也是从内层"走出去"返回外层大地图时经过的位置。
  锚点通常是村口/寨门/山门这类天然的入口性质房间

之前版本一度把"狼曲河谷"错误地放在锦官城对外道路上。核对 `qucuoMap.js`

### 10.3 隐藏房间的解锁机制

据点内层箱庭里，凡是标注"隐藏"的房间（白塔地宫、贡措海密室、雪山崖底、
熊山温泉、喇嘛庙荤食地下室、天都镇欢喜堂等），解锁方式**复用现有任务
系统的前置条件机制**（`requiresQuestCompleted`/`isQuestGateOpen`，见
第七章7.1节），不新造一套解锁逻辑：

- 房间数据里增加 `unlockCondition` 字段，值是某个任务id或flag——玩家
  达成这个条件之后，这个房间才会出现在当前锚点房间的可选出口列表里，
  之前则完全不存在这个出口选项（不是"存在但打不开"，是"根本不出现"，
  避免玩家在没有线索的情况下瞎猜出一个隐藏地名）
- 举例：白塔地宫的 `unlockCondition` 可以是"已从行脚僧/达摩药堂等渠道
  获得地宫相关线索"这个flag；贡措海密室的解锁需要线二+线三真相修正
  篇章的进度门槛，跟终局揭露真相的节奏绑定

**雪山崖底：两条解锁通道**（本轮新增，与既有主线解锁并存不冲突）

雪山崖底目前有**两条完全独立**的进入方式，互不依赖、互不阻塞：

1. **主线通道**（已有）：`unlockCondition`——线二+线三"真相修正"篇章均已完成，
   随主线叙事自然抵达，触发的是终局真相揭露相关的既定剧情（第二章"线三·
   真相修正"篇章，呼延大侠遗骸/遗物作为终局关键物证）
2. **探索通道**（本轮新增）：在"绝顶"选择跳崖，**不需要等线二/线三先
   完成**，只看玩家当前的属性数值是否达到门槛。这是一条纯粹的探索型
   隐藏内容，触发时机跟主线真相揭露完全无关，两条通道并存

跳崖后落地地点是崖底本身的一池深水（暗河潭），**与贡措海无关**，是
雪山崖底自身的一处地理细节，不涉及两处据点之间的地下水路连通。

**跳崖判定与两条属性分支**：

- 门槛：外功≥85 或 内功≥85（两者满足其一即可跳崖并存活，双双不满足则
  跳崖判定为重伤/濒死，不触发下方隐藏剧情，仅作为一次高风险的失败尝试）
- **内功85分支**：跳崖之后一头没入崖底的深水潭，冰冷刺骨，几乎瞬间
  失去方向感。凭借深厚内力硬憋住这口气，任由水流把人卷向潭底，在
  几乎撑不住的最后关头，靠内息运转硬生生续住一线生机，缓缓浮沉挣扎，
  最终自己凭内力游回水面——全程没有第三方出手相救，是纯粹靠角色自身
  内功修为完成的一次生死挣扎
- **外功85分支**：跳崖落在崖壁凸出的乱石堆上，没有入水，是被强健的
  体魄硬生生扛住了这一下失足般的冲击——摔断骨头也好，磕破皮肉也好，
  终究没有当场毙命，靠外功锤炼出的强健筋骨硬撑着挪动、爬出乱石堆
- 两条分支具体隐藏剧情内容（呼延大侠遗物/心法残留/当年死斗现场的
  具体物证等）留待下一阶段展开，本轮先确立跳崖交互本身的机制骨架和
  两条分支"如何活下来"的差异化描写

## 十一、CG 分层合成机制（设计存档，暂不实现）

> 本节是纯技术架构设计，描述"AI如何标注场景状态、前端如何据此渲染分层立绘"
> 这套机制本身，不涉及具体内容生成——AI 全程只从固定词库里选词打标签，不
> 生成图像、不生成场景描述之外的具体内容。此节明确记录为"暂不实现"，等
> 前置内容（人物建档、任务系统等）就绪后再排期。

### 11.1 核心思路

每段叙事文本生成完毕后，AI 在正文末尾追加一行固定格式的标签，从预先定义
好的词库里选词，不自由发挥：

```
｜角色｜位置｜表情｜状态｜
```

示例：`｜钱塘君｜碉楼｜开怀｜手交｜`

前端解析这一行标签，按四个独立图层叠加渲染：

| 图层 | 对应标签 | 说明 |
|---|---|---|
| 背景图层 | 位置 | 场景背景，比如"碉楼""跑马场""雪山派内室" |
| 角色图层 | 角色 | 立绘本体，前置于背景之上 |
| 表情图层 | 表情 | 叠加在角色图层的面部表情差分 |
| 状态图层 | 状态 | 特殊判定层，见9.2 |

### 11.2 状态图层的两条判定规则

你提出的具体规则（以雪山派"山门"为界）：

- **山门内**：状态图层不显示，判定为"隐形/无形状"——雪山派内部场景不触发
  这层内容，符合门派场景的基调约束
- **山门外**：按好感度门槛判定——
  - 好感度 80 以下：状态图层不显示
  - 好感度 80 以上：状态图层显示，且替换为"特殊状态版本"（即 hcg 版本图层，
    整层替换而非叠加）

这套"地点决定是否可能触发 + 好感度决定具体显示什么"的双重判定逻辑，跟现有
`characterMilestones.js` 的"好感度阈值触发固定内容"思路是同一个方向，可以
共用同一套好感度读取接口，不需要另起一套判断代码。

### 11.3 词库设计原则

四个标签维度都应该是**预先定义的固定词表**，不是自由文本，理由：
- 前端渲染依赖标签精确匹配到具体素材文件名，自由文本没法映射到素材
- 限定词库同时约束了 AI 的输出空间，跟项目"AI提议系统裁决"的核心原则一致——
  AI 只负责在预先框定的选项里做选择，不负责创造新的图层组合

词库结构建议（跟现有 `npcLore`/`CHARACTER_MILESTONES` 用 `name` 做主键的
风格保持一致）：

```js
// 位置词库：跟拓扑地图现有13据点+子场景对应，不需要另起一套地名
const CG_LOCATIONS = ["鱼定村", "雪山派", "碉楼", "跑马场", "百花楼", ...];

// 每个角色独立的表情词库（不同角色的表情差分素材不同，不能共用一张总表）
const CG_EXPRESSIONS = {
  钱塘君: ["平静", "开怀", "羞赧", "恼怒", ...],
  何雨谢: ["温和", "疲惫", "虚弱", ...],
};

// 状态词库：常规状态 + 特殊状态（hcg替换版）分开定义
const CG_STATES_NORMAL = ["无", "持杯", "抱剑", ...];
const CG_STATES_SPECIAL = ["手交", ...]; // 仅好感度80+且非山门内场景才可能触发
```

### 11.4 实现前置依赖

- 需要先有第七章提出的"势力声誉/据点归属"数据（判断"是否在山门内"需要
  明确的据点边界数据，现有 `qucuoMap.js` 已有据点归属，这块可以直接复用）
- 需要角色好感度读取接口（已有，`mvu.js` 好感度系统直接可用）
- 需要美术素材（背景/角色/表情/状态四套图层，是单人开发的产能瓶颈，
  参照v0.1设计文档"美术是单人开发不可逾越的瓶颈"这条既定认知，这套机制
  的实际落地速度取决于素材产出，不是代码问题）

### 11.5 与主叙事 AI 的接口设计

主叙事 system prompt 末尾追加一句固定指令（类似现有"格式铁律"的写法）：

```
每轮正文结束后，另起一行按固定格式输出当前状态标签（不计入字数预算，
不影响正文内容）：｜角色｜位置｜表情｜状态｜
角色/位置/表情/状态 四项都只能从下发的词库列表里选，不能自造新词；
如果这一轮没有明确的具体角色特写焦点，角色项可留空，其余三项仍需选择。
```

这条指令的定位和现有"NPC认知隔离""格式铁律"这些硬性技术规范平级，属于
`buildSysBase` 里"系统输入"部分（不受用户预设编辑影响），不是可由用户
自由改写的预设条目。

## 十二、切磋战斗招式系统重构：品阶定下限，博弈定上限

### 12.1 现状问题

现有战斗系统（`combat/moveTypes.js`/`combat/resolveTurn.js`/
`npcGeneration.js` 的 `MOVE_POOL`）是纯粹的**品阶单向锁死**结构：招式
分白/绿/蓝/紫/橙/红六档，每档固定一套攻击/防御/状态三招（外加保底回气），
角色能摸到的招式档位由 `levelCap` 决定，`levelCap` 又直接决定了角色的
战力上限——**白档角色物理上不可能打出红档效果，无论怎么打**。这套结构
只有下限保证（品阶越高基础越强），完全没有上限突破的空间。

参考洛克王国这类宠物对战手游的技能设计范式（详见对话记录中查阅的
`wiki.biligame.com/rocom` 技能图鉴），高质量的回合制战斗设计普遍存在
"高风险高收益"机制：永久成长型数值（如"猛烈攻击"每次命中威力永久+45）、
耗能越高伤害越高（"魔能爆"消耗全部能量、消耗量决定伤害）、拿自身生命
换伤害（"垂死反击"每损失5%生命威力+5、"彗星"耗尽全部生命打出240威力后
自灭）、精准应对换质变效果等。这些机制的共同点是：**给低品阶角色一条
不认命的翻盘线，让博弈判断本身成为决定胜负的变量，而不是纯粹拼品阶**。

### 12.2 架构原则：品阶定下限，博弈定上限

这次重构确立的核心设计原则——

- **下限由品阶（levelCap）保证**：品阶越高，兜底越强（更高基础伤害、
  更多容错空间、更强保底回气效果），符合"高手就是比新手强"的常识，
  这部分沿用现有 `MOVE_POOL` 品质分档不变
- **上限由博弈决定，不受品阶限制**：任何品阶的角色都能装备"博弈型"
  招式——这类招式不再跟品阶绑死在同一个池子里查表，而是独立的一层
  机制，允许角色通过承担风险（消耗自身资源、精准把握时机、下重注）
  换取超越自身品阶应有的效果，实现"以小搏大"；反过来，高品阶角色若
  一味打保守套路，也可能被低品阶角色的极限操作反打得手忙脚乱

### 12.3 新增招式效果类型（在现有效果标志位体系上扩展）

`resolveTurn.js` 里已经存在"效果标志位驱动"的模式（比如
`onCounterSuccessDamageRatio`/`energyDiffDamage`/`freezeEnergyRecovery`），
这次不是推倒重来，是在同一套模式下新增以下几类标志位：

**永久成长型**：
- `permanentGrowthOnUse: N` —— 每次使用后，这一招的基础威力永久+N
  （参考"猛烈攻击"/"能量刃"）
- `permanentCostReductionOnUse: N` —— 每次使用后能耗永久-N，用到最后
  几乎不要钱，但前期打起来肉疼（参考"冲撞"/"水炮"）

**耗能换伤害型（高赌注）**：
- `allInDamage: true` —— 消耗当前全部能量，消耗量直接决定伤害倍数
  （参考"魔能爆"），能量攒得越久这一下越致命，但赌错时机等于這回合
  纯送人头
- `lowHpBonus: 系数` —— 自己生命越低，这一招威力越高（参考"垂死反击"），
  给残血角色一条不认命的路
- `selfSacrifice: {hpCost: 百分比, damageMultiplier: 倍数}` —— 主动
  燃烧自己一部分生命换一次性大额伤害（参考"彗星"耗尽生命换240威力），
  这是最激进的博弈型招式，用不好等于自杀

**精准应对型（现有机制的扩展，不是全新概念）**：
- 现有 `onCounterSuccessDamageRatio` 系列已经是这个思路，本轮不新增
  概念，只是确认这套体系要作为"博弈层"的核心组成部分保留和扩展

### 12.4 数据结构改动

招式不再是"品阶固定死板对应一套招式"，而是拆成两层：

```js
// 品阶层（沿用现状，决定下限）：MOVE_POOL 按品质档位提供基础招式
// 博弈层（新增）：BURDEN_MOVE_POOL，不分品阶，任何角色都能装备，
// 通过 npc.burdenMoves 数组挂载，跟品阶完全脱钩
export const BURDEN_MOVE_POOL = {
  move_yu_jin_fan_ji: {
    id: "move_yu_jin_fan_ji", name: "垂死反击", type: MOVE_TYPE.ATTACK,
    energyCost: 4, baseDamageMultiplier: 1.0,
    lowHpBonus: 0.5, // 每损失当前生命10%，威力+50%
  },
  // ...更多博弈型招式
};
```

角色的完整技能位 = 品阶层固定3-4个（现有 `moveset`）+ 博弈层0-2个
（新增 `burdenMoves`，是否装备、装备哪个由角色设计者/AI性格权重决定，
不是必装）。`decideNpcMove` 的加权随机逻辑需要相应扩展，让博弈型招式
的选用也受 `riskAppetite` 影响——`riskAppetite` 越高的角色，越倾向于
在合适时机启用博弈层招式而不是无脑用品阶层的保底招式。

### 12.5 实现范围与验证要求

本轮改动文件：`combat/moveTypes.js`（如需新增效果类型枚举）、
`combat/resolveTurn.js`（新增标志位的结算逻辑）、`npcGeneration.js`
（`BURDEN_MOVE_POOL` 定义、`ensureNpcCombatData` 接入 `burdenMoves`
字段）、`combat/aiDecision.js`（`decideNpcMove` 支持博弈层招式的选用
权重）。每新增一类效果标志位，必须在 `resolveTurn.js` 里补上对应的
数值结算分支，不能只在数据里声明标志位却没有代码消费它（那样等于
死数据，跟本轮之前内层箱庭房间踩过的坑是同一类问题，必须避免重演）。
