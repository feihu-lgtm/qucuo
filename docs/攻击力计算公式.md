# 曲措乡·武学攻击力计算完整公式（以代码为准）

> 本文档逐个函数列出战斗数值的真实计算式，**全部从代码抠出、非设计稿理想值**。
> 每个公式都标注了所在文件与行号，可直接对照核实。
>
> **重要更正**：《内外功修炼设计.md》里写的"最终伤害 = ... × (1 + 外功/125)"
> 这条公式**代码里没有采用**。实际代码为避免"外功内功各顶两遍导致伤害爆炸"，
> 改成了分工制——外功只进 baseAtk、内功只进气血/防御，伤害段不再乘内外功系数。
> 以本文档为准，那份修炼设计文档的公式是历史草稿。

## 〇、总览：一次攻击从属性到掉血，经过几层函数

```
外功 ──atkFromWaigong()──→ baseAtk ┐
装备武器 ──statsForQuality()──→ equipAtk ┤
                                        ├─calcBaseDamage()─→ 原始伤害 rawDmg
体魄 ──→ 力量系数 strengthCoef ─────────┤
武学招式 ──→ baseDamageMultiplier ──────┘
                                              │
                              三角克制判定（resolveTurn 主体）
                                              │
              ┌───────────────┬───────────────┴────────────┐
        攻击 vs 状态      攻击 vs 攻击                  攻击 vs 防御
        （克，全额+可翻倍）  （比身法，先手可击杀免伤）      （被减伤）
                                                          │
                            内功 ──defFromNeigong()──→ baseDef ┐
                            装备护甲 ──→ equipDef ─────────────┤
                            根骨 ──→ 根骨系数 genGuCoef ───────┼─calcDefenseValue()
                            招式防御折扣 ──→ defenseEffectRatio ┘
                                                          │
                                          finalReduced = max(1, 招式折扣后伤害 − 防御值)
                                                          │
                                                    落到对方血条
```

内功还有第三个出口：`hpFromNeigong()` → 气血上限（生存段位，不进攻击段）。

## 一、底层常量

### 1.1 战斗成长率 COMBAT_GROWTH
`src/npcGeneration.js:39`
```

```
含义：每跨 20 点内功/外功，数值翻约 1.82 倍；跨满 100 点（5 段）恰好翻 20 倍。
与 `equipment.js` 的品质跨度（白→红 20 倍）同源。

### 1.2 攻击兜底基数 BASE_ATK
`src/combat/resolveTurn.js:16`
```
BASE_ATK = 20    // 只在 side 没带 baseAtk 时兜底，正常玩家/NPC 都会带算好的值
```

### 1.3 装备品质基准与比例
`src/equipment.js`
```

饰品：无攻防、无 bonus（0730 起该字段已删）→ 战力走 sixDim / effect，不进本公式
qualityIndex：白0 绿1 蓝2 紫3 橙4 红5
```

## 三、原始伤害（攻击段核心）

### 3.1 力量系数 strengthCoef（体魄）
`src/combat/resolveTurn.js:41`
```
strengthCoef = 0.8 + 体魄 × 0.04      // 体魄默认5 → 1.0；范围约 0.8~1.2（体魄0~10）
```

### 3.2 calcBaseDamage(move, attacker, defender)
`src/combat/resolveTurn.js:39`

**主公式：**
```
atk        = (attacker.baseAtk ?? 20) + (attacker.equipAtk ?? 0)
multiplier = move.baseDamageMultiplier ?? 1     // 招式倍率，见第六节
rawDmg     = round( atk × multiplier × strengthCoef )
```
注意：**这里不乘外功系数、不乘内功系数**。外功已在 atk 里（baseAtk），
内功走气血/防御，不重复计入。

**multiplier 在 return 之前会被下列修正逐项叠加**（同一函数内，按代码顺序）：

博弈层（三选一，互斥，`resolveTurn.js:47-56`）：
```
selfSacrifice：  multiplier = selfSacrifice.damageMultiplier              // 直接替换
allInDamage：    multiplier = max(0.5, 当前能量 / 2)                       // 耗尽能量，攒越久越狠
lowHpBonus：     lostTenths = floor((1 − hp当前/hp上限) × 10)
                 multiplier += lowHpBonus × lostTenths                   // 每losing 10%血 +系数
```
读牌型加成（可叠加，`resolveTurn.js:59-75`）：
```
highHpBonus：      hp比例 ≥ 0.8 时  multiplier += highHpBonus
selfDebuffBonus：  自身带控制/耗气减益时  multiplier += selfDebuffBonus
afterCounterBonus：上回合应对成功  multiplier += afterCounterBonus
afterStatusBonus： 上回合成功施加状态/印记  multiplier += afterStatusBonus
pendingAtkBonus：  上回合蓄势  multiplier += attacker.pendingAtkBonus
```
乘算加成（放最后，`resolveTurn.js:77-80`）：
```
lowEnemyEnergyBonus：对方能量 ≤ threshold 时  multiplier ×= m
```

最终：`rawDmg = round(atk × multiplier × strengthCoef)`

## 四、内功 → 气血 / 防御

### 4.1 hpFromNeigong(neigong, 体魄)  —— 生存段位
`src/npcGeneration.js:49`
```
n    = clamp(neigong, 0, 100)
base = 60 + 体魄 × 8                      // 体魄5 → 100（跟旧的固定100血兼容）
maxHp = round( base × 1.8206^(n/20) )
```
| 内功(体魄5) | 0 | 20 | 40 | 60 | 80 | 100 |
|---|---|---|---|---|---|---|
| 气血上限 | 100 | 182 | 331 | 603 | 1098 | 约2000 |

（内功100、体魄10 → 约2800）

### 4.2 defFromNeigong(neigong)  —— 基础防御力
`src/npcGeneration.js:60`
```
n = clamp(neigong, 0, 100)
baseDef = round( 9 × 1.8206^(n/20) )      // 跟攻击同曲线，基数取一半（18→9）
```
| 内功 | 0 | 20 | 40 | 60 | 80 | 100 |
|---|---|---|---|---|---|---|
| baseDef | 9 | 16 | 30 | 55 | 99 | 约164 |

基数取攻击的一半，是防止"防御完全吃掉攻击、战斗打不动"——防御是削弱不是抵消。

### 4.3 装备防御力 equipDef
`statsForQuality("armor", quality)`
```
def = round( 5 × 1.741^qualityIndex )
```
| 品质 | 白 | 绿 | 蓝 | 紫 | 橙 | 红 |
|---|---|---|---|---|---|---|
| 护甲def | 5 | 9 | 15 | 26 | 46 | 80 |

`computeEquippedStats(inv).totalDef = Σ(已装备护甲.def)`

## 五、三角克制 → 最终伤害

克制表 `BEATS`（`combat/moveTypes.js`）：攻击克状态、状态克防御、防御克攻击。

### 5.1 攻击 克 状态（攻击方赢）
`src/combat/resolveTurn.js:189`
```
dmg = calcBaseDamage(赢家招, 赢家, 输家)
若 doubleVsStatus：dmg ×= 2        // 紫及以上攻击招克中状态时翻倍
最终伤害 = dmg                     // 全额，状态招被打断无任何减免
```

### 5.2 攻击 vs 攻击（同类，比身法）
`src/combat/resolveTurn.js:86,158`
```
先手判定 decideFirst：forceFirst 优先；否则比身法(默认5)，相等则五五开
dmgA = calcBaseDamage(A招, A, B)
dmgB = calcBaseDamage(B招, B, A)
若 先手方 dmg ≥ 后手方当前气血：后手免伤（先手击杀），否则双方互扣各自 dmg
```

### 5.3 防御 克 攻击（防御方赢）—— 唯一动用防御值的分支
`src/combat/resolveTurn.js:238`

```
rawDmg = calcBaseDamage(攻击方招, 攻击方, 防御方)     // 攻击方本来的伤害

若 攻击招.ignoreDefense（橙/红攻击招）：
    最终伤害 = rawDmg                                // 无视防御，防御白挡，且不触发反击
否则：
    reduced       = round( rawDmg × 攻击招.baseDamageMultiplier )   // 招式自带折扣先削一层
    defenseValue  = calcDefenseValue(防御方, 防御招)                // 见 5.4
    finalReduced  = max(1, reduced − defenseValue)                // 保底1点，防打不动
    最终伤害 = finalReduced

    // 若防御招带反击（听风/归元/听桥系 onCounterSuccessDamageRatio）：
    counterDmg = round( rawDmg × 防御招.onCounterSuccessDamageRatio )
    反打给攻击方 counterDmg
    若反击可击杀攻击方 且 onCounterSuccessPreemptive（红档听桥）：防御方本次免伤（finalReduced 清0）
```

> 注意 5.3 里 reduced 用的是**攻击方招的** baseDamageMultiplier（原始攻击倍率再乘一次做折扣），
> 而 defenseEffectRatio（5.4）用的是**防御方招的** baseDamageMultiplier 的补数。两者是不同招的字段，别混。

### 5.4 calcDefenseValue(defenderSide, defenseMove)  —— 防御值
`src/combat/resolveTurn.js:25`
```
armorDef           = defenderSide.equipDef ?? 0                       // 装备护甲防御
baseDef            = defFromNeigong(defenderSide.neigong ?? 0)        // 内功基础防御（4.2）
genGuCoef          = 0.8 + 根骨 × 0.04                                // 根骨系数，默认5→1.0，范围0.8~1.2
defenseEffectRatio = 1 − (防御招.baseDamageMultiplier ?? 0.6)         // 防御招折扣越狠，防御发挥越充分

defenseValue = round( (baseDef + armorDef) × defenseEffectRatio × genGuCoef )
```
例：红档"听桥"baseDamageMultiplier=0.05 → defenseEffectRatio=0.95（防御力几乎全额发挥）；
白档"硬架"=0.6 → defenseEffectRatio=0.4（只发挥四成）。

### 5.5 状态 克 防御（状态方赢）
`src/combat/resolveTurn.js:200`
```
基本无直接伤害，走状态招自身效果：
  energyDiffDamage：    伤害 = |双方能量差| × 3
  doubleReflectDamage： 反弹 = round( 防御招算出的伤害 × 防御倍率 × 2 )
  + 施加状态（气乱/内伤印等）、封气、抬耗气等
防御方"应对失败"额外惩罚：onCounterFailEnergyPenalty 扣能量、onCounterFailDefenseNullified 下回合防御失效
```

## 六、武学招式倍率 baseDamageMultiplier（品阶层）

来源 `src/combat/moveArchetypes.js` 的 tiers 数组，索引 = levelCap（白0~红5）。
**招式倍率只管"发挥比例"，段位强度已由外功→baseAtk 体现**（见 moveArchetypes.js:20-22）。

攻击类原型（示例）：
| 档 | 白 | 绿 | 蓝 | 紫 | 橙 | 红 |
|---|---|---|---|---|---|---|
| baseDamageMultiplier | 1.0 | 1.15 | 1.3 | 1.5 | 1.8 | 2.2 |
| 特效 | — | — | — | 克状态翻倍 | +无视防御+引爆 | +必先+命中废招 |

防御类原型：baseDamageMultiplier 从白 0.6 递减到红 0.05（越小防得越好），
配 onCounterSuccessDamageRatio 从 0.2 递增到 1.0（应对反击）。

### NPC 品阶 → 内外功值：getTierPower(levelCap)
`src/npcGeneration.js:68`
```
cap     = clamp(levelCap, 0, 5)
neigong = min(100, round(5 + cap × 18))     // 白5 绿23 蓝41 紫59 橙77 红95
waigong = neigong                            // NPC 内外功同值
baseAtk = atkFromWaigong(waigong)            // 白18 绿33 蓝60 紫109 橙198 红约310
```

## 七、一个完整算例

**玩家**：外功60、体魄5、装备紫档武器(atk34)，用绿档攻击招(倍率1.15)，无博弈/读牌加成。
**对手**：白档NPC(内功5)，选白档防御招"硬架"(倍率0.6)，无护甲、根骨5。

攻击段：
```
baseAtk      = atkFromWaigong(60) = 109
atk          = 109 + 34 = 143
strengthCoef = 0.8 + 5×0.04 = 1.0
multiplier   = 1.15
rawDmg       = round(143 × 1.15 × 1.0) = 164
```
防御结算（防御克攻击）：
```
reduced            = round(164 × 0.6) = 98          // 攻击招折扣
baseDef            = defFromNeigong(5) ≈ 9
armorDef           = 0
genGuCoef          = 1.0
defenseEffectRatio = 1 − 0.6 = 0.4
defenseValue       = round((9+0)×0.4×1.0) = 4
finalReduced       = max(1, 98 − 4) = 94            // 白档防御没什么防御值，主要靠招式折扣
```
**这一击对手实收 94 点。**

若对手改用**红档听桥**(倍率0.05)且内功80、橙护甲(def46)、根骨10：
```
reduced            = round(164 × 0.05) = 8
baseDef            = defFromNeigong(80) ≈ 99
armorDef           = 46
genGuCoef          = 0.8 + 10×0.04 = 1.2
defenseEffectRatio = 1 − 0.05 = 0.95
defenseValue       = round((99+46)×0.95×1.2) = 165
finalReduced       = max(1, 8 − 165) = 1            // 触发保底，几乎全免
```
**这一击对手实收 1 点**（顶级防御配置的意义），且听桥会反打 `rawDmg×1.0 = 164` 回来。

## 八、公式分工一句话总结

| 属性 | 走哪个函数 | 管什么 | 进不进伤害乘法 |
|---|---|---|---|
| 外功 | atkFromWaigong | baseAtk（攻击段位） | 进（作为加数，不是系数） |
| 内功 | hpFromNeigong / defFromNeigong | 气血上限 + 防御值 | 不进攻击段，只在被打时减伤 |
| 体魄 | strengthCoef | 攻击力量系数 0.8~1.2 + 血量base | 进（乘） |
| 根骨 | genGuCoef | 防御力量系数 0.8~1.2 | 只进防御值（乘） |
| 身法 | decideFirst | 同类对撞先手判定 | 不进伤害 |
| 武学招式 | baseDamageMultiplier | 招式倍率 + 特效 | 进（乘） |
| 装备武器 | statsForQuality→equipAtk | 额外攻击力 | 进（作为加数） |
| 装备护甲 | statsForQuality→equipDef | 额外防御力 | 只进防御值 |
