## 二、数据在哪（改物品先认门）

| 文件 | 管什么 |
|---|---|
| `src/items/catalog.js` | **物品库权威源**。346 件的名/类/品阶/数值/特效/六维/consumable。分子数组：WEAPONS/ARMORS/ACCESSORIES(具名) + STANDARD_*(制式) + SUNDRIES(杂项,含药食) + SUPPLEMENT_WEAPONS + LEGENDARY(神兵) + DIVINE_ARMS(神器)，拼成 `CATALOG` |
| `src/items/distribution.js` | **可上架商品的流通归属**。每件 `{regions, shopTypes}`——属于哪些地域池、该在哪类店卖。神兵/私人信物/剧情物不在此表（=不上架） |
| `src/items/regionMap.js` | **分池规则**。据点→地域、15 家店铺档案(region+shopTypes+tier)、品阶权重表、NPC role 携带风格 |
| `src/shops/qucuoShops.js` | **店铺铺货** `rollShopStock(shopKey, gameTime)`——按天刷新滚货单 |
| `src/npcGeneration.js` | **NPC 携带** `rollNpcCarry(npc)`——按 role×region×levelCap 抽货 |
| `src/equipment.js` | 数值公式 `makeItem/statsForQuality/priceForQuality`——匿名兜底货走这套 |

## 三、四池怎么运转（横向店型 × 纵向地域 × 品阶权重）

### 3.1 两个维度定"什么货在哪出现"

- **地域（region，7 类）**：村镇 / 市镇 / 官城 / 宗教 / 门派 / 山野 / 异域。
  据点→地域见 `DISTRICT_REGION`（15 据点）。一件货可属多地域（通货型给多地域）。
- **店型（shopType，7 类）**：铁铺 / 药堂 / 粮食铺 / 成衣皮货 / 当铺古玩 / 金玉 / 香料。
  真实店铺多为"综合店"，一家店 `shopTypes` 是数组（如天下商行覆盖铁铺+当铺+粮食+药堂+成衣）。

**一家店的候选货 = 它的 region ∩ (shopTypes 任一命中) 在 distribution 里的货。**
例：天都镇孟记铁铺(市镇/铁铺·成衣皮货) → 抽出孟记弯刀、马帮护商弩这类"天都镇的铁器/皮货"，
抽不到锦官官造剑，也抽不到药。

池内实际分布（271 件）：
- 地域：山野 55 / 异域 55 / 官城 49 / 村镇 43 / 市镇 39 / 宗教 24 / 门派 21
- 店型：铁铺 89 / 药堂 66 / 粮食铺 46 / 当铺古玩 34 / 成衣皮货 19 / 金玉 11 / 香料 6

### 3.2 品阶权重定"档次高低"

三档店（`TIER_PROFILE` 低/中/高）对各品阶有不同偏好概率，用作每件货的**出摊概率**：
- 低阶店（村口）：白 60% 绿 30% 蓝 10%，紫橙红 0 —— 基本只白绿
- 中阶店（天都/门派）：白 20 绿 40 蓝 30 紫 10
- 高阶店（锦官官市）：白 5 绿 20 蓝 35 紫 30 橙 8 红 2 —— 偶尔能淘到紫橙红

因为具名货品阶是**写死**的（松纹剑就是蓝），品阶权重不改它的档，只决定它"这次出不出摊"。

### 3.3 刷新：每天一次（已定）

`rollShopStock` 用 `Math.floor(gameTime/24)`（每 24 时辰=1 天）做随机种子：
**同一天进同一家店货单不变，隔天变。** 既有"今天有什么好货"的期待，又杜绝刷货卡 bug。
（顺带修掉了旧 `rollShopInventory` 里 floating 概率写死 0.5、不读各件 chance 的 bug。）

### 3.4 NPC 携带：掉落 = 可偷 = 所见即所得（已定）

`rollNpcCarry` 按 `role`（平民/武人/高手/宗教/官吏/江湖闲杂）× 当前 region × levelCap 抽：
- 乞丐掉白档杂物、镖师掉绿蓝兵器、门主掉紫、山贼掉本地匪货
- 品阶窗口 `levelCap±1`，牧民不会掉橙红；无放回抽样防重复
- 只在 NPC **没有 AI 声明的 carry** 时作随机兜底；打死掉的 = 能偷的 = 同一批（沿用既有接线，AI 声明的 carry 优先）

### 3.5 什么不进池

神兵（LEGENDARY 30）、神器（DIVINE_ARMS 5）、带人名的私人信物、定情/遗物/缴获物、
剧情核心兽材宝物（虎胆/百花引等）——共 75 件，`distribution.js` 不收录，
走具名 NPC carry / 剧情任务发放。`isPoolable(name)` 可查某件是否进池。

## 四、怎么加新货（最常见的操作）

1. **写条目进 catalog**：用 `docs/补货生成提示词.md` 生成规范条目，粘进 `catalog.js`
   的 `SUNDRIES` 数组。只写 `name/category/quality/tags/desc`（+可选 sixDim/consumable/effect），
   **绝不写 atk/def/price**——数值系统按品阶自动算。
2. **让它能上架**：在 `distribution.js` 加一行 `"新货名": { regions:[...], shopTypes:[...] }`。
   不加 = 只能靠 AI 发放/具名携带，不进店。
3. **私人信物/神兵**：**不要**加进 distribution，改挂到对应 NPC 的 `carry`（residentNpcs.js）
   或任务奖励。
4. **验证**：`grep` 确认写进去了；`node` 解析 `CATALOG.length` 看件数涨没涨；
   跑一下 `rollShopStock` 看新货会不会在对味的店出现。

> 特效字段必须是 combat 层真读的白名单（见 `补货生成提示词.md` 的 effect 清单），
> 否则是"死字段"（写了不生效）。加特效后 grep combat/ 确认字段被消费。

## 五、怎么调分配（改归属/开新店）

- **某件货该在别的地方卖**：改 `distribution.js` 里它的 `regions`/`shopTypes`。
- **新开一家店**：在 `regionMap.js` 的 `SHOP_PROFILE` 加一条 `{region, shopTypes:[...], tier}`，
  并确保 shopKey 对应 `qucuoBuildings.js` 的店铺。
- **调档次概率**：改 `regionMap.js` 的 `TIER_PROFILE`（低/中/高三档的品阶概率）。
- **改 NPC 携带风格**：改 `regionMap.js` 的 `ROLE_CARRY`（每 role 的 count/cats/tier）。

## 六、已知小遗留（不阻塞）

- 自动归类曾漏抓几件 desc 带人名但没触发规则的物件（如"曲措三曲水""老兵烟斗"），
  偶尔混进 NPC 携带。影响小（单件、多在携带非货架）。要清干净：在生成 distribution 的
  脚本 EXTRA 排除表补名字重跑即可。
