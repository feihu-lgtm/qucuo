# 设计：亲密互动·按人设的好感门槛

> 口径：每个有名有姓的角色都有自己的"界限"——好感度过她自己那条线才解锁亲密互动。
> 线不是统一数值：风骚的开 30，贞烈的 80，怪杰看心情——按各人性情定。
> 系统裁决过没过线，AI 只写互动场景；私密段（nsfw 字段）是过线后喂给 AI 的料。

## 0. 现状家底

- `varTree.角色[名].好感度`：单人好感 0-100，npcAwareness 初见裁决初值。
- `AFFECTION_TIERS`（narrator.js）：旁白文风五档，只做文风不做门槛。
- OC 数据：`archetype`（chivalrous/greedy/eccentric/opportunist/lustful…）+ `nsfw` 私密外貌段（元朵朵等已写）。
- `bodyProfile`：私密层只认 ■ 模式硬开关，尚无按人门槛。
- 驻场/游走 NPC：大多没有 nsfw 字段——没过线前也不需要。

## 1. 数据模型

### 1.1 每角色字段（NPC/OC 数据层加一条）

```js
intimacy: {
  threshold: 60,        // 她自己的界限：好感 ≥ 它才解锁亲密互动
  style: "娇憨",        // 亲密画风给 AI 的提示词（自由词，人设腔）
  forbidden: false,     // true = 永不解锁（嬷嬷/仇敌/设定上不可）
}
```

- 没写 `intimacy` 的角色按 `archetype` 映射默认门槛，不用逐条补。

### 1.2 archetype 默认门槛表

| archetype | threshold | 气质 |
|---|---|---|
| lustful / 合欢系 | 25 | 见人三分熟 |
| opportunist / 狡黠 | 40 | 有利可图就松 |
| eccentric / 奇葩怪诞 | 45 | 对眼缘就行（朵朵这档） |
| gentle / 温婉 | 55 | 水到渠成 |
| chivalrous / 侠义 | 65 | 重礼数，慢热 |
| proud / 冷傲 | 75 | 界线最高 |
| devoted / 贞烈 | 85 | 近乎不可 |
| 无 archetype | 60 | 通用人 |

阈值是"意愿"，不是交易——跟 cherish 那套物件钟爱度互不干涉。

### 1.3 每人定制（数据层逐条，可后补）

元朵朵 `threshold:40`（怪诞+涉世未深，好感来得快去得也快）、铁伯 `forbidden`（机关人偶没有这档事）、贞烈型 OC 80+、合欢派出场即 25。第一批先把 77 OC 按 archetype 落默认，特殊人设的逐条 override。

## 2. 判定通路

```js
intimacyGate(npc, affection) →
  { unlocked, threshold, style, reason }
```

- `forbidden` → 永不解锁，reason 给拒词方向（"她是墨家机关，听不懂这个"）。
- `affection < threshold` → 未解锁：亲密指令照样能输，但系统裁决「被拒」——拒词按 archetype 出（侠义厉色、狡黠调笑、朵朵"诶？我们不是在做买卖吗"）。
- 过线 → 解锁：亲密互动指令进 nsfw 分支，`nsfw` 字段+style 喂 AI 写场景。
- 好感跌破线 → 重新上锁（变心是常态）。

## 3. 互动入口

- 对话自由文本/动作菜单出「亲近」族指令（搂抱/亲吻/更进一步），先过 intimacyGate：
  - 未过线 → 系统写拒词事件 + 好感微降（-3~-8 按 archetype，侠义扣最狠）；
  - 过线 → 进 nsfw 叙事分支，NPC 的 nsfw 段+style+私密层喂 AI；
  - 过了线的对象在面板/详情卡出现标记（♥ 已亲密）。
- 与留守/入队联动：已亲密的角色留守时好感自然衰减减半——她舍不得。
- ■ 模式没开时整个指令族隐藏，拒词也不走亲密口径。

## 4. AI 侧

- 上下文注入：`{名字}好感 X/Y(她的界限)，{已亲密|未亲密|从不}` + archetype 拒词腔提示 + style。
- 过线后叙事自由度放开到 nsfw 段；未过线 AI 一律写婉拒场景，不写擦边。

## 5. 拆单

| 单 | 内容 | 文件量 |
|---|---|---|
| A | intimacyGate + archetype 门槛表 + OC/驻场逐条 intimacy 标注 | 3-4 |
| B | 互动入口（指令族+拒词事件+好感扣/面板标记） | 3-4 |
| C | nsfw 段+style 上下文注入 + ■模式串联 | 2-3 |

A 先行，B/C 并发。

## 6. 验收

- 朵朵 threshold 40：好感 39 亲她→拒词+扣好感；40 后→解锁，nsfw 段进上下文。
- 贞烈档 80：不到 80 永远婉拒。
- 铁伯 forbidden：输入亲密指令出机关拒词。
- 跌破线重新上锁；■模式关掉时指令族整族隐藏。
