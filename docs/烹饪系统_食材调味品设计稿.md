## 三、烹饪台架构（BUILDING_TYPE.KITCHEN）

烹饪台是独立建筑类型，不是家园设施。挂在有灶房的房间（溪边小屋·灶房、
山间别墅·一楼客厅、蜀王庄·倒座房），走左栏建筑入口，CenterPanel 条件渲染
`<CookingScreen />`。

### 六格槽位

```
┌─────────────────────────────────────────────────────────┐
│  烹饪台 · 溪边小屋·灶房                              ×  │
│─────────────────────────────────────────────────────────│
│                                                         │
│   ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐                   │
│   │ 料①  │ │ 料②  │ │ 料③  │ │ 料④  │   ← 调味料/食材  │
│   │ 空   │ │ 花椒 │ │ 团鱼 │ │ 空   │     混装，≤4 格  │
│   └──────┘ └──────┘ └──────┘ └──────┘                   │
│                                                         │
│   ┌──────────────┐   ┌──────────────┐                   │
│   │  技法        │   │  炊具        │                   │
│   │  炒 ▼       │   │  铁锅 ▼      │                   │
│   └──────────────┘   └──────────────┘                   │
│                                                         │
│   ┌─────────────────────────────────────────────────┐   │
│   │  灶膛火焰噼啪响。铁锅烧热了，花椒在油里打转。   │   │
│   │  预测：冷锅鱼 · 回血22% + 身法+2（25回合）      │   │
│   └─────────────────────────────────────────────────┘   │
│                                                         │
│              [ 开火 ]        [ 清空 ]                   │
│─────────────────────────────────────────────────────────│
│  🎒 可用材料（点击放入空槽）                            │
│  熊山花椒×2  贡措海盐×1  青衣江团鱼×3  熊猫笋×1 ...     │
└─────────────────────────────────────────────────────────┘
```

**槽位规则**：
- 料①~④：调味料与食材混装，不分先后，总数 ≤ 4。点击背包材料 → 放入第一个空槽；点击已放槽位 → 退回背包。
- 技法槽：下拉选 5 种技法之一（炖/烤/炒/腌/蒸），未解锁的灰显。
- 炊具槽：下拉选已拥有的炊具，炊具决定技法可用性（见下表）。
- 开火：校验「料槽组合 × 技法 × 炊具」是否命中配方表 → 命中则扣料、产出成品入背包、写 buff flag；未命中则灶台叙事反馈（"这搭配炒出来一塌糊涂"），不扣料。
- 预测行：实时显示当前组合命中的配方名与效果，未命中显示"灶神摇头"。

| 3 | 烤 | hp×1.3 + 体魄 | 30t | 明火，肉食加成 |

| 5 | 蒸 | hp×1.8 + 回气 | 40t | 天花板，需蒸笼 |

- 蓝档 2 件是双技法复合，中后期追求。
- 紫档 1 件是终局收藏品，全技法加成，广汉当铺流拍品——叙事钩子：这东西为什么流拍？

## 六、落地注意事项

1. 新增物品录入 `catalog.js` SUNDRIES 数组，category 一律 `ITEM_CATEGORY.MISC`。
2. 调味品 tags 标 `["调味品", "食材"]`，食材标 `["食材"]`，两者都能进烹饪台。
3. 已在库的 6 件（熊山花椒/贡措海盐/熊山松茸/狼曲冷水鱼/雪山雪鸡肉/熊猫笋）不重复录入，只补 tags 里缺的 `"调味品"` 标签。
4. 烹饪台 UI 读 `tags.includes("食材")` 过滤可用材料，配方表另建 `cooking/recipes.js`。
5. 品阶只影响叙事稀有度和 AI 引用权重，不影响烹饪数值——数值由配方表硬编码。
