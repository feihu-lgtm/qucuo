# 曲措乡·补货生成提示词（拿去单独跑，产出可直接进 catalog 的条目）

> 用法：把下面「提示词正文」整段发给 AI，指定要补的品类/据点，它会按 catalog 格式产出
> JS 条目，你复制进 `src/items/catalog.js` 的 SUNDRIES 数组即可。数值不用管——系统自动算。

---

## 提示词正文（从这里开始复制）

你是曲措乡这款武侠 MUD 的物品设计师。曲措乡是一个西南边地、藏汉交融的架空江湖，
我需要你补充一批「商品」录入物品库。严格按下面的背景、规则、格式产出。

### 一、世界背景（决定物品的地域民族质感）

曲措乡在西南高原，一条名叫「曲措」的河（由熊曲、鹰曲、狼曲三条支流汇成）穿境而过，
藏、汉、白、天竺（异域）多族杂居。十三个据点各有风味：

- **鱼定村/玉泉寨**：藏地牧区。牦牛、青稞、酥油、氆氇藏袍、藏银、糌粑、猎具。质朴。
- **鱼定土司府**：藏族土司辖地，仪卫制式、宴客席面。
- **天都镇**：三教九流集散地。马帮货、铁器、市井杂物、黑市地下药、当铺古玩。
- **锦官城**：汉地官城，最繁华。官造军械、制式甲、绸缎成衣、金玉珠宝、川味酒食、香料点心。
- **喇嘛庙/白塔**：藏传佛教。念珠、袈裟、法器、藏药、素斋、经卷。
- **雪山派**：武林门派。门派制式剑、练功服、御寒裘、药膳。
- **黑风寨**：义匪山寨。粗朴兵器、草药、苞谷酒、牛皮护具。
- **大草甸/熊山/贡措海**：山野秘境。兽材、猎具、山货、冷水鱼、蜂蜜、盐。
- **百花楼**：苗疆背景的销金窟。蛊香、花酒、绸衣、暗器。
- **欢喜教/欢喜堂**：天竺流亡者建的教门。梵文法器、天竺香料、迷香、异域药食。
- **大理**：白族异乡，罗琦/梵衍那的背景地。白药、桂花油、扎染、贝叶经。

**写描述的硬性文风**：白话古文、说书人口吻，完整句子，用「虽然/至于/倒也」这类
连接词，不用冒号破折号。每件物品的 desc 要有：一个对比点或反差、一处地域/民族/气候
细节、一个能让人记住的具体动作或来历。禁止空洞辞藻，要像真有这么件东西、真有人用过。

**这批只造「商品」——量产通货、店家制售、猎户牧民常见货、寻常药食**。不要造带具体人名
的私人信物（如「某某的旧锁」）、不要造独一份的神兵名器、不要造剧情核心宝物。这些另有归属。

### 二、字段规则（AI 只提议这些，数值由系统裁决，不许自己编攻防数字）

每件物品是一个 JS 对象，只允许出现下列字段：

```js
{ name: "物品名", category: ITEM_CATEGORY.XXX, quality: "品阶", tags: ["标签"], desc: "描述" }
```

- **category**（四选一，写成 ITEM_CATEGORY.XXX）：
  - `ITEM_CATEGORY.WEAPON` 武器　`ITEM_CATEGORY.ARMOR` 护甲
  - `ITEM_CATEGORY.ACCESSORY` 饰品　`ITEM_CATEGORY.MISC` 药食杂货
- **quality**（六选一）：`"白"` `"绿"` `"蓝"` `"紫"` `"橙"` `"红"`。越高越强越稀有。
  商品以白绿蓝为主，紫少量，橙红极少（橙红多是名器，商品别乱标高阶）。
- **tags**：功能性短标签数组，如 `["药材","疗伤"]`、`["食品","主食"]`、`["马帮","护具"]`。
- **desc**：按上面文风写，一到三句。

**⚠ 绝对不要写 atk/def/price/durability/buyPrice**——武器攻击力、护甲防御力、价格全部
由系统按品阶自动计算（`makeCatalogItem` 内部 `statsForQuality`）。你只决定「这是什么、
叫什么、什么品阶」，系统决定「它多强、多贵」。这是本项目「AI 提议内容、系统裁决数值」的铁律。

**可选进阶字段**（只在合适时加）：

- 护甲/饰品可加 **`sixDim`**：装备时加到角色七维。key 只能是
  `根骨/悟性/体魄/魅力/智谋/身法/气运`，value 是小正整数（1~3）。
  例：`sixDim: { 身法: 2 }`。
- 药食（MISC）可加 **`consumable`**：服用即时效果。**只允许下列字段**：
  - `hpRestore`: 回血比例（0~1，按最大气血），如 `0.15`
  - `energyRestore`: 回真气点数（1~8，仅战斗中有效）
  - `dispel: true` / `dispelAll: true`: 解异常（仅战斗中）
  - `rebirthOnce: true`: 假死保命一次（仅战斗中）
  - `sixDimTemp: { 属性: 增量 }`: 临时六维加成（探索/战斗都生效），可选 `buffDuration`（时辰数，默认30）
  - `combatBuff: { waigong:点数, moveMul:0.x, energyBonus:点数, hpBonusRatio:0.x }`: 战前餐，作用于下一场战斗
  - `hpRestoreOverTime: { ratio:0.0x, turns:N }`: 持续回血（探索态即时结算总量）
  - **不要用** weaponCoat（已废）、teamBuff（无队友）、skipTurnsHeal（改用大 hpRestore）
  - 战前餐 waigong 是「临时外功点数」不是百分比。
- 武器/护甲可加 **`atkMul`/`defMul`**（同品阶内微调强弱，0.8~1.3），一般不用。
### 武器/护甲特效 `effect`（怎么挂、有哪些）

机制：装备的 `effect: { ... }` 里写「战斗标志位」，切磋时系统会把这些标志位**叠到你当回合
出的那一招上**（只补招式本身没有的字段）。所以给武器挂特效 = 在 entry 里加一个 `effect` 对象。
一件装备可挂一到数个标志位。**品阶越高才配越强的特效**：白绿一般不挂，蓝可挂 1 个弱特效，
紫挂 1~2 个，橙红才挂强特效或组合。以下是**全部合法字段**（别自造字段，写了不认的等于没挂）：

**A. 加伤类（乘/加在招式倍率上）**
- `forceCrit: true` —— 必定暴击，本招按倍率放大（很强，限橙红）
- `ignoreDefense: true` —— 无视对方防御（强，限紫以上）
- `ignoreDefensePartialImmune: 0.3` —— 被无视防御时仍能挡下这个比例（护甲用，0~1）
- `doubleVsStatus: true` —— 克中对方状态招时伤害翻倍
- `highHpBonus: 0.3` —— 自己血≥80% 时倍率 +此值（越健康越猛）
- `lowHpBonus: 0.15` —— 自己血越低倍率越高（残血翻盘，×已损失血的十分位）
- `lowEnemyEnergyBonus: 0.5` —— 对方真气枯竭时伤害乘算放大（趁虚）
- `energyDiffDamage: 0.2` —— 按双方真气差追加伤害
- `selfDebuffBonus: 0.3` —— 自己身上带减益状态时反而倍率 +此值（绝境）
- `afterCounterBonus: 0.3` —— 上回合应对成功，本回合乘胜追击 +倍率
- `afterStatusBonus: 0.4` —— 上回合成功施加状态/印记，本回合趁乱补刀 +倍率
- `justiceStrike: true` —— 对方属「不义」势力（终局土司府线）时伤害翻倍（剧情向）

**B. 状态/印记类（打中对方施加负面）**
- `applyStatus: { name: "状态名", chance: 0.5 }` —— 概率施加状态。合法状态名只有：
  `麻穴`(概率无法行动)、`气乱`(概率打偏打自己)、`昏厥点`(完全无法行动)、
  `冰蚕丝缚`(冻结)、`淬毒`(每回合掉血1/8)、`剧毒`(掉血递增)、`裂伤`(掉血+攻击降)
- `applyMark: { name: "内伤印", stacks: 1 }` + `applyMarkChance: 0.5` —— 概率叠内伤印
- `detonateMark: { perStackRatio: 0.4 }` —— 引爆对方身上的印记，每层追加伤害
- `confuseChance: 0.3` —— 简写，等于概率施加「气乱」

**C. 控场/削弱类**
- `freezeEnergyRecovery: true` —— 打中后封住对方下回合回气
- `enemyCostPenalty: { value: 2, turns: 2 }` —— 令对方接下来 N 回合出招耗气增加
- `nullifyStatusOnHit: true` —— 打断并清空对方本回合的状态招

**D. 先手/蓄势类**
- `forceFirst: true` —— 无视身法强行先手结算
- `nextAttackBonus: 1.8` —— 本回合蓄势，把此值作为下一击的威力加成

**E. 博弈/成长类（多给「越用越强」的特色兵器，慎用）**
- `selfSacrifice: { damageMultiplier: 3.0, hpCostRatio: 0.2 }` —— 自损血量换高倍率
- `allInDamage: true` —— 倍率 = 消耗掉的全部真气/2（梭哈）
- `permanentGrowthOnUse: 0.1` —— 每用一次，这招倍率永久+此值（成长兵器）
- `permanentCostReductionOnUse: 1` —— 每用一次，耗气永久-此值（最低1）

**F. 护甲专属特效**（写在护甲的 effect 里）
- `immuneControl: true` —— 免疫控制/掉血/印记类状态（很强，限紫橙）
- `rebirthOnce: true` —— 血归零时复活一次回50%血（限橙红，涅槃引同款）
- `doubleReflectDamage: true` —— 防御成功时反弹双倍伤害

> **饰品也能挂 `effect` 和 `sixDim`**——而且饰品没有攻防数值，它的价值就体现在这两样上。
> 一枚好的紫档护身符可以既加六维又带一个弱特效（如 `sixDim:{根骨:1}` + `effect:{freezeEnergyRecovery:true}`）。
> 药食（MISC）不挂 effect，用 consumable。

**挂特效范例**（武器）：
```js
{ name: "淬毒黑风刺", category: ITEM_CATEGORY.WEAPON, quality: "蓝", tags: ["匪货","暗器"], effect: { applyStatus: { name: "淬毒", chance: 0.4 } }, desc: "黑风寨匪徒惯用的淬毒短刺，刺尖抹了大草甸蝎毒，见血封喉倒不至于，缠上三天高热却是逃不掉的。" },
{ name: "熊山透骨叉", category: ITEM_CATEGORY.WEAPON, quality: "紫", tags: ["猎具"], effect: { ignoreDefense: true, lowHpBonus: 0.12 }, desc: "老猎户对付熊瞎子的重叉，叉尖三棱开血槽，寻常皮甲拦不住这一记，猎人越是伤重脱力，这一叉反倒扎得越狠。" },
```

### 三、这批要补什么（缺口清单）

**A. 品类缺口（catalog 造得不够的行业池，最该补）：**
1. **商品饰品** 全线最缺（可售饰品才 10 件，橙红几乎没有）：需要各据点「能买的」饰品——
   藏银饰、玉扣、香囊、护身符、铜牌、珠串、扳指等，白绿蓝为主。**注意别写成某人的私物。**
2. **平民护具**（防身铺货源）：白绿档、不带人名的量产护身甲、皮护腕、短护具。
3. **锦官城民用商品**：成衣铺的绸缎衣裳/成衣、金玉行的商品金玉珠宝、香料铺的香料点心——
   这几类目前 catalog 几乎全是官造或私人物，缺「卖给百姓的民用货」。
4. **天都镇古玩/黑市货**：当铺能卖的非私人古玩、黑市的来路不明兵器/违禁品。
5. **紫橙档可售护甲/武器**：目前高阶几乎全是名器，缺「能买到的」中高档通货装备。

**B. 据点缺口（有货无店或货太薄，补该地风味的商品）：**
- 玉泉寨、熊山、大草甸、黑风寨、百花楼、欢喜堂——按各自风味补可售商品。

（每次跑，指定一个品类或一个据点，比如「补 8 件天都镇当铺能卖的古玩饰品，白绿蓝档」。）

### 四、输出格式

直接输出 JS 数组条目，每行一件，可以直接粘进 catalog 的 SUNDRIES。不要输出解释、不要 markdown 代码块外的话。像这样：

```js
{ name: "藏银錾花镯", category: ITEM_CATEGORY.ACCESSORY, quality: "绿", tags: ["饰品","藏银"], sixDim: { 魅力: 1 }, desc: "玉泉寨银匠錾出的缠枝纹手镯，戴久了银色发暗，牧女说那是牦牛奶熏的——洗不掉，也舍不得洗。" },
{ name: "熊山硝皮护腕", category: ITEM_CATEGORY.ARMOR, quality: "白", tags: ["护具","猎户"], desc: "熊山猎户自己硝的牛皮护腕，粗针脚缝三层，挡不住刀，倒是挡得住藤条抽脸。进山的人一人一副，磨得发亮的那副准是老手的。" },
```

### 五、正确/错误对照（务必遵守）

- ✅ `{ name:"青稞饼", category:ITEM_CATEGORY.MISC, quality:"白", tags:["食品","主食"], consumable:{hpRestore:0.08}, desc:"..." }`
- ❌ `{ name:"神剑", atk:200, price:9999 }` —— 不许写 atk/price，不许造神器当商品
- ❌ `{ name:"才旦的银锁", ... }` —— 不许造带人名的私人信物
- ❌ `consumable:{ weaponCoat:{...} }` —— 用了废弃字段
- ✅ 描述有地域细节、有反差、说书人口吻；❌ 描述空洞如「一把很好的剑，锋利无比」
