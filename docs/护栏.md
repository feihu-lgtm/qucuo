# CI 与依赖护栏

全局工程铁律见仓库根目录 `AGENTS.md`；已作废的历史状态快照与路线图已归档至 `docs/_archive/`。

## CI

PR 和推送到 `main` 都运行 `.github/workflows/ci.yml`：Node 24、npm 缓存、`npm ci`、`npm run verify`、`npm run ratchet`。现有 `deploy.yml` 保持不变。

本地快检用 `npm run verify:fast`（eslint + vitest，不跑构建）；`npm run verify` 与 CI 同构（eslint + vitest + pages build）。

## 硬门禁与棘轮上限

`npm run ratchet` 与 `src/boundary.test.js` 共同执行以下门禁，违者直接失败：

1. **跨层反向依赖**：沿 `entry/debug/ui → app/store → features/engine → domain/core/utils → infra/content` 方向检查逆向依赖，以及 `features -> engine`（0 容忍）。
2. **`engine/act` 禁 `.current`**：0 容忍。
3. **AI 直调旁路棘轮（`KNOWN_DIRECT_AI_CALL_DEBT`）**：扫描非测试文件中绕过 `withAI.js` 的 `callModel` / `callModelStream` / `ai.chat` 调用，未登记新文件 0 容忍，已登记文件只减不增（`storyteller.js`、`scanCalls.js`、卡片导入 UI 4 件套及 `resolveIntent.js` 死代码均已清零，当前存量 5 文件 7 处）。
4. **状态直写旁路棘轮（`KNOWN_STATE_WRITE_DEBT`）**：扫描 `ui/`、`app/hooks/`、`features/`（除 `features/run.js`）中的 `setVarTree` / `setVarTreeState` / `gameActions.set*` 调用，`features/` 0 容忍，`ui`（上限 5）与 `app/hooks`（上限 19）只减不增。
5. **结构膨胀棘轮**：`MudRPG.jsx` hook 传参数量（`KNOWN_MUD_RPG_HOOK_ARGS_CAP = 214`）及各层直连 `infra/` 数量（`KNOWN_EXTERNAL_INFRA_CAP` 中 `ui` 上限已降至 33）只减不增。

`npm run tree` 按需实时打印目录树（可带目录参数，如 `npm run tree -- src/ui`）。

## ESLint 层边界

以下规则设为 ESLint error：`engine/`、`features/`、`domain/` 不得导入 `ui/` 或
`app/`；`features/`、`domain/` 不得导入 `infra/`；`store/` 不得导入 `ui/`；`ui/` 全部生产文件均不得从 `ports/ai`、`infra/apiTransport`、`infra/apiConfig` 或 `infra/apiDiagnostics` 直接导入 `callModel` 或 `callModelStream`。
